# 13.6 Cross Join

## 1. What is Cross Join?

A **Cross Join** combines **every row of one table with every row of another table**.

In simple words:

> **Each row of Table 1 matches with ALL rows of Table 2.**

It is also called the **cross product of tables**. 

### Simple Example

Suppose:

**Table 1 has 4 rows**

**Table 2 has 3 rows**

Then:

**4 × 3 = 12 rows**

So the Cross Join produces **12 combinations**.

---

## 2. How does Cross Join work?

Suppose Table 1 contains:

| A |  B |
| - | -: |
| 1 |  2 |
| 3 |  4 |
| 5 |  6 |
| 7 |  8 |

And Table 2 contains:

|  B |  C |
| -: | -: |
|  2 |  1 |
|  8 |  1 |
|  9 |  1 |

Cross Join does **not look for matching values**.

It combines:

* Table 1 Row 1 → with Table 2 Row 1, Row 2, Row 3
* Table 1 Row 2 → with Table 2 Row 1, Row 2, Row 3
* Table 1 Row 3 → with Table 2 Row 1, Row 2, Row 3
* Table 1 Row 4 → with Table 2 Row 1, Row 2, Row 3

Therefore:

**4 × 3 = 12 rows**

---

## 3. Syntax

```sql
SELECT */attribute
FROM Table1
CROSS JOIN Table2;
```

The important point is:

**There is no `ON` condition in a Cross Join.**

The Cross Join automatically creates all possible combinations. 

---

## 4. Question → Answer

### Question:

**Perform a Cross Join between two tables where Table 1 contains 4 rows and Table 2 contains 3 rows.**

### Answer / Query:

```sql
SELECT *
FROM Table1
CROSS JOIN Table2;
```

### What happens?

If:

* Table1 = 4 rows
* Table2 = 3 rows

Then:

```text
4 × 3 = 12 rows
```

So the result contains **12 rows**.

---

## 5. Cross Join vs Inner Join

| Cross Join                                       | Inner Join                    |
| ------------------------------------------------ | ----------------------------- |
| Combines every row with every row                | Combines only matching rows   |
| No joining condition required                    | Joining condition is required |
| Produces Cartesian product                       | Produces matching records     |
| Number of rows = rows in Table1 × rows in Table2 | Depends on matching records   |

### Easy memory trick

**INNER JOIN → Find matches**

**CROSS JOIN → Combine everything**
