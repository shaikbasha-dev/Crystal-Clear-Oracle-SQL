# 14.2.1-Create

## 1. What is CREATE?

**CREATE** is a DDL command.

It is used to **create a database, table, or database object**.

In this section, we will focus on creating a **table**, because the example in the material creates a `Bank` table.

---

## 2. Why do we need CREATE?

Before we can store data in a table, we first need to create the table structure.

For example, suppose we want to store bank information.

We need columns such as:

* `bid` → Bank ID
* `bname` → Bank Name
* `bhq` → Bank Headquarters

So first we create the table.

```text
CREATE TABLE
      ↓
Creates the table structure
      ↓
Then data can be stored in it
```

---

# 3. CREATE TABLE Syntax

### Question

**How do we create a table in SQL?**

### Syntax

```sql id="b2f6e3"
CREATE TABLE table_name
(
    column_name1 datatype,
    column_name2 datatype,
    column_name3 datatype
);
```

---

## 4. Syntax Explanation

| Part           | Meaning                                |
| -------------- | -------------------------------------- |
| `CREATE`       | Command used to create something       |
| `TABLE`        | Specifies that we are creating a table |
| `table_name`   | Name of the table                      |
| `column_name1` | First column name                      |
| `datatype`     | Type of data that column can hold      |
| `column_name2` | Second column name                     |
| `column_name3` | Third column name                      |
| `;`            | End of the SQL statement               |

### Simple understanding

```text
CREATE TABLE
     ↓
"I want to create a table"

table_name
     ↓
"What should the table be called?"

column_name + datatype
     ↓
"What columns should the table contain?"
```

# 5. Example from the Material

### Question

**Create a table named `Bank` with bank ID, bank name and bank headquarters.**

### Query

```sql id="8zq4zq"
CREATE TABLE Bank
(
    bid   INT,
    bname VARCHAR2(87),
    bhq   VARCHAR2(46)

```

The example uses the `Bank` table with `bid`, `bname`, and `bhq` columns. 

---

# 6. Understanding the Table Structure

After executing the query, the table structure is:

| Column Name | Data Type      | Purpose                  |
| ----------- | -------------- | ------------------------ |
| `BID`       | `INT`          | Stores bank ID           |
| `BNAME`     | `VARCHAR2(87)` | Stores bank name         |
| `BHQ`       | `VARCHAR2(46)` | Stores bank headquarters |

So the table looks conceptually like this:

| BID | BNAME | BHQ |
| --- | ----- | --- |
| —   | —     | —   |

There are **no rows yet**.

Only the **table structure** has been created.

# 7. What happens when CREATE TABLE executes?

Suppose we execute:

```sql id="6myx5c"
CREATE TABLE Bank
(
    bid   INT,
    bname VARCHAR2(87),
    bhq   VARCHAR2(46)
);
```

### Step-by-step

**Step 1**

Oracle receives the `CREATE TABLE` command.

↓

**Step 2**

Oracle understands that a new table has to be created.

↓

**Step 3**

Oracle creates a table named `BANK`.

↓

**Step 4**

Oracle creates three columns:

```text
BID
BNAME
BHQ
```

↓

**Step 5**

The specified data types are associated with those columns.

↓

**Result:**

The `BANK` table structure is created.

---

# 8. Important Point

`CREATE TABLE` creates the **structure** of the table.

It does **not** insert data into the table.

For example:

```text
CREATE TABLE
      ↓
Creates structure

INSERT
      ↓
Adds data
```

So these are two different operations.

---

# 9. CREATE vs INSERT

| CREATE                     | INSERT                  |
| -------------------------- | ----------------------- |
| Creates table structure    | Adds data into table    |
| DDL command                | DML command             |
| Defines columns            | Adds rows               |
| Used before inserting data | Used after table exists |

### Easy Example

```sql id="2m5n5d"
CREATE TABLE Student
(
    id INT,
    name VARCHAR2(50)
);
```

This creates:

| ID | NAME |
| -- | ---- |
| —  | —    |

Then `INSERT` can be used to add rows.

# 10. Important Rules

### Rule 1 — Table name is required

```sql id="9m9f5f"
CREATE TABLE Bank
```

`Bank` is the table name.

---

### Rule 2 — Every column needs a data type

```sql id="u5v8b2"
bid INT
```

Here:

* `bid` → column name
* `INT` → data type

---

### Rule 3 — Multiple columns are separated by commas

```sql id="w4tq9j"
bid INT,
bname VARCHAR2(87),
bhq VARCHAR2(46)
```

---

### Rule 4 — Parentheses contain the table columns

```sql id="7t7l1w"
CREATE TABLE Bank
(
    ...
);
```

---

### Rule 5 — End the command with `;`

```sql id="7w7j6c"
);
```

# 11. Common Confusion

### Confusion: Does CREATE add rows?

**No.**

`CREATE TABLE` creates the **table structure**.

For adding rows, we use:

```text
INSERT
```

---

### Confusion: Does CREATE change an existing table?

**No.**

To modify the structure of an existing table, we use:

```text
ALTER
```

---

### Confusion: Does CREATE delete a table?

**No.**

To remove a table, we use:

```text
DROP
```

---

# 12. CREATE, ALTER, TRUNCATE and DROP

| Command      | What happens?                    |
| ------------ | -------------------------------- |
| **CREATE**   | Creates table/object             |
| **ALTER**    | Changes existing table structure |
| **TRUNCATE** | Removes all rows                 |
| **DROP**     | Removes the table/object         |

These four commands form the DDL group.
