# 14.2.2-Alter-Overview

## 1. What is ALTER?

**ALTER** is a **DDL command** used to **alter or modify the structure of an existing table**.

### Simple Example

Suppose we already have:

| BID | BNAME | BHQ       |
| --: | ----- | --------- |
|   1 | SBI   | Hyderabad |
|   2 | HDFC  | Mumbai    |

Now suppose we want to add a new column called `PH_NO`.

We don't need to create the table again.

We use **ALTER**.

```text
Existing Table
      ↓
     ALTER
      ↓
Modified Table Structure
```

---

# 2. Why do we need ALTER?

After creating a table, requirements may change.

For example:

| Requirement             | What we use       |
| ----------------------- | ----------------- |
| Add a new column        | `ADD`             |
| Remove a column         | `DROP COLUMN`     |
| Change column name      | `RENAME COLUMN`   |
| Change table name       | `RENAME TO`       |
| Change column data type | `MODIFY`          |
| Change data type size   | `MODIFY`          |
| Add a constraint        | `ADD CONSTRAINT`  |
| Remove a constraint     | `DROP CONSTRAINT` |

So, **ALTER allows us to change the existing table structure without creating a completely new table.**

# 4. Basic Syntax of ALTER

### Question

**What is the general syntax used to modify an existing table?**

### Syntax

```sql
ALTER TABLE table_name
operation;
```

### Syntax Explanation

| Part         | Meaning                                       |
| ------------ | --------------------------------------------- |
| `ALTER`      | Tells Oracle that we want to modify something |
| `TABLE`      | Specifies that we are modifying a table       |
| `table_name` | Name of the existing table                    |
| `operation`  | Modification that we want to perform          |
| `;`          | End of the SQL command                        |

The actual operation changes depending on what we want to modify.

# 5. Eight Operations of ALTER

## 5.1 Add a Column

Used when we want to **add a new column** to an existing table.

```sql
ALTER TABLE table_name
ADD column_name datatype;
```

Example:

```sql
ALTER TABLE Bank
ADD ph_no NUMBER;
```

---

## 5.2 Drop a Column

Used when we want to **remove an existing column**.

```sql
ALTER TABLE table_name
DROP COLUMN column_name;
```

Example:

```sql
ALTER TABLE Bank
DROP COLUMN ph_no;
```

---

## 5.3 Rename a Column

Used when we want to **change the name of an existing column**.

```sql
ALTER TABLE table_name
RENAME COLUMN old_column_name
TO new_column_name;
```

Example:

```sql
ALTER TABLE Bank
RENAME COLUMN bname
TO bankname;
```

---

## 5.4 Rename a Table

Used when we want to **change the name of an existing table**.

```sql
ALTER TABLE table_name
RENAME TO new_table_name;
```

Example:

```sql
ALTER TABLE Bank
RENAME TO Bank_Details;
```

---

## 5.5 Modify Data Type

Used when we want to **change the data type of a column**.

```sql
ALTER TABLE table_name
MODIFY column_name datatype;
```

Example:

```sql
ALTER TABLE Bank_Details
MODIFY bid VARCHAR2(54);
```

### Important Rule

The column being modified must be **empty** when changing its data type.

---

## 5.6 Change Data Type Size

Used when we want to **change the size of a column's data type**.

```sql
ALTER TABLE table_name
MODIFY column_name datatype(size);
```

Example:

```sql
ALTER TABLE Bank_Details
MODIFY bank_name VARCHAR2(97);
```

---

## 5.7 Add a Constraint

Used when we want to **add a constraint to an existing table**.

```sql
ALTER TABLE table_name
ADD CONSTRAINT constraint_name
constraint_type(column_name);
```

Example:

```sql
ALTER TABLE Bank_Details
ADD CONSTRAINT b_pk
PRIMARY KEY(bid);
```

---

## 5.8 Drop a Constraint

Used when we want to **remove an existing constraint**.

```sql
ALTER TABLE table_name
DROP CONSTRAINT constraint_name;
```

Example:

```sql
ALTER TABLE Bank_Details
DROP CONSTRAINT b_pk;
```

# 6. ALTER Operations at a Glance

| No. | Operation             | What changes?            |
| --: | --------------------- | ------------------------ |
|   1 | Add Column            | Adds a column            |
|   2 | Drop Column           | Removes a column         |
|   3 | Rename Column         | Changes column name      |
|   4 | Rename Table          | Changes table name       |
|   5 | Modify Data Type      | Changes column data type |
|   6 | Change Data Type Size | Changes datatype size    |
|   7 | Add Constraint        | Adds a constraint        |
|   8 | Drop Constraint       | Removes a constraint     |

---

# 7. ALTER vs CREATE

| CREATE                        | ALTER                               |
| ----------------------------- | ----------------------------------- |
| Creates a new table           | Modifies an existing table          |
| Defines the initial structure | Changes the existing structure      |
| Used when creating a table    | Used after the table already exists |

### Easy Memory Trick

> **CREATE = Build**
> **ALTER = Change**

---

# 8. ALTER vs DML

| ALTER                              | DML                              |
| ---------------------------------- | -------------------------------- |
| Changes table structure            | Changes/manipulates table data   |
| DDL command                        | DML command                      |
| Examples: ADD, DROP COLUMN, RENAME | Examples: INSERT, UPDATE, DELETE |
| Works with structure               | Works with rows/data             |

### Example

**Change structure:**

```sql
ALTER TABLE Bank
ADD ph_no NUMBER;
```

**Change data:**

```sql
UPDATE Bank
SET bname = 'Bank of Baroda';
```

The first changes the **structure**; the second changes the **data**.

---

# 9. Important Rules

### Rule 1

`ALTER` is used for an **existing table**.

### Rule 2

`ALTER` changes the **structure** of the table.

### Rule 3

Different structural changes require different ALTER operations.

### Rule 4

When changing a column's data type, the column must be empty.

### Rule 5

Adding and dropping constraints are also performed using `ALTER TABLE`.

# 10. Interview Questions

### Question 1

**What is ALTER command?**

**Answer:**

> ALTER is a DDL command used to alter or modify the structure of an existing table.

### Question 2

**What are the operations performed using ALTER?**

**Answer:**

> We can add or drop columns, rename columns, rename tables, modify data types, change data type sizes, add constraints, and drop constraints.

### Question 3

**Can ALTER be used to modify data values?**

**Answer:**

> ALTER is used to modify the table structure. To modify data values, we use UPDATE.
