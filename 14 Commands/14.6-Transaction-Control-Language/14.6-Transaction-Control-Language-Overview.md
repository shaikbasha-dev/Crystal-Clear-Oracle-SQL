# 14.6-Transaction-Control-Language-Overview

## 1. What is TCL?

**TCL** stands for **Transaction Control Language**.

TCL commands are used to **control transactions** such as:

* Insertion
* Updation
* Deletion

TCL commands are used along with **DML commands**.

The TCL commands covered here are:

1. **COMMIT**
2. **ROLLBACK**
3. **SAVEPOINT** 

---

## 2. What is a Transaction?

A **transaction** is a group of DML operations performed as one unit.

For example:

```text
INSERT
INSERT
UPDATE
DELETE
   ↓
Transaction
   ↓
COMMIT / ROLLBACK
```

TCL helps us decide what should happen to those DML changes.

---

## 3. Why do we need TCL?

DML actions such as `INSERT`, `UPDATE`, and `DELETE` are not permanent until they are controlled using TCL.

```text
DML
 │
 ├── INSERT
 ├── UPDATE
 └── DELETE
       │
       ↓
      TCL
       │
       ├── COMMIT    → Save permanently
       ├── ROLLBACK  → Undo changes
       └── SAVEPOINT → Create temporary point
```

The main purpose is therefore to **control changes made by DML commands**. 

---

# 4. Types of TCL Commands

| Command       | Purpose                                                 |
| ------------- | ------------------------------------------------------- |
| **COMMIT**    | Permanently saves DML actions                           |
| **ROLLBACK**  | Undoes DML actions that have not been permanently saved |
| **SAVEPOINT** | Sets a temporary point within a transaction             |



---

# 5. COMMIT

### Question:

**Which TCL command is used to save DML actions permanently in the database?**

### Answer:

`COMMIT`

### Syntax:

```sql
COMMIT;
```

The `COMMIT` command permanently saves the DML actions in the database. 

### Simple flow

```text
INSERT / UPDATE / DELETE
          ↓
       COMMIT
          ↓
   Changes saved permanently
```

---

# 6. ROLLBACK

### Question:

**Which TCL command is used to undo DML actions that are not permanently saved?**

### Answer:

`ROLLBACK`

### Syntax:

```sql
ROLLBACK;
```

`ROLLBACK` is used to undo DML actions that have not been permanently saved. 

There is also another form:

```sql
ROLLBACK TO savepoint_name;
```

This rolls back to a particular savepoint. 

---

# 7. SAVEPOINT

### Question:

**Which TCL command is used to set a temporary savepoint within a transaction?**

### Answer:

`SAVEPOINT`

### Syntax:

```sql
SAVEPOINT savepoint_name;
```

A savepoint creates a temporary point inside a transaction. 

### Simple flow

```text
DML 1
  ↓
SAVEPOINT X
  ↓
DML 2
  ↓
ROLLBACK TO X
  ↓
Back to SAVEPOINT X
```

---

# 8. Complete Transaction Flow

The following sequence demonstrates how `COMMIT`, `SAVEPOINT`, and `ROLLBACK` work together.

### Question:

**How can multiple DML operations be controlled using COMMIT, SAVEPOINT, and ROLLBACK?**

### Answer / Query:

```sql
INSERT INTO demo1 VALUES(1, 'A', 22);

INSERT INTO demo1 VALUES(2, 'B', 23);

INSERT INTO demo1 VALUES(3, 'C', 23);

COMMIT;

INSERT INTO demo1 VALUES(4, 'D', 24);

SAVEPOINT x;

INSERT INTO demo1 VALUES(5, 'P', 25);

ROLLBACK TO x;

ROLLBACK;
```



---

## 9. Understand the Sequence Step-by-Step

### Step 1

### Question:

**What happens when the first three rows are inserted into `demo1`?**

```sql
INSERT INTO demo1 VALUES(1, 'A', 22);
INSERT INTO demo1 VALUES(2, 'B', 23);
INSERT INTO demo1 VALUES(3, 'C', 23);
```

Three rows are inserted as DML operations.

---

### Step 2

### Question:

**How are the first three INSERT operations permanently saved?**

```sql
COMMIT;
```

The first three insertions are permanently saved.

```text
Rows 1, 2, 3
     ↓
  COMMIT
     ↓
Permanently saved
```

---

### Step 3

### Question:

**How is another row inserted after the COMMIT?**

```sql
INSERT INTO demo1 VALUES(4, 'D', 24);
```

Row 4 is inserted after the previous `COMMIT`.

---

### Step 4

### Question:

**How do you create a temporary savepoint named `x`?**

```sql
SAVEPOINT x;
```

A temporary point named `x` is created.

```text
Rows 1,2,3 → COMMIT
                 ↓
              Row 4
                 ↓
            SAVEPOINT x
```

---

### Step 5

### Question:

**How is another row inserted after savepoint `x`?**

```sql
INSERT INTO demo1 VALUES(5, 'P', 25);
```

Row 5 is inserted after the savepoint.

---

### Step 6

### Question:

**How do you return to savepoint `x`?**

```sql
ROLLBACK TO x;
```

The transaction returns to savepoint `x`.

The change made after savepoint `x` is undone.

```text
SAVEPOINT x
     ↓
INSERT row 5
     ↓
ROLLBACK TO x
     ↓
Row 5 change is undone
```

---

### Step 7

### Question:

**How do you perform a general rollback?**

```sql
ROLLBACK;
```

The remaining uncommitted DML changes are rolled back.

---

# 10. COMMIT vs ROLLBACK vs SAVEPOINT

| Command       | Simple meaning           |
| ------------- | ------------------------ |
| **COMMIT**    | Save changes permanently |
| **ROLLBACK**  | Undo uncommitted changes |
| **SAVEPOINT** | Mark a temporary point   |

### Easy memory trick

```text
COMMIT     → SAVE
ROLLBACK   → UNDO
SAVEPOINT  → MARK A POINT
```

---

# 11. TCL and DML Relationship

```text
             SQL COMMANDS
                  │
        ┌─────────┴─────────┐
        │                   │
       DML                 TCL
        │                   │
 INSERT / UPDATE / DELETE   │
        │                   │
        └────────┬──────────┘
                 ↓
       Control the transaction
```

### Important point

**DML performs the data changes.**

**TCL controls those changes.**
