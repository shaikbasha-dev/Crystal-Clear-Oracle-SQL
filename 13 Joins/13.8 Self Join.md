# 13.8 Self Join

## 1. What is Self Join?

A **Self Join** means:

> **A table is joined with itself.**

That means we use the **same table twice** in a query.

The database treats these two references as if they are two separate copies of the same table.

### Why do we need it?

A Self Join is useful when we want to **compare data in one row with data in another row of the same table**.

For example, we may want to compare the salary of one employee with the salary of another employee in the **same EMP table**.

---

## 2. Simple Understanding

Suppose the `EMP` table contains:

| F_NAME | SALARY |
| ------ | -----: |
| Pandey | 50,000 |
| Akash  | 30,000 |
| Raja   | 40,000 |

If we want to find employees whose salary is **greater than Pandey's salary**, we need to compare:

```text
Employee salary
       ↓
with
       ↓
Pandey's salary
```

Both pieces of information are present in the **same EMP table**.

Therefore, we use a **Self Join**.

---

## 3. Important Point

In a Self Join, we generally use **aliases** so that we can refer to the same table in two different ways.

For example:

```sql
EMP e
EMP f
```

Here:

```text
e → first reference of EMP
f → second reference of EMP
```

---

## 4. Syntax

The syntax used is:

```sql id="1w7q2a"
SELECT ...
FROM Emp e, Emp f
WHERE ...;
```

Here:

* `Emp e` → first copy/reference
* `Emp f` → second copy/reference

---

# 5. Question → Answer

### Question:

**Display the first name, last name and salary of employees whose salary is greater than the salary of the employee whose last name is `Pandey`.**

### Answer / Query:

```sql id="k8v4r2"
SELECT f.F_name, f.L_name, f.Salary
FROM Emp e, Emp f
WHERE f.Salary > e.Salary
AND e.F_name = 'Pandey';
```

---

## 6. Understand the Query Step-by-Step

### Step 1: Same table is used twice

```sql
FROM Emp e, Emp f
```

The `EMP` table is referenced two times:

```text
EMP e
EMP f
```

---

### Step 2: Find Pandey

```sql
e.F_name = 'Pandey'
```

This identifies the row representing Pandey.

---

### Step 3: Compare salaries

```sql
f.Salary > e.Salary
```

This means:

> Find employees whose salary is greater than Pandey's salary.

---

### Step 4: Display required columns

```sql
SELECT f.F_name, f.L_name, f.Salary
```

The query displays:

* First name
* Last name
* Salary

of the employees whose salary is greater than Pandey's salary.

---

## 7. Why are `e` and `f` used?

Without aliases, it would become confusing because both references point to the same table.

Instead of repeatedly writing:

```text
EMP
EMP
```

we write:

```text
EMP e
EMP f
```

So:

```text
e.Salary
```

means salary from the first reference.

And:

```text
f.Salary
```

means salary from the second reference.

---

## 8. Self Join vs Normal Join

| Normal Join                    | Self Join                                                   |
| ------------------------------ | ----------------------------------------------------------- |
| Usually joins different tables | Joins a table with itself                                   |
| Example: `EMP` + `DEPT`        | Example: `EMP` + `EMP`                                      |
| Tables are different           | Same table is used twice                                    |
| Aliases may be used            | Aliases are important for distinguishing the two references |

### Easy memory trick

**Self Join = Table joins itself**

```text
EMP
 ↓
EMP
```

Think:

> **Same table + Same table = Self Join**
