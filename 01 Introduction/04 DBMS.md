# DBMS

## 1. What is DBMS?

**DBMS** stands for:

> **DataBase Management System**

A DBMS is a system used to **manage a large volume of facts and figures**.

In simple words:

> **DBMS is software that helps us manage data stored in a database.**

---

## 2. Why do we need DBMS?

In the beginning, programming languages were used to store facts and figures.

For example:

```java
String name = "Basha";
int age = 23;
String gender = "Male";
String branch = "E.C.E";
int studentId = 458;
int percentage = 93;
```

This works when we have a **small volume of information**.

But imagine a university has information about thousands of students.

For every fact and figure, we would have to:

```text
Declare a variable
       ↓
Specify a data type
       ↓
Initialize the variable
```

Managing a large volume this way becomes difficult.

Therefore:

```text
Programming Languages
        ↓
Difficulty in managing large volume
        ↓
       DBMS
        ↓
Management of large volume of facts & figures
```

---

## 3. Simple Real-Life Analogy

Imagine a huge library.

You have thousands of books.

If books are simply thrown everywhere:

```text
📚 📚 📚 📚 📚
📚 📚 📚 📚 📚
📚 📚 📚 📚 📚
```

Finding a particular book becomes difficult.

Now imagine there is a **library management system** that helps organize and find those books.

Similarly:

```text
Books              → Data
Library collection → Database
Library system     → DBMS
```

The DBMS helps manage the large amount of information.

---

## 4. What does DBMS mean?

Break the word:

```text
D → Data
B → Base
M → Management
S → System
```

So:

> **DataBase Management System**

It is a system for managing a database.

---

## 5. What does DBMS manage?

The main purpose discussed here is managing a **large volume of facts and figures**.

The important requirements are:

```text
Facts & Figures
      ↓
Store Permanently
      +
Retrieve Efficiently
```

So we need a system that helps us manage information in this way.

---

## 6. DBMS and Database

Don't confuse these two.

### Database

A **database** is the collection of a large volume of facts and figures.

### DBMS

A **DBMS** is the system used to manage that database.

Think:

```text
DATABASE
   ↓
Large volume of facts & figures

       ↑
       |
      DBMS
       |
       ↓
Management System
```

## 9. Important Rules

Remember:

1. **DBMS = DataBase Management System**
2. DBMS came into the picture when programming languages became insufficient for managing a large volume of facts and figures.
3. DBMS is used for managing databases.
4. Facts and figures need to be:

   * **Stored permanently**
   * **Retrieved efficiently**
5. Programming languages can handle a small volume of facts and figures, but managing a large volume becomes difficult.
