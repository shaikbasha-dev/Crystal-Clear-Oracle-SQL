# 16.6.3-Deleting-a-Sequence

## 1. What does Deleting a Sequence mean?

Deleting a Sequence means **removing an existing Sequence database object** from the database.

The command used is:

```text
DROP SEQUENCE
```

---

## 2. Syntax

### Question:

What is the syntax for deleting a Sequence?

### Answer / Syntax:

```sql
DROP SEQUENCE sequence_name;
```

Here:

| Part            | Meaning                                 |
| --------------- | --------------------------------------- |
| `DROP`          | Removes a database object               |
| `SEQUENCE`      | Specifies that the object is a Sequence |
| `sequence_name` | Name of the Sequence to delete          |

The deletion syntax is `DROP SEQUENCE sequence_name;`. 

---

## 3. Deleting the `Dec` Sequence

Earlier, we created a Sequence named `Dec`.

### Question:

How can you delete the Sequence named `Dec`?

### Answer / Query:

```sql
DROP SEQUENCE Dec;
```

### Explanation

Here:

```text
DROP
 ↓
Remove

SEQUENCE
 ↓
Object type

Dec
 ↓
Sequence name
```

So:

```text
DROP SEQUENCE Dec;
```

means:

> **Remove the Sequence named `Dec` from the database.**

The example for deleting the Sequence is `DROP SEQUENCE Dec;`. 

---

## 4. What happens after deleting the Sequence?

Before deletion:

```text
Database
   ↓
Sequence: Dec
   ↓
Can generate Sequence values
```

After:

```text
DROP SEQUENCE Dec;
```

the Sequence `Dec` is removed.

```text
Database
   ↓
Sequence: Dec ❌
```

It no longer exists as a Sequence database object.

---

## 5. Complete Sequence Lifecycle

The basic lifecycle is:

```text
CREATE SEQUENCE
       ↓
Sequence created
       ↓
Use NEXTVAL
       ↓
Generate values
       ↓
DROP SEQUENCE
       ↓
Sequence removed
```

For example:

### Question:

Create a Sequence named `Dec` starting from 1 and increasing by 1.

### Answer / Query:

```sql
CREATE SEQUENCE Dec
START WITH 1
INCREMENT BY 1;
```

### Question:

Delete the Sequence named `Dec`.

### Answer / Query:

```sql
DROP SEQUENCE Dec;
```

---

## 6. `DROP SEQUENCE` vs `DROP TABLE`

| `DROP SEQUENCE`        | `DROP TABLE`               |
| ---------------------- | -------------------------- |
| Deletes a Sequence     | Deletes a table            |
| Object type = Sequence | Object type = Table        |
| `DROP SEQUENCE Dec;`   | `DROP TABLE Bank_Details;` |

### Easy memory:

```text
Sequence → DROP SEQUENCE

Table → DROP TABLE
```

---

## 7. `DROP SEQUENCE` vs `DROP TRIGGER`

| Command         | Removes  |
| --------------- | -------- |
| `DROP SEQUENCE` | Sequence |
| `DROP TRIGGER`  | Trigger  |

Examples:

### Question:

Delete Sequence `Dec`.

### Answer / Query:

```sql
DROP SEQUENCE Dec;
```

### Question:

Delete Trigger `dec`.

### Answer / Query:

```sql
DROP TRIGGER dec;
```

---

## 8. Important Points

* `DROP SEQUENCE` is used to delete a Sequence.
* The Sequence name must be specified.
* Example:

```sql
DROP SEQUENCE Dec;
```

* After dropping it, the Sequence is no longer available as a database object.
* `DROP` removes the Sequence object; it is different from using `NEXTVAL` or `CURRVAL`.
