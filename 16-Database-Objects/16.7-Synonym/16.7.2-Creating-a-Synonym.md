# 16.7.2-Creating-a-Synonym

## 1. What does Creating a Synonym mean?

Creating a Synonym means creating an **alternate name for an existing table**.

For example:

```text
Existing table
     ↓
    EMP
     ↓
Create Synonym
     ↓
EMP_DETAILS
```

So `EMP_DETAILS` becomes another name for `EMP`.

---

## 2. Syntax

### Question:

What is the syntax for creating a Synonym?

### Answer / Syntax:

```sql
CREATE SYNONYM synonym_name
FOR table_name;
```

### Meaning

| Part             | Meaning                                      |
| ---------------- | -------------------------------------------- |
| `CREATE SYNONYM` | Creates a Synonym                            |
| `synonym_name`   | Name you want to give to the Synonym         |
| `FOR`            | Connects the Synonym with the existing table |
| `table_name`     | Existing table name                          |

---

# 3. Example

### Question:

Create a Synonym named `emp_details` for the `emp` table.

### Answer / Query:

```sql
CREATE SYNONYM emp_details
FOR emp;
```



### Explanation

In this query:

```text
emp_details
     ↓
Synonym name

emp
     ↓
Existing table
```

Therefore:

```text
EMP
 ↑
 │
EMP_DETAILS
```

`emp_details` is another name for the existing `emp` table.

---

# 4. Understanding the Query Word by Word

### Question:

What does `CREATE SYNONYM emp_details FOR emp;` do?

### Answer / Query:

```sql
CREATE SYNONYM emp_details
FOR emp;
```

Break it down:

```text
CREATE
  ↓
Create something

SYNONYM
  ↓
Create an alternate name

emp_details
  ↓
Name of the Synonym

FOR
  ↓
For which existing object?

emp
  ↓
Existing table
```

So the complete meaning is:

> **Create the Synonym `emp_details` for the existing table `emp`.**

---

# 5. What Happens After Creating the Synonym?

Before creating:

```text
EMP
```

After:

```text
EMP
 ↑
 │
EMP_DETAILS
```

There are **not two copies of the table**.

There is still one actual table:

```text
EMP
```

and another name:

```text
EMP_DETAILS
```

that refers to it.

---

# 6. Important Point

Creating a Synonym does **not** create a new table.

### Question:

If we execute the following query, does Oracle create another copy of `EMP`?

### Answer / Query:

```sql
CREATE SYNONYM emp_details
FOR emp;
```

**Answer:** No.

It creates another name for the existing table.

```text
Actual table → EMP
Synonym      → EMP_DETAILS
```

---


Think:

```text

      ↓
new_name
      ↓
FOR
      ↓
existing_table
```

# 9. Common Confusion

### Synonym name vs Table name

In:

```sql
CREATE SYNONYM emp_details
FOR emp;
```

Do not confuse them.

```text
emp_details → Synonym name
emp         → Existing table name
```

### Easy memory:

> **The name before `FOR` is the Synonym; the name after `FOR` is the existing table.**

---

# 10. Creating vs Deleting a Synonym

| Creating                              | Deleting                    |
| ------------------------------------- | --------------------------- |
| `CREATE SYNONYM`                      | `DROP SYNONYM`              |
| Creates an alternate name             | Removes the Synonym         |
| `CREATE SYNONYM emp_details FOR emp;` | `DROP SYNONYM emp_details;` |

# 11. Interview Questions

### Q1. Which command is used to create a Synonym?

**Answer:**

```text
CREATE SYNONYM
```

### Q2. Write the syntax for creating a Synonym.

**Answer:**

```sql
CREATE SYNONYM synonym_name
FOR table_name;
```

### Q3. Create a Synonym named `emp_details` for the `emp` table.

**Answer:**

```sql
CREATE SYNONYM emp_details
FOR emp;
```

### Q4. In `CREATE SYNONYM emp_details FOR emp;`, what is `emp_details`?

**Answer:**
`emp_details` is the **Synonym name**.

### Q5. In `CREATE SYNONYM emp_details FOR emp;`, what is `emp`?

**Answer:**
`emp` is the **existing table**.

### Q6. Does creating a Synonym create a new copy of the table?

**Answer:**
No. It gives another name to the existing table.
