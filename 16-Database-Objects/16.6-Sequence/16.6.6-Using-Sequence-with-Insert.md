# 16.6.6-Using-Sequence-with-Insert

## 1. What does Using Sequence with INSERT mean?

A Sequence generates numbers automatically.

`INSERT` can use the Sequence's `NEXTVAL` to insert that automatically generated number into a table.

The basic flow is:

```text
SEQUENCE
   ↓
NEXTVAL
   ↓
Automatic number
   ↓
INSERT INTO table
```

The pattern used is:

```sql
sequence_name.NEXTVAL
```

inside the `INSERT` statement. 

---

## 2. Why use a Sequence with INSERT?

Suppose a table contains:

| ID | NAME   |
| -: | ------ |
|  1 | Sachin |
|  2 | Virat  |
|  3 | Rohit  |

Instead of manually entering:

```text
1
2
3
4
5
...
```

we can allow the Sequence to generate the ID.

```text
Dec.NEXTVAL
     ↓
     4
     ↓
INSERT
```

So the number is generated automatically.

---

# 3. Syntax

### Question:

What is the syntax for using a Sequence with an INSERT statement?

### Answer / Syntax:

```sql
INSERT INTO table_name
VALUES(sequence_name.NEXTVAL, 'value');
```

Here:

| Part                    | Meaning                           |
| ----------------------- | --------------------------------- |
| `INSERT INTO`           | Inserts a new record              |
| `table_name`            | Name of the table                 |
| `sequence_name.NEXTVAL` | Generates the next Sequence value |
| `'value'`               | Value for another column          |

---

# 4. Sequence Used in the Example

The Sequence used is `Dec`.

### Question:

Create a Sequence named `Dec` starting from `1` and increasing by `1`.

### Answer / Query:

```sql
CREATE SEQUENCE Dec
START WITH 1
INCREMENT BY 1;
```

Now:

```text
Dec.NEXTVAL
```

can generate:

```text
1 → 2 → 3 → 4 → 5 → ...
```

---

# 5. First INSERT Using Sequence

Suppose the `demo` table has:

```text
ID
NAME
```

### Question:

Insert `Sachin` into the `demo` table using the next value of the `Dec` Sequence.

### Answer / Query:

```sql
INSERT INTO demo
VALUES(Dec.NEXTVAL, 'Sachin');
```

The query uses:

```text
Dec.NEXTVAL
```

instead of manually entering an ID.

If the next Sequence value is `1`, the result is:

| ID | NAME   |
| -: | ------ |
|  1 | Sachin |

This is the first INSERT example given with `Dec.nextval`. 

---

# 6. Second INSERT Using Sequence

### Question:

Insert `virat` into the `demo` table using the next value of the `Dec` Sequence.

### Answer / Query:

```sql
INSERT INTO demo
VALUES(Dec.NEXTVAL, 'virat');
```

The next Sequence value is generated automatically.

If the previous value was `1`, the new value is `2`.

Result:

| ID | NAME   |
| -: | ------ |
|  1 | Sachin |
|  2 | virat  |

The example uses `dec.nextval` again for the second INSERT. 

---

# 7. Third INSERT Concept

The same idea continues for every new record.

### Question:

Insert another employee using the next value generated by the `Dec` Sequence.

### Answer / Query:

```sql
INSERT INTO demo
VALUES(Dec.NEXTVAL, 'Rohit');
```

If the current sequence progression is:

```text
1 → 2 → 3
```

then this INSERT receives:

```text
ID = 3
```

So the table becomes:

| ID | NAME   |
| -: | ------ |
|  1 | Sachin |
|  2 | virat  |
|  3 | Rohit  |

---

# 8. How the Process Works

Suppose the Sequence starts at `1` and increments by `1`.

### First INSERT

```text
Dec.NEXTVAL
     ↓
     1
     ↓
Sachin
```

### Second INSERT

```text
Dec.NEXTVAL
     ↓
     2
     ↓
virat
```

### Third INSERT

```text
Dec.NEXTVAL
     ↓
     3
     ↓
Rohit
```

Therefore:

```text
Dec.NEXTVAL
     ↓
Automatic ID
     ↓
INSERT INTO demo
```

# 9. `NEXTVAL` is the Important Part

When using a Sequence with `INSERT`, remember:

```sql
Dec.NEXTVAL
```

not:

```sql
Dec
```

### Question:

Which expression should be used to obtain the next Sequence value during INSERT?

### Answer:

```sql
Dec.NEXTVAL
```

`NEXTVAL` tells Oracle to generate the next value from the Sequence.

---

# 10. Sequence + INSERT vs Manual INSERT

### Manual approach

### Question:

Insert `Sachin` with ID `1` manually.

### Answer / Query:

```sql
INSERT INTO demo
VALUES(1, 'Sachin');
```

Here, the ID is entered manually.

### Sequence approach

### Question:

Insert `Sachin` using the next value from the `Dec` Sequence.

### Answer / Query:

```sql
INSERT INTO demo
VALUES(Dec.NEXTVAL, 'Sachin');
```

Here, the Sequence generates the ID.

| Manual                       | Sequence                     |
| ---------------------------- | ---------------------------- |
| ID entered manually          | ID generated by Sequence     |
| `1`                          | `Dec.NEXTVAL`                |
| Developer decides the number | Sequence provides the number |

# 12. Important Points

* A Sequence can generate numbers automatically.
* `NEXTVAL` is used to obtain the next Sequence value.
* `NEXTVAL` can be used inside an `INSERT` statement.
* The general pattern is:

```sql
INSERT INTO table_name
VALUES(sequence_name.NEXTVAL, 'value');
```

* Example:

```sql
INSERT INTO demo
VALUES(Dec.NEXTVAL, 'Sachin');
```

* Each use of `NEXTVAL` obtains the next Sequence value.

---

# 13. Common Confusion

### `NEXTVAL` vs `CURRVAL`

```text
NEXTVAL
   ↓
Generates next value
```

```text
CURRVAL
   ↓
Current value
```

When inserting a new record and an automatic Sequence number is required, the important expression is:

```text
sequence_name.NEXTVAL
```
