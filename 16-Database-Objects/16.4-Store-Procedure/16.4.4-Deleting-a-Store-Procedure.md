# 16.4.4-Deleting-a-Store-Procedure

## 1. What does Deleting a Stored Procedure mean?

Deleting a Stored Procedure means **removing an already-created procedure from the database**.

Once a procedure is deleted, it is no longer available to call.

```text
Stored Procedure
       ↓
   DROP PROCEDURE
       ↓
Procedure removed
       ↓
Cannot call that procedure
```

---

## 2. Syntax

### Question:

What is the syntax for deleting a Stored Procedure?

### Answer / Syntax:

```sql
DROP PROCEDURE procedure_name;
```

The procedure name is the name of the procedure that you want to remove.

---

## 3. Example

Suppose the procedure created earlier is named `hike_sal`.

### Question:

How can you delete the `hike_sal` Stored Procedure?

### Answer / Query:

```sql
DROP PROCEDURE hike_sal;
```

### Explanation:

Here:

| Part        | Meaning                                  |
| ----------- | ---------------------------------------- |
| `DROP`      | Removes the database object              |
| `PROCEDURE` | Specifies that the object is a procedure |
| `hike_sal`  | Name of the procedure                    |
| `;`         | Ends the SQL statement                   |

After executing this command, the `hike_sal` procedure is deleted.

---

## 4. Complete Procedure Lifecycle

A Stored Procedure can be understood in three main steps:

```text
CREATE
  ↓
Procedure is created and stored
  ↓
CALL
  ↓
Procedure is executed
  ↓
DROP
  ↓
Procedure is deleted
```

### Step 1 — Create

### Question:

Create a procedure named `hike_sal`.

### Answer / Query:

```sql
CREATE PROCEDURE hike_sal(sal IN NUMBER, did IN NUMBER)
AS
BEGIN
    UPDATE emp1
    SET salary = salary + sal
    WHERE dept_id = did;
END;
```

### Step 2 — Call

### Question:

Call `hike_sal` with `2000` as salary increase and `22` as department ID.

### Answer / Query:

```sql
BEGIN
    hike_sal(2000, 22);
END;
```

### Step 3 — Delete

### Question:

Delete the `hike_sal` Stored Procedure.

### Answer / Query:

```sql
DROP PROCEDURE hike_sal;
```

---

## 5. What happens after DROP?

Before deletion:

```text
Database
   ↓
hike_sal procedure
   ↓
Can be called
```

After:

```sql
DROP PROCEDURE hike_sal;
```

the procedure is removed:

```text
Database
   ↓
hike_sal procedure ❌
```

So attempting to call the deleted procedure will not work because the procedure no longer exists.

---

## 6. DROP PROCEDURE vs DROP TABLE

| `DROP PROCEDURE`               | `DROP TABLE`               |
| ------------------------------ | -------------------------- |
| Deletes a Stored Procedure     | Deletes a table            |
| Syntax: `DROP PROCEDURE name;` | Syntax: `DROP TABLE name;` |
| Removes the procedure object   | Removes the table object   |

---

## 7. Important Point

Do not confuse:

```sql
DROP PROCEDURE hike_sal;
```

with:

```sql
DROP TABLE hike_sal;
```

The first removes a **procedure**.

The second attempts to remove a **table** named `hike_sal`.

## 8. Interview Questions

### Q1. How do you delete a Stored Procedure?

**Answer:**

```sql
DROP PROCEDURE procedure_name;
```

### Q2. How do you delete the `hike_sal` procedure?

**Answer:**

```sql
DROP PROCEDURE hike_sal;
```

### Q3. What happens after dropping a Stored Procedure?

**Answer:**
The procedure is removed from the database and can no longer be called.

### Q4. Which command is used to remove a Stored Procedure?

**Answer:**
`DROP PROCEDURE`

### Q5. What is the difference between calling and deleting a Stored Procedure?

**Answer:**

```text
CALL → Execute the procedure

DROP → Remove the procedure
```

```text
CREATE → CALL → DROP
   ↓       ↓      ↓
Create   Execute  Delete
```
