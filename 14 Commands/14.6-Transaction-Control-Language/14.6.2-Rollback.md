# 14.6.2-Rollback

## 1. What is ROLLBACK?

`ROLLBACK` is a **TCL (Transaction Control Language)** command.

It is used to **undo DML actions that have not been permanently saved in the database**. 

DML commands include:

* `INSERT`
* `UPDATE`
* `DELETE`

### Simple idea

```text
DML operation
     ↓
Changes made
     ↓
ROLLBACK
     ↓
Changes undone
```

---

## 2. Why do we need ROLLBACK?

Suppose we perform an `INSERT`, `UPDATE`, or `DELETE` operation and then realize that the change should not be kept.

`ROLLBACK` allows us to **undo the changes that have not been permanently saved**.

```text
INSERT / UPDATE / DELETE
          ↓
      Mistake found
          ↓
       ROLLBACK
          ↓
    Undo the changes
```

---

## 3. Syntax

### Question:

**What is the syntax of the ROLLBACK command?**

### Answer / Query:

```sql
ROLLBACK;
```

This is used to undo the applicable uncommitted DML actions. 

---

## 4. ROLLBACK TO SAVEPOINT

There is another form of ROLLBACK.

### Question:

**How do you roll back a transaction to a particular savepoint?**

### Answer / Query:

```sql
ROLLBACK TO savepoint_name;
```



For example, if the savepoint is named `x`:

### Question:

**How do you roll back to savepoint `x`?**

### Answer / Query:

```sql
ROLLBACK TO x;
```

This returns the transaction to the specified savepoint.

---

# 5. ROLLBACK with INSERT

### Question:

**How can an INSERT operation be undone using ROLLBACK?**

### Answer / Query:

```sql
INSERT INTO demo1 VALUES(1, 'A', 22);

ROLLBACK;
```

### Flow

```text
INSERT
  ↓
Row inserted
  ↓
ROLLBACK
  ↓
Uncommitted INSERT is undone
```

---

# 6. ROLLBACK After COMMIT

### Question:

**What happens when COMMIT is performed before ROLLBACK?**

### Answer / Query:

```sql
INSERT INTO demo1 VALUES(1, 'A', 22);

COMMIT;

ROLLBACK;
```

### Understanding

```text
INSERT
  ↓
COMMIT
  ↓
Permanently saved
  ↓
ROLLBACK
  ↓
Cannot undo that committed change
```

The important point is that `ROLLBACK` is used for DML actions that **have not been permanently saved**. 

---

# 7. ROLLBACK TO SAVEPOINT

### Question:

**How can a transaction return to a temporary savepoint?**

### Answer / Query:

```sql
INSERT INTO demo1 VALUES(4, 'D', 24);

SAVEPOINT x;

INSERT INTO demo1 VALUES(5, 'P', 25);

ROLLBACK TO x;
```



### Step-by-step

```text
INSERT row 4
     ↓
SAVEPOINT x
     ↓
INSERT row 5
     ↓
ROLLBACK TO x
     ↓
Return to point x
```

So the change made after savepoint `x` is undone.

---

# 8. Complete Transaction Example

### Question:

**How are INSERT, COMMIT, SAVEPOINT, and ROLLBACK used together in a transaction?**

### Answer / Query:

```sql
INSERT INTO demo1 VALUES(1, 'A', 22);

INSERT INTO demo1 VALUES(2, 'B', 23);

INSERT INTO demo1 VALUES(3, 'C', 23);

COMMIT;

INSERT INTO demo1 VALUES(4, 'D', 24);

SAVEPOINT x;

INSERT INTO demo1 VALUES(5, 'P', 25);

ROLLBACK TO x;

ROLLBACK;
```



### Understanding the sequence

| Step | Operation       | Meaning                                       |
| ---- | --------------- | --------------------------------------------- |
| 1    | INSERT row 1    | Insert data                                   |
| 2    | INSERT row 2    | Insert data                                   |
| 3    | INSERT row 3    | Insert data                                   |
| 4    | `COMMIT`        | Permanently save previous DML                 |
| 5    | INSERT row 4    | New DML operation                             |
| 6    | `SAVEPOINT x`   | Create temporary point                        |
| 7    | INSERT row 5    | New DML operation                             |
| 8    | `ROLLBACK TO x` | Return to savepoint `x`                       |
| 9    | `ROLLBACK`      | Undo remaining applicable uncommitted changes |

# 9. COMMIT vs ROLLBACK

### Question:

**What is the difference between COMMIT and ROLLBACK?**

| COMMIT                        | ROLLBACK                                          |
| ----------------------------- | ------------------------------------------------- |
| Saves DML changes permanently | Undoes DML changes that are not permanently saved |
| Used to save changes          | Used to undo changes                              |
| `COMMIT;`                     | `ROLLBACK;`                                       |



### Memory trick

```text
COMMIT
  ↓
SAVE

ROLLBACK
  ↓
UNDO
```

---

# 10. ROLLBACK vs ROLLBACK TO

### Question:

**What is the difference between `ROLLBACK` and `ROLLBACK TO savepoint_name`?**

| `ROLLBACK`                                | `ROLLBACK TO savepoint_name`        |
| ----------------------------------------- | ----------------------------------- |
| Rolls back applicable uncommitted changes | Rolls back to a specified savepoint |
| `ROLLBACK;`                               | `ROLLBACK TO x;`                    |

---

# 11. Important Rules

### Rule 1

`ROLLBACK` is a **TCL command**, not a DML command.

### Rule 2

It is used along with DML operations.

### Rule 3

It undoes DML actions that have **not been permanently saved**. 

### Rule 4

A savepoint can be used as a specific rollback point.

```sql
ROLLBACK TO x;
```
