# 16.6.2-Creating-a-Sequence

## 1. What does Creating a Sequence mean?

Creating a Sequence means **creating a database object that can generate automatic numbers**.

For example, if we want numbers like:

```text
1
2
3
4
5
...
```

we can create a Sequence that generates them automatically.

---

## 2. Syntax

### Question:

What is the syntax for creating a Sequence?

### Answer / Syntax:

```sql
CREATE SEQUENCE sequence_name
START WITH start_value
INCREMENT BY increment_value;
```

### Meaning of each part

| Part              | Meaning                               |
| ----------------- | ------------------------------------- |
| `CREATE SEQUENCE` | Creates a Sequence                    |
| `sequence_name`   | Name given to the Sequence            |
| `START WITH`      | Starting value                        |
| `start_value`     | Number from which the Sequence starts |
| `INCREMENT BY`    | Amount by which the value increases   |
| `increment_value` | Increase amount                       |

---

# 3. Creating the `Dec` Sequence

### Question:

Create a Sequence named `Dec` that starts with `1` and increments by `1`.

### Answer / Query:

```sql
CREATE SEQUENCE Dec
START WITH 1
INCREMENT BY 1;
```

### Explanation

Here:

```text
Dec
 ↓
Sequence name
```

```text
START WITH 1
      ↓
Starting value = 1
```

```text
INCREMENT BY 1
      ↓
Increase by 1
```

So the Sequence will generate values like:

```text
1 → 2 → 3 → 4 → 5 → ...
```

The creation example uses `Dec`, `START WITH 1`, and `INCREMENT BY 1`. 

---

# 4. Understanding `START WITH`

`START WITH` tells Oracle **where the Sequence should begin**.

### Question:

Create a Sequence named `Dec` starting from `1`.

### Answer / Query:

```sql
CREATE SEQUENCE Dec
START WITH 1
INCREMENT BY 1;
```

The starting value is:

```text
1
```

Therefore, the first generated value will begin from the specified starting point.

---

# 5. Understanding `INCREMENT BY`

`INCREMENT BY` tells Oracle **how much the Sequence should increase**.

In the example:

```sql
INCREMENT BY 1
```

the values increase by `1`.

Conceptually:

```text
1
↓ +1
2
↓ +1
3
↓ +1
4
```

---

# 6. Sequence Creation Flow

```text
CREATE SEQUENCE Dec
        ↓
START WITH 1
        ↓
First value = 1
        ↓
INCREMENT BY 1
        ↓
Next values increase by 1
```

So:

```text
1 → 2 → 3 → 4 → 5 → ...
```

---

# 7. Important Point

Creating a Sequence **only creates the Sequence object**.

The generated number can later be used while inserting data into a table using `NEXTVAL`.

For example, the Sequence can be used like:

```text
Dec.nextval
```

The actual use of a Sequence with `INSERT` is covered separately.

---

# 8. Important Rules to Remember

### Rule 1

`CREATE SEQUENCE` is used to create a Sequence.

### Rule 2

`START WITH` specifies the starting value.

### Rule 3

`INCREMENT BY` specifies the increase.

### Rule 4

The Sequence gets a name.

For example:

```text
Sequence name = Dec
```

### Rule 5

The Sequence is a **database object**.

---

# 9. Common Confusion

### `START WITH` vs `INCREMENT BY`

| `START WITH`            | `INCREMENT BY`             |
| ----------------------- | -------------------------- |
| Tells where to start    | Tells how much to increase |
| Example: `START WITH 1` | Example: `INCREMENT BY 1`  |
| Starting value          | Increase value             |

### Easy memory:

```text
START WITH → Where do I START?

INCREMENT BY → How much do I INCREASE?
```

# 10. Interview Questions

### Q1. Which command is used to create a Sequence?

**Answer:**

```sql
CREATE SEQUENCE
```

### Q2. What does `START WITH` specify?

**Answer:**
It specifies the starting value of the Sequence.

### Q3. What does `INCREMENT BY` specify?

**Answer:**
It specifies the amount by which the Sequence value increases.

### Q4. Write the syntax for creating a Sequence.

**Answer:**

```sql
CREATE SEQUENCE sequence_name
START WITH start_value
INCREMENT BY increment_value;
```
