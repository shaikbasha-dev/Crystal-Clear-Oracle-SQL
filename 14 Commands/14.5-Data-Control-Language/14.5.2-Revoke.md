# 14.5.2-Revoke

## 1. What is REVOKE?

`REVOKE` is a **DCL command**.

It is used to **take back a privilege/permission from a user**. 

### Simple meaning

If `GRANT` means:

> **Give permission**

then `REVOKE` means:

> **Take back permission**

```text
GRANT
  ↓
Give permission

REVOKE
  ↓
Take back permission
```

---

## 2. Why do we need REVOKE?

Suppose a user has permission to access the `emp` table.

Later, we decide that the user should **no longer have that permission**.

We can use `REVOKE`.

```text
User
  ↓
Has permission
  ↓
REVOKE
  ↓
Permission removed
```

---

# 3. Syntax of REVOKE

### Question:

**What is the syntax of the REVOKE command?**

### Answer / Query:

```sql
REVOKE [Privilege]
ON table_name
FROM user_name;
```



### Meaning of each part

| Part          | Meaning                                  |
| ------------- | ---------------------------------------- |
| `REVOKE`      | Take back permission                     |
| `[Privilege]` | Permission being removed                 |
| `ON`          | Specifies the database object            |
| `table_name`  | Name of the table                        |
| `FROM`        | Specifies the user losing the permission |
| `user_name`   | Name of the user                         |

---

# 4. Example of REVOKE

### Question:

**How do you remove SELECT permission on the `emp` table from the user `December`?**

### Answer / Query:

```sql
REVOKE SELECT
ON emp
FROM December;
```

### Step-by-step

```text
REVOKE
   ↓
Take back

SELECT
   ↓
SELECT permission

ON emp
   ↓
From EMP table

FROM December
   ↓
From DECEMBER user
```

So the complete meaning is:

> **Take back SELECT permission on the EMP table from DECEMBER.**

---

# 5. GRANT and REVOKE Together

### Question:

**How do you first give SELECT permission on EMP to DECEMBER and then take that permission back?**

### Answer / Query:

```sql
GRANT SELECT
ON emp
TO December;

REVOKE SELECT
ON emp
FROM December;
```

### Flow

```text
GRANT
  ↓
December gets SELECT permission
  ↓
REVOKE
  ↓
December loses SELECT permission
```

---

# 6. Complete User Example

### Question:

**How do you create the user `December`, give SELECT permission on EMP, remove that permission, and then delete the user?**

### Answer / Query:

```sql
CREATE USER December IDENTIFIED BY December;

GRANT SELECT
ON emp
TO December;

REVOKE SELECT
ON emp
FROM December;

DROP USER December;
```

The sequence demonstrates user creation, granting a privilege, revoking the privilege, and deleting the user. 

---

# 7. Important Difference: GRANT vs REVOKE

| GRANT                              | REVOKE                                |
| ---------------------------------- | ------------------------------------- |
| Gives permission                   | Takes back permission                 |
| `TO` is used                       | `FROM` is used                        |
| `GRANT SELECT ON emp TO December;` | `REVOKE SELECT ON emp FROM December;` |

### Memory trick

```text
GRANT  → TO
REVOKE → FROM
```

---

# 8. Common Mistake

### ❌ Wrong

```sql
REVOKE SELECT ON emp TO December;
```

### ✅ Correct

```sql
REVOKE SELECT ON emp FROM December;
```

`REVOKE` uses **`FROM`**, not `TO`. 

---

# 9. GRANT vs REVOKE — Easy Example

Imagine a teacher gives a student permission to enter a laboratory.

```text
GRANT
Teacher → Gives permission
```

Later, the teacher removes that permission.

```text
REVOKE
Teacher → Takes permission back
```

So:

> **GRANT = Give**
> **REVOKE = Take back**

# 10. Interview Questions

### Q1. What is REVOKE?

**Answer:**

> REVOKE is a DCL command used to take back a privilege or permission from a user.

### Q2. What is the purpose of REVOKE?

**Answer:**

> It is used to remove a previously granted privilege from a user.

### Q3. Which keyword is used with REVOKE to specify the user?

**Answer:**

> `FROM`.

### Q4. Write the syntax of REVOKE.

**Answer:**

```sql
REVOKE [Privilege]
ON table_name
FROM user_name;
```

### Q5. Write a query to revoke SELECT permission on EMP from DECEMBER.

**Answer:**

```sql
REVOKE SELECT
ON emp
FROM December;
```

### Q6. What is the difference between GRANT and REVOKE?

**Answer:**

> GRANT gives privileges to a user, whereas REVOKE takes those privileges back.
