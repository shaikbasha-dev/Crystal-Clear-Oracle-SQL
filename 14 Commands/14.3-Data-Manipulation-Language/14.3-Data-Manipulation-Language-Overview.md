# 14.3-Data-Manipulation-Language-Overview

## 1. What is DML?

**DML** stands for **Data Manipulation Language**.

DML commands are used to **manipulate the data stored in a table**.

The DML commands are:

```text
DML
│
├── INSERT
├── UPDATE
└── DELETE
```

These commands work with the **rows of a table**.

---

## 2. Why do we need DML?

Creating a table only creates its **structure**.

For example:

```text
BANK
├── BID
├── BNAME
└── BHQ
```

To actually put data into the table, change existing data, or remove data, we use DML.

```text
CREATE
  ↓
Creates table structure
  ↓
DML
  ↓
Manipulates table data
```

---

# 3. Three DML Commands

| Command  | Purpose               |
| -------- | --------------------- |
| `INSERT` | Adds data as new rows |
| `UPDATE` | Changes existing data |
| `DELETE` | Removes rows          |

---

## 4. INSERT

`INSERT` is used to **insert data into a table as rows**.

### Question

**How do you insert data into a table?**

### Syntax

```sql
INSERT INTO table_name
VALUES(value1, value2, value3);
```

Another form:

```sql
INSERT INTO table_name(column1, column2)
VALUES(value1, value2);
```

### Example

### Question

**Insert `State bank`, `Hyderabad`, and `1` into the `Bank` table.**

### Query

```sql
INSERT INTO Bank
VALUES('State bank', 'Hyderabad', 1);
```

This adds a new row to the table.

---

# 5. UPDATE

`UPDATE` is used to **update or change values in the columns of a table**.

### Question

**Change the bank name from `Axis bank` to `Bank of Baroda`.**

### Query

```sql
UPDATE Bank
SET Bname = 'Bank of Baroda'
WHERE Bname = 'Axis bank';
```

Here:

```text
UPDATE
  ↓
Find the required row using WHERE
  ↓
Change the required column value
```

---

# 6. DELETE

`DELETE` is used to **remove rows from a table**.

There are two forms.

### Question

**Delete the row from `Bank` where the bank name is `State bank`.**

### Query

```sql
DELETE FROM Bank
WHERE Bname = 'State bank';
```

This removes the matching row.

---

### Question

**Delete all rows from the `Bank` table.**

### Query

```sql
DELETE FROM Bank;
```

Without a `WHERE` condition, all rows are targeted.

---

# 7. DML Commands at a Glance

```text
                 DML
                  │
       ┌──────────┼──────────┐
       ↓          ↓          ↓
    INSERT      UPDATE     DELETE
       │          │          │
       ↓          ↓          ↓
   Add rows    Change      Remove
               values       rows
```

---

# 8. DML and Rows

The important idea is:

> **DML commands operate with respect to the rows of a table.**

For example:

```text
INSERT  → adds rows
UPDATE  → changes data in rows
DELETE  → removes rows
```

---

# 9. DML Actions Are Not Permanent

DML actions are not permanent immediately.

The changes can be made permanent using the **Transaction Control Language (TCL)** commands.

The important TCL commands are:

```text
COMMIT
ROLLBACK
SAVEPOINT
```

### Question

**Which command is used to make DML actions permanent?**

### Answer

`COMMIT`.

### Example

### Question

**Insert a record into `Bank` and make the insertion permanent.**

### Query

```sql
INSERT INTO Bank
VALUES('State bank', 'Hyderabad', 1);

COMMIT;
```

The basic flow is:

```text
INSERT / UPDATE / DELETE
          ↓
     DML operation
          ↓
       COMMIT
          ↓
   Change becomes permanent
```

---

# 10. DDL vs DML

This is an important interview difference.

| DDL                               | DML                        |
| --------------------------------- | -------------------------- |
| Data Definition Language          | Data Manipulation Language |
| Deals mainly with table structure | Deals with table data      |
| `CREATE`                          | `INSERT`                   |
| `ALTER`                           | `UPDATE`                   |
| `TRUNCATE`                        | `DELETE`                   |
| `DROP`                            |                            |

### Easy Memory Trick

> **DDL → Define the structure**
> **DML → Manipulate the data**

---

# 11. INSERT vs UPDATE vs DELETE

| Requirement               | Command                  |
| ------------------------- | ------------------------ |
| Add a new row             | `INSERT`                 |
| Change existing data      | `UPDATE`                 |
| Remove a row              | `DELETE`                 |
| Remove all rows using DML | `DELETE` without `WHERE` |

### Example flow

```text
Table
 ↓
INSERT
 ↓
New row added
 ↓
UPDATE
 ↓
Existing value changed
 ↓
DELETE
 ↓
Row removed
```

---

# 12. Important Points

1. **DML = Data Manipulation Language**
2. DML is used to manipulate data.
3. DML works with the **rows** of a table.
4. The three DML commands are:

   * `INSERT`
   * `UPDATE`
   * `DELETE`
5. `INSERT` adds rows.
6. `UPDATE` changes existing values.
7. `DELETE` removes rows.
8. DML actions are not permanent immediately.
9. `COMMIT` is used to make DML actions permanent.
