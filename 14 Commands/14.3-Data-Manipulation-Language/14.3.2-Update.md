# 14.3.2-Update

## 1. What is UPDATE?

`UPDATE` is a **DML (Data Manipulation Language) command**.

It is used to **update or change values in the columns of a table**.

Simple idea:

```text
Existing Data
     ↓
   UPDATE
     ↓
Changed Data
```

For example:

```text
Axis bank
   ↓
UPDATE
   ↓
Bank of Baroda
```

---

# 2. Why do we need UPDATE?

Suppose a table already contains:

| BNAME     | BHQ       | BID |
| --------- | --------- | --: |
| Axis bank | Hyderabad |   1 |
| SBI       | Delhi     |   2 |

Later, we want to change:

```text
Axis bank
     ↓
Bank of Baroda
```

We don't need to delete the row and insert it again.

We can directly change the existing value using `UPDATE`.

---

# 3. Syntax

### Question

**What is the syntax for updating a value in a table?**

### Syntax

```sql
UPDATE table_name
SET column_name = 'new_value'
WHERE condition;
```

The structure is:

```text
UPDATE
   ↓
Which table?
   ↓
SET
   ↓
Which column?
   ↓
New value
   ↓
WHERE
   ↓
Which row?
```

---

# 4. Syntax Explanation

| Part          | Meaning                                        |
| ------------- | ---------------------------------------------- |
| `UPDATE`      | Specifies that existing data must be changed   |
| `table_name`  | Name of the table                              |
| `SET`         | Specifies the new value                        |
| `column_name` | Column whose value must be changed             |
| `'new_value'` | New value                                      |
| `WHERE`       | Specifies which row(s) should be updated       |
| `condition`   | Condition used to identify the required row(s) |

---

# 5. Example

### Question

**Update the bank name from `Axis bank` to `Bank of Baroda` in the `Bank` table.**

### Query

```sql
UPDATE Bank
SET Bname = 'Bank of Baroda'
WHERE Bname = 'Axis bank';
```

This is the UPDATE example given for this command. 

---

# 6. Step-by-Step Execution

Suppose the table contains:

| BNAME     | BHQ       | BID |
| --------- | --------- | --: |
| Axis bank | Hyderabad |   1 |
| SBI       | Delhi     |   2 |
| HDFC      | Mumbai    |   3 |

We want to change `Axis bank` to `Bank of Baroda`.

### Step 1 — Choose the table

```text
Bank
```

### Step 2 — Identify the column to change

```text
Bname
```

### Step 3 — Give the new value

```text
Bank of Baroda
```

### Step 4 — Identify the row

```text
Bname = 'Axis bank'
```

### Complete Query

```sql
UPDATE Bank
SET Bname = 'Bank of Baroda'
WHERE Bname = 'Axis bank';
```

### Before

| BNAME     | BHQ       | BID |
| --------- | --------- | --: |
| Axis bank | Hyderabad |   1 |
| SBI       | Delhi     |   2 |
| HDFC      | Mumbai    |   3 |

### After

| BNAME          | BHQ       | BID |
| -------------- | --------- | --: |
| Bank of Baroda | Hyderabad |   1 |
| SBI            | Delhi     |   2 |
| HDFC           | Mumbai    |   3 |

Only the matching value is changed.

---

# 7. Importance of WHERE

`WHERE` is very important when we want to update **particular rows**.

### Question

**Change the bank name `Axis bank` to `Bank of Baroda` only for the matching row.**

### Query

```sql
UPDATE Bank
SET Bname = 'Bank of Baroda'
WHERE Bname = 'Axis bank';
```

The `WHERE` condition identifies which row should be changed.

```text
WHERE Bname = 'Axis bank'
              ↓
       Find this row
              ↓
SET Bname = 'Bank of Baroda'
              ↓
       Change its value
```

---

# 8. UPDATE Without WHERE

If `WHERE` is not used, the update applies to **all rows**.

### Question

**Change the `Bname` value to `Bank of Baroda` for every row in the `Bank` table.**

### Query

```sql
UPDATE Bank
SET Bname = 'Bank of Baroda';
```

Every row's `Bname` value will be changed.

### Before

| BNAME     |
| --------- |
| Axis bank |
| SBI       |
| HDFC      |

### After

| BNAME          |
| -------------- |
| Bank of Baroda |
| Bank of Baroda |
| Bank of Baroda |

### Important

> **Be careful when using UPDATE without WHERE.**

It affects all rows.

---

# 9. UPDATE Multiple Columns

The `SET` clause can be used to change column values.

### Question

**Update the `Bname` and `BHQ` values of the row where `BID = 1`.**

### Query

```sql
UPDATE Bank
SET Bname = 'Bank of Baroda',
    BHQ = 'Mumbai'
WHERE BID = 1;
```

Here two columns are changed:

```text
Bname → Bank of Baroda
BHQ   → Mumbai
```

---

# 10. UPDATE vs INSERT

| UPDATE                   | INSERT            |
| ------------------------ | ----------------- |
| Changes existing data    | Adds new data     |
| Works with existing rows | Creates a new row |
| Uses `UPDATE`            | Uses `INSERT`     |

### UPDATE

### Question

**Change `Axis bank` to `Bank of Baroda`.**

### Query

```sql
UPDATE Bank
SET Bname = 'Bank of Baroda'
WHERE Bname = 'Axis bank';
```

### INSERT

### Question

**Add a new bank record.**

### Query

```sql
INSERT INTO Bank
VALUES('State bank', 'Hyderabad', 1);
```

---

# 11. UPDATE vs DELETE

| UPDATE         | DELETE         |
| -------------- | -------------- |
| Changes values | Removes rows   |
| Row remains    | Row is removed |
| Uses `UPDATE`  | Uses `DELETE`  |

### UPDATE

### Question

**Change the bank name `Axis bank` to `Bank of Baroda`.**

### Query

```sql
UPDATE Bank
SET Bname = 'Bank of Baroda'
WHERE Bname = 'Axis bank';
```

### DELETE

### Question

**Delete the bank whose name is `State bank`.**

### Query

```sql
DELETE FROM Bank
WHERE Bname = 'State bank';
```

---

# 12. UPDATE and COMMIT

`UPDATE` is a DML operation.

DML actions are not permanent until they are committed.

### Question

**Update the bank name and make the change permanent.**

### Query

```sql
UPDATE Bank
SET Bname = 'Bank of Baroda'
WHERE Bname = 'Axis bank';

COMMIT;
```

The flow is:

```text
UPDATE
   ↓
Existing value changed
   ↓
COMMIT
   ↓
Change made permanent
```

# 13. Common Mistakes

### Mistake 1 — Forgetting SET

❌

```sql
UPDATE Bank
Bname = 'Bank of Baroda'
WHERE Bname = 'Axis bank';
```

✅

```sql
UPDATE Bank
SET Bname = 'Bank of Baroda'
WHERE Bname = 'Axis bank';
```

---

### Mistake 2 — Forgetting WHERE

If you intend to update only one particular row:

❌

```sql
UPDATE Bank
SET Bname = 'Bank of Baroda';
```

This updates every row.

✅

```sql
UPDATE Bank
SET Bname = 'Bank of Baroda'
WHERE Bname = 'Axis bank';
```

---

### Mistake 3 — Forgetting quotes around character data

❌

```sql
UPDATE Bank
SET Bname = Bank of Baroda
WHERE Bname = Axis bank;
```

✅

```sql
UPDATE Bank
SET Bname = 'Bank of Baroda'
WHERE Bname = 'Axis bank';
```

---

# 14. Important Points

1. `UPDATE` is a **DML command**.
2. It changes existing values in a table.
3. `SET` specifies the new value.
4. `WHERE` identifies the row(s) to update.
5. Without `WHERE`, all rows are updated.
6. Multiple columns can be updated using `SET`.
7. `COMMIT` can be used to make the DML change permanent.
