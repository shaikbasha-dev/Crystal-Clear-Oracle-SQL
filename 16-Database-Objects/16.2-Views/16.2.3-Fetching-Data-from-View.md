# 16.2.3-Fetching-Data-from-View

## 1. What does Fetching Data from a View mean?

After creating a View, we can **retrieve the data from that View** using a `SELECT` statement.

Think of it simply:

```text id="q7h4nf"
EMP TABLE
    ↓
CREATE VIEW
    ↓
   DEC
    ↓
SELECT data from DEC
```

A View can be queried to retrieve the data represented by it.

---

## 2. Syntax

### Question:

What is the syntax for fetching data from a View?

### Answer / Query:

```sql id="5wq5v7"
SELECT * FROM view_name;
```

Here:

* `SELECT *` → retrieves all columns available through the View.
* `FROM view_name` → specifies the View from which we want the data.



---

# 3. Fetch Data from the `dec` View

Earlier, we created the View `dec`:

```sql id="h8n8m3"
CREATE VIEW dec
AS
SELECT f_name, salary, dept_id
FROM emp
WHERE dept_id = 22;
```

Now we want to retrieve its data.

### Question:

How do you fetch all the data from the `dec` View?

### Answer / Query:

```sql id="5m9f8v"
SELECT * FROM dec;
```

### Query Explanation:

* `SELECT *` → asks Oracle to display all columns available in the View.
* `FROM dec` → tells Oracle to retrieve the data from the View named `dec`.

### Output:

The output contains the columns defined in the View:

| f_name        | salary | dept_id |
| ------------- | -----: | ------: |
| Employee name | Salary |      22 |
| Employee name | Salary |      22 |
| Employee name | Salary |      22 |

The actual rows depend on the data present in `emp`.

---

# 4. Important Point About the Example

The example shown for **Fetching the data** is:

### Question:

Fetch the data.

### Query shown:

```sql id="h0p5wl"
SELECT * FROM emp;
```



### Important correction

If the intention is specifically to **fetch data from the View `dec`**, the query should be:

```sql id="7akxqf"
SELECT * FROM dec;
```

because `emp` is the original table, whereas `dec` is the View created earlier.

---

# 5. View vs Original Table

Suppose:

```text id="6gdq1p"
EMP
 │
 │ CREATE VIEW
 ↓
DEC
```

Then:

### Question:

Fetch data from the original `emp` table.

### Query:

```sql id="qv4k0w"
SELECT * FROM emp;
```

This retrieves data directly from the **actual table**.

### Question:

Fetch data from the `dec` View.

### Query:

```sql id="r7w6hc"
SELECT * FROM dec;
```

This retrieves data through the **View**.

---

# 6. What will we get from `dec`?

The View was created using:

```sql id="7d0o2p"
SELECT f_name, salary, dept_id
FROM emp
WHERE dept_id = 22;
```

Therefore, when we execute:

```sql id="d5tqyv"
SELECT * FROM dec;
```

we get:

```text id="q6d9be"
f_name
salary
dept_id
```

for the employees satisfying:

```text id="6xw3ob"
dept_id = 22
```

So the View gives us the **result defined by its underlying query**.

# 7. Simple Flow to Remember

```text id="2xv5h6"
CREATE VIEW
     ↓
   dec
     ↓
SELECT * FROM dec;
     ↓
Data from View
```

### Very important:

```sql id="c1r7h9"
SELECT * FROM emp;
```

➡️ Fetches from the **table**

```sql id="4j5g0a"
SELECT * FROM dec;
```

➡️ Fetches from the **View**

# 8. Interview Questions

### Q1. How do you fetch data from a View?

**Answer:**

```sql id="y4c7v5"
SELECT * FROM view_name;
```

### Q2. Can we use `SELECT` on a View?

**Answer:**
Yes. A View can be queried using `SELECT`.

### Q3. If the View name is `dec`, how do you fetch its data?

**Answer:**

```sql id="2d6y2c"
SELECT * FROM dec;
```

### Q4. What is the difference between these two queries?

```sql id="j9k5g8"
SELECT * FROM emp;
```

and

```sql id="4h4t6w"
SELECT * FROM dec;
```

**Answer:**

* `SELECT * FROM emp;` → fetches directly from the `emp` table.
* `SELECT * FROM dec;` → fetches through the `dec` View.

## 9. One-Line Memory Trick

> **Create View → `CREATE VIEW`**
> **Fetch View Data → `SELECT * FROM view_name`**

```text id="y2yq2r"
CREATE VIEW dec
       ↓
SELECT * FROM dec;
       ↓
View Data
```
