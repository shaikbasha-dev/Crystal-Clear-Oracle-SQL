# 16.6.4-NEXTVAL

## 1. What is `NEXTVAL`?

`NEXTVAL` is used with a **Sequence** to generate the **next value** of that Sequence.

### Simple idea

Suppose we have a Sequence that starts at `1` and increments by `1`:

```text
NEXTVAL
   ↓
1
```

Next time:

```text
NEXTVAL
   ↓
2
```

Then:

```text
NEXTVAL
   ↓
3
```

So the basic idea is:

> **`NEXTVAL` → generates the next value of a Sequence.**

---

## 2. Why do we use `NEXTVAL`?

When we need automatic numbers, we don't want to manually enter:

```text
1
2
3
4
5
```

Instead, the Sequence can generate the values.

```text
Sequence
   ↓
NEXTVAL
   ↓
Next number
```

This is especially useful when inserting records into a table.

---

# 3. Syntax

### Question:

How do you refer to the next value of a Sequence?

### Answer / Syntax:

```sql
sequence_name.NEXTVAL
```

For the Sequence named `Dec`:

```sql
Dec.NEXTVAL
```

---

# 4. Example Sequence

Suppose we create the following Sequence.

### Question:

Create a Sequence named `Dec` starting from `1` and increasing by `1`.

### Answer / Query:

```sql
CREATE SEQUENCE Dec
START WITH 1
INCREMENT BY 1;
```

Now the Sequence is ready to generate values.

```text
Dec
 ↓
NEXTVAL
```

---

# 5. First `NEXTVAL`

### Question:

What happens when `NEXTVAL` is used for the first time with the `Dec` Sequence?

### Answer:

```sql
Dec.NEXTVAL
```

The Sequence generates:

```text
1
```

Because the Sequence was created with:

```text
START WITH 1
```

---

# 6. Second `NEXTVAL`

### Question:

What value is generated when `NEXTVAL` is used again with `Dec`?

### Answer:

```sql
Dec.NEXTVAL
```

The next value is:

```text
2
```

Because:

```text
Previous value = 1
Increment = 1

1 + 1 = 2
```

---

# 7. Third `NEXTVAL`

### Question:

What value is generated by the third use of `Dec.NEXTVAL`?

### Answer:

```sql
Dec.NEXTVAL
```

The generated value is:

```text
3
```

Therefore:

```text
1st NEXTVAL → 1
2nd NEXTVAL → 2
3rd NEXTVAL → 3
4th NEXTVAL → 4
...
```

---

# 8. Using `NEXTVAL` with INSERT

A Sequence's generated number can be used while inserting data into a table.

The form given for using a Sequence is:

### Question:

How can a Sequence's next value be used while inserting a value into a table?

### Answer / Syntax:

```sql
INSERT INTO table_name
VALUES(sequence_name.NEXTVAL, 'value');
```

The Sequence usage pattern is `sequence_name.nextval` inside an `INSERT`. 

---

# 9. Example from the Sequence

Suppose there is a table named `demo` with two columns:

```text
ID    NAME
```

And the Sequence is named `Dec`.

### Question:

Insert `Sachin` into the `demo` table using the next value of the `Dec` Sequence.

### Answer / Query:

```sql
INSERT INTO demo
VALUES(Dec.NEXTVAL, 'Sachin');
```

If the next Sequence value is `1`, the inserted data is:

| ID | NAME   |
| -: | ------ |
|  1 | Sachin |

---

# 10. Another `NEXTVAL` Example

### Question:

Insert `virat` into the `demo` table using the next value of the `Dec` Sequence.

### Answer / Query:

```sql
INSERT INTO demo
VALUES(Dec.NEXTVAL, 'virat');
```

If the previous `NEXTVAL` generated `1`, this one generates `2`.

Result:

| ID | NAME   |
| -: | ------ |
|  1 | Sachin |
|  2 | virat  |

The examples use `Dec.nextval` to automatically generate the first column value while inserting `Sachin` and `virat`.

# 11. Understanding the Flow

```text
CREATE SEQUENCE Dec
        ↓
START WITH 1
        ↓
INCREMENT BY 1
        ↓
Dec.NEXTVAL
        ↓
1
        ↓
Dec.NEXTVAL
        ↓
2
        ↓
Dec.NEXTVAL
        ↓
3
```

When used with `INSERT`:

```text
Dec.NEXTVAL
     ↓
Automatic number
     ↓
ID column
```

---

# 12. `NEXTVAL` vs `CURRVAL`

| `NEXTVAL`                         | `CURRVAL`                           |
| --------------------------------- | ----------------------------------- |
| Generates the next Sequence value | Gives the current Sequence value    |
| Moves to the next value           | Refers to the current value         |
| Used to generate a new number     | Used to refer to the current number |

### Easy memory:

```text
NEXTVAL
   ↓
NEXT number

CURRVAL
   ↓
CURRENT number
```

---

# 13. Important Points

* `NEXTVAL` is associated with a Sequence.
* It generates the **next value**.
* Syntax:

```text
sequence_name.NEXTVAL
```

* Example:

```text
Dec.NEXTVAL
```

* `NEXTVAL` can be used in an `INSERT` statement to supply an automatically generated number.
* The value generated depends on the Sequence's starting value and increment value.

# 14. Interview Questions

### Q1. What is `NEXTVAL`?

**Answer:**
`NEXTVAL` is used to generate the next value of a Sequence.

### Q2. What is the syntax of `NEXTVAL`?

**Answer:**

```sql
sequence_name.NEXTVAL
```

### Q3. What is `Dec.NEXTVAL`?

**Answer:**
It refers to the next value generated by the Sequence named `Dec`.

### Q4. Can `NEXTVAL` be used with INSERT?

**Answer:**
Yes. It can be used to automatically provide a Sequence-generated value during insertion.

### Q5. What is the difference between `NEXTVAL` and `CURRVAL`?

**Answer:**

```text
NEXTVAL → Next Sequence value
CURRVAL → Current Sequence value
```
