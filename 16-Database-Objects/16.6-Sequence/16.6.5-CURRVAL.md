# 16.6.5-CURRVAL

## 1. What is `CURRVAL`?

`CURRVAL` is used with a **Sequence** to refer to the **current value** of that Sequence.

The two important Sequence keywords are:

```text
NEXTVAL → generates the next value
CURRVAL → gives the current value
```



### Simple example

Suppose a Sequence generates:

```text
1 → 2 → 3 → 4
```

If the current Sequence value is `3`, then:

```text
CURRVAL → 3
```

It does **not** generate a new number.

---

## 2. Why do we use `CURRVAL`?

Sometimes we already generated a Sequence value and want to refer to that **same current value**.

Think of it like this:

```text
NEXTVAL
   ↓
Generates 5
   ↓
Current value = 5
   ↓
CURRVAL
   ↓
5
```

So:

> **`NEXTVAL` moves the Sequence forward; `CURRVAL` refers to the current value.**

---

# 3. Syntax

### Question:

How do you refer to the current value of a Sequence?

### Answer / Syntax:

```sql
sequence_name.CURRVAL
```

For a Sequence named `Dec`:

```sql
Dec.CURRVAL
```

---

# 4. `NEXTVAL` and `CURRVAL` Together

Suppose we have the Sequence:

### Question:

Create a Sequence named `Dec` starting from `1` and increasing by `1`.

### Answer / Query:

```sql
CREATE SEQUENCE Dec
START WITH 1
INCREMENT BY 1;
```

Now suppose `NEXTVAL` generates `1`.

### Question:

Generate the next value of the `Dec` Sequence.

### Answer / Query:

```sql
Dec.NEXTVAL
```

Result:

```text
1
```

Now `1` is the current value.

### Question:

Refer to the current value of the `Dec` Sequence.

### Answer / Query:

```sql
Dec.CURRVAL
```

Result:

```text
1
```

So:

```text
Dec.NEXTVAL
     ↓
     1
     ↓
Current value = 1
     ↓
Dec.CURRVAL
     ↓
     1
```

---

# 5. Important Difference

Suppose the current value is `3`.

### Question:

What happens when `Dec.NEXTVAL` is used?

### Answer:

```text
Dec.NEXTVAL → 4
```

The Sequence moves forward.

But:

### Question:

What happens when `Dec.CURRVAL` is used after the current value is `4`?

### Answer:

```text
Dec.CURRVAL → 4
```

It refers to the current value.

### Remember:

```text
NEXTVAL → NEXT
CURRVAL → CURRENT
```

---

# 6. Example with INSERT

A Sequence can be used with an `INSERT`.

### Question:

Insert `Sachin` into `demo` using the next value of the `Dec` Sequence.

### Answer / Query:

```sql
INSERT INTO demo
VALUES(Dec.NEXTVAL, 'Sachin');
```

Suppose `Dec.NEXTVAL` generates `1`.

The table becomes:

| ID | NAME   |
| -: | ------ |
|  1 | Sachin |

Now the current Sequence value is `1`.

### Question:

What is the current value of the `Dec` Sequence?

### Answer / Query:

```sql
Dec.CURRVAL
```

Result:

```text
1
```

---

# 7. `CURRVAL` Does Not Mean "Generate Next Number"

This is a very important distinction.

Suppose:

```text
Current value = 5
```

### Question:

What value does `Dec.CURRVAL` refer to?

### Answer:

```text
5
```

It does not change the value to `6`.

But:

### Question:

What happens when `Dec.NEXTVAL` is used?

### Answer:

```text
6
```

Therefore:

```text
CURRVAL → 5
NEXTVAL → 6
```

---

# 8. Simple Real-Life Example

Imagine a token counter.

The counter currently shows:

```text
Token = 25
```

If someone asks:

> "What is the current token number?"

That's like:

```text
CURRVAL → 25
```

If the counter gives the next token:

```text
NEXTVAL → 26
```

### Memory:

```text
NEXTVAL → Give me the NEXT number
CURRVAL → Tell me the CURRENT number
```

---

# 9. `NEXTVAL` vs `CURRVAL`

| `NEXTVAL`                                | `CURRVAL`                             |
| ---------------------------------------- | ------------------------------------- |
| Generates the next value                 | Gives the current value               |
| Advances the Sequence                    | Refers to the current Sequence value  |
| Example: `Dec.NEXTVAL`                   | Example: `Dec.CURRVAL`                |
| Used when a new Sequence value is needed | Used when the current value is needed |

---

# 10. Sequence Flow

```text
CREATE SEQUENCE
      ↓
Dec
      ↓
NEXTVAL
      ↓
1
      ↓
CURRVAL
      ↓
1
```

Next time:

```text
NEXTVAL
   ↓
2
   ↓
CURRVAL
   ↓
2
```

Next:

```text
NEXTVAL
   ↓
3
   ↓
CURRVAL
   ↓
3
```

So:

```text
NEXTVAL → changes the Sequence to the next value
CURRVAL → refers to that current value
```

---

# 11. Important Points

* `CURRVAL` is used with a Sequence.
* It represents the **current value** of the Sequence.
* Syntax:

```sql
sequence_name.CURRVAL
```

* Example:

```sql
Dec.CURRVAL
```

* `NEXTVAL` generates the next value.
* `CURRVAL` refers to the current value.
* The two keywords are commonly understood together.
