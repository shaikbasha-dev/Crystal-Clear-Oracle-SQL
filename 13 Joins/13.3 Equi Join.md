# 13.3 Equi Join

## 1. What is an Equi Join?

An **Equi Join** is a type of join where the relationship between two tables is specified using the **equal (`=`) operator**.

The important point is:

> **Equi Join is the same as Inner Join, but the joining condition is written in the `WHERE` clause using `=`.**



---

## 2. Why is it called "Equi" Join?

**Equi** means **equal**.

The joining condition uses:

```sql
=
```

For example:

```sql
WHERE Table1.B = Table2.B
```

Oracle checks whether the value in `Table1.B` is **equal to** the value in `Table2.B`.

---

# 3. Simple Example

Suppose we have:

### Table 1

|  A |  B |
| -: | -: |
|  1 |  2 |
|  3 |  4 |
|  5 |  6 |
|  9 |  8 |

### Table 2

|  B |  C |
| -: | -: |
|  2 |  1 |
|  8 |  1 |
|  9 |  1 |

The common column is `B`.

Oracle compares:

```text
Table1.B = Table2.B
```

### Matching values

```text
2 = 2  ✓
4 = 2  ✗
4 = 8  ✗
6 = 8  ✗
8 = 8  ✓
```

So only the matching rows are returned.

### Result

|  A |  B |  B |  C |
| -: | -: | -: | -: |
|  1 |  2 |  2 |  1 |
|  9 |  8 |  8 |  1 |

---

# 4. Syntax

### Question

**What is the syntax of an Equi Join?**

### Answer / Query

```sql
SELECT */attribute
FROM Table1, Table2
WHERE Table1.B = Table2.B;
```



### Understand it

```sql
SELECT *
```

→ Select all columns.

```sql
FROM Table1, Table2
```

→ Take data from both tables.

```sql
WHERE Table1.B = Table2.B
```

→ Match rows where the values of column `B` are equal.

---

# 5. Equi Join Using EMP and DEPT

The `EMP` and `DEPT` tables have a common column:

```text
DEPT_ID
```

So we can use:

```text
EMP.DEPT_ID = DEPT.DEPT_ID
```

### Question

**Display employee and department information by matching the department ID of EMP with the department ID of DEPT.**

### Answer / Query

```sql
SELECT *
FROM EMP, DEPT
WHERE EMP.DEPT_ID = DEPT.DEPT_ID;
```

### Step-by-step

Oracle takes:

```text
EMP
  ↓
DEPT_ID
```

and compares it with:

```text
DEPT
  ↓
DEPT_ID
```

The condition is:

```sql
EMP.DEPT_ID = DEPT.DEPT_ID
```

If equal → the rows are combined.

If not equal → the rows are not returned.

---

# 6. Equi Join with Table Aliases

When two tables are involved, aliases make the query easier to read.

### Question

**Display employee and department information using table aliases and match the department IDs.**

### Answer / Query

```sql
SELECT *
FROM EMP e, DEPT d
WHERE e.DEPT_ID = d.DEPT_ID;
```

Here:

```text
e → EMP
d → DEPT
```

Therefore:

```sql
e.DEPT_ID
```

means:

```text
EMP.DEPT_ID
```

and:

```sql
d.DEPT_ID
```

means:

```text
DEPT.DEPT_ID
```

# 7. Equi Join vs Inner Join

The important thing is that both can produce the same matching result.

### Inner Join

```sql
SELECT *
FROM EMP e
INNER JOIN DEPT d
ON e.DEPT_ID = d.DEPT_ID;
```

### Equi Join

```sql
SELECT *
FROM EMP e, DEPT d
WHERE e.DEPT_ID = d.DEPT_ID;
```

The main difference in the material is **where the joining condition is written**:

| Inner Join                           | Equi Join                             |
| ------------------------------------ | ------------------------------------- |
| Uses `INNER JOIN`                    | Uses tables separated by comma        |
| Joining condition is given with `ON` | Joining condition is given in `WHERE` |
| Uses `=` in the example              | Uses explicit `=`                     |
| Returns matching records             | Returns matching records              |

The key definition given is that Equi Join is the same as Inner Join, with the joining condition in the `WHERE` clause using the explicit `=` operator. 

---

# 8. Very Important Confusion

Don't confuse these two:

```sql
INNER JOIN
```

and

```sql
WHERE
```

### Inner Join style

```sql
FROM EMP e
INNER JOIN DEPT d
ON e.DEPT_ID = d.DEPT_ID
```

### Equi Join style

```sql
FROM EMP e, DEPT d
WHERE e.DEPT_ID = d.DEPT_ID
```

The matching condition is still:

```sql
e.DEPT_ID = d.DEPT_ID
```

The difference is **how the join is written**.

---

# 9. Memory Trick

Remember:

```text
EQUI
 ↓
EQUAL
 ↓
=
```

So:

> **Equi Join → Equal (`=`) condition → Matching records**

And remember the placement:

```text
INNER JOIN → ON
EQUI JOIN  → WHERE
```

# 10. Interview Questions

### Q1. What is an Equi Join?

**Answer:**
An Equi Join is a join where the joining condition uses the equality (`=`) operator.

### Q2. Is Equi Join similar to Inner Join?

**Answer:**
Yes. It is described as the same as Inner Join, with the joining condition specified in the `WHERE` clause using `=`.

### Q3. Where is the joining condition specified in an Equi Join?

**Answer:**
In the **`WHERE` clause**.

### Q4. Which operator is used in an Equi Join?

**Answer:**
The **equal (`=`) operator**.

### Q5. Does Equi Join return unmatched records?

**Answer:**
No. It returns the matching records.

### Q6. Give the basic Equi Join syntax.

**Answer:**

```sql
SELECT *
FROM Table1, Table2
WHERE Table1.B = Table2.B;
```
