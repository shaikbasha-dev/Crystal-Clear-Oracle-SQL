# 13.7 Cartesian Join

## 1. What is Cartesian Join?

A **Cartesian Join** combines **every row of one table with every row of another table**.

In simple words:

> **Every row of Table 1 is combined with every row of Table 2.**

So, Cartesian Join produces the **Cartesian product** of the two tables.

### Example

If:

* Table 1 has **4 rows**
* Table 2 has **3 rows**

Then:

**4 × 3 = 12 rows**

So the result will contain **12 combinations**.

---

## 2. Syntax

The syntax given for Cartesian Join is:

```sql id="m3f8p7"
SELECT *
FROM Table1, Table2;
```

Notice that there is **no `WHERE` condition** and no `ON` condition.

---

## 3. Question → Answer

### Question:

**Perform a Cartesian Join between Table11 and Table12.**

### Table11

| A |  B |
| - | -: |
| 1 |  2 |
| 3 |  4 |
| 5 |  6 |
| 7 |  8 |

### Table12

|  B |  C |
| -: | -: |
|  2 |  1 |
|  8 |  1 |
|  9 |  1 |

### Answer / Query:

```sql id="c8x4n2"
SELECT *
FROM Table11, Table12;
```

### Result

Because Table11 has **4 rows** and Table12 has **3 rows**:

**4 × 3 = 12 rows**

The combinations are:

| Table11 A | Table11 B | Table12 B | Table12 C |
| --------: | --------: | --------: | --------: |
|         1 |         2 |         2 |         1 |
|         1 |         2 |         8 |         1 |
|         1 |         2 |         9 |         1 |
|         3 |         4 |         2 |         1 |
|         3 |         4 |         8 |         1 |
|         3 |         4 |         9 |         1 |
|         5 |         6 |         2 |         1 |
|         5 |         6 |         8 |         1 |
|         5 |         6 |         9 |         1 |
|         7 |         8 |         2 |         1 |
|         7 |         8 |         8 |         1 |
|         7 |         8 |         9 |         1 |

## 4. Cross Join vs Cartesian Join

Both produce the **Cartesian product**.

| Cross Join                        | Cartesian Join                    |
| --------------------------------- | --------------------------------- |
| Uses `CROSS JOIN` keyword         | Uses comma `,` between tables     |
| `FROM Table1 CROSS JOIN Table2`   | `FROM Table1, Table2`             |
| Every row combines with every row | Every row combines with every row |
| No join condition                 | No join condition                 |

### Easy memory trick

```text
CROSS JOIN
     ↓
Everything × Everything

Cartesian Join
     ↓
Everything × Everything
```

So the main difference here is **the syntax used**, not the result. The notes describe Cross Join as the cross product and give Cartesian Join the comma-based syntax.
