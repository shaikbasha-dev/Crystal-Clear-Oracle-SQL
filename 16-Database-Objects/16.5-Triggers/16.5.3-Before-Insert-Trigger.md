# 16.5.3-Before-Insert-Trigger

## 1. What is a BEFORE INSERT Trigger?

A **BEFORE INSERT Trigger** is a Trigger whose action is executed **before a new row is inserted into a table**.

The two important parts are:

```text
BEFORE → When should the Trigger execute?
INSERT → What event activates the Trigger?
```

So:

```text
INSERT is about to happen
        ↓
BEFORE INSERT Trigger executes
        ↓
Trigger action takes place
        ↓
INSERT continues
```

The six event/action combinations include **Before Insert**, **After Insert**, **Before Update**, **After Update**, **Before Delete**, and **After Delete**. 

---

## 2. Why is it called BEFORE INSERT?

Because the Trigger is associated with the **INSERT event**, but its action is performed **before** that INSERT event.

```text
BEFORE + INSERT
     ↓
BEFORE INSERT
```

### Easy memory

> **BEFORE = first**
> **INSERT = new row**

Therefore:

> **BEFORE INSERT = Trigger action happens before inserting a new row.**

---

## 3. General Syntax

### Question:

What is the syntax for creating a BEFORE INSERT Trigger?

### Answer / Syntax:

```sql
CREATE TRIGGER trigger_name
BEFORE INSERT
ON table_name
FOR EACH ROW
BEGIN
    SQL Query;
END;
```

This follows the Trigger creation syntax given for specifying the timing and event. 

### Meaning of each part

| Part             | Meaning                                     |
| ---------------- | ------------------------------------------- |
| `CREATE TRIGGER` | Creates a Trigger                           |
| `trigger_name`   | Name of the Trigger                         |
| `BEFORE`         | Execute the Trigger action before the event |
| `INSERT`         | Event that activates the Trigger            |
| `ON table_name`  | Table on which INSERT occurs                |
| `FOR EACH ROW`   | Trigger works for each affected row         |
| `BEGIN`          | Starts the Trigger body                     |
| `SQL Query`      | Action performed by Trigger                 |
| `END`            | Ends the Trigger                            |

# 4. Example from the Trigger Topic

### Question:

Create a Trigger named `dec` that executes **before an INSERT** on `table1` and inserts the new `id` and `name` into `table2`.

### Answer / Query:

```sql
CREATE TRIGGER dec
BEFORE INSERT
ON table1
FOR EACH ROW
BEGIN
    INSERT INTO table2 VALUES(:NEW.id, :NEW.name);
END;
```

The example uses `:NEW.id` and `:NEW.name` for the values associated with the new row. 

> **Correction:** The source example contains `before inser`; the correct SQL keyword is `BEFORE INSERT`.

---

# 5. Understanding the Example

Suppose a new row is inserted into `table1`:

```text
table1

ID    NAME
1     A
```

Now another row is going to be inserted:

```text
ID = 2
NAME = B
```

The flow is:

```text
New row is going to be inserted into table1
                 ↓
          BEFORE INSERT
                 ↓
             Trigger
                 ↓
     :NEW.id   = 2
     :NEW.name = B
                 ↓
      INSERT into table2
```

The Trigger action is:

```sql
INSERT INTO table2 VALUES(:NEW.id, :NEW.name);
```

So the values from the new row are used by the Trigger.

---

# 6. What is `:NEW`?

For an INSERT event, the Trigger works with the **new row values**.

The mapping given is:

```text
INSERT → :NEW
UPDATE → :NEW + :OLD
DELETE → :OLD
```



Therefore, in a BEFORE INSERT Trigger:

```sql
:NEW.id
```

means the new `id` value.

And:

```sql
:NEW.name
```

means the new `name` value.

---

# 7. BEFORE INSERT vs AFTER INSERT

| BEFORE INSERT                       | AFTER INSERT                       |
| ----------------------------------- | ---------------------------------- |
| Trigger action occurs before INSERT | Trigger action occurs after INSERT |
| Activated by INSERT                 | Activated by INSERT                |
| Uses new row information            | Uses new row information           |
| Timing is BEFORE                    | Timing is AFTER                    |

### Memory trick

```text
BEFORE INSERT
      ↓
Trigger
      ↓
INSERT


AFTER INSERT
      ↓
INSERT
      ↓
Trigger
```

# 8. Event and Action in This Example

### Question:

In the `dec` Trigger, identify the event and action.

### Answer:

**Event:**

```text
BEFORE INSERT
```

**Action:**

```sql
INSERT INTO table2 VALUES(:NEW.id, :NEW.name);
```

So:

```text
EVENT
  ↓
BEFORE INSERT
  ↓
ACTION
  ↓
Insert :NEW.id and :NEW.name into table2
```

---

# 9. Important Points

* `BEFORE INSERT` is one of the six Trigger event/timing combinations. 
* `BEFORE` tells **when** the Trigger action executes.
* `INSERT` tells **which event** activates the Trigger.
* `:NEW` is associated with INSERT. 
* A Trigger is stored in the database and executes autonomously when its specified event occurs. 
* `FOR EACH ROW` is included in the Trigger creation syntax.
