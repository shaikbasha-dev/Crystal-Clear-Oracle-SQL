# 14.2.2.1-Add-Column

## 1. What is ADD COLUMN?

**ADD COLUMN** is an operation of the `ALTER` command.

It is used to **add a new column to an existing table**.

### Simple idea

Suppose we already have a `BANK` table:

| BID | BNAME | BHQ       |
| --: | ----- | --------- |
|   1 | SBI   | Hyderabad |
|   2 | HDFC  | Mumbai    |

Now we want to add a phone number column.

We can use:

```text
ALTER TABLE
     ↓
ADD
     ↓
New Column
```

The existing table remains, and a new column is added to its structure.

---

# 2. Why do we need ADD COLUMN?

When a table has already been created, we may later realize that we need additional information.

For example:

| Existing Columns | New Requirement   |
| ---------------- | ----------------- |
| `BID`            | Already available |
| `BNAME`          | Already available |
| `BHQ`            | Already available |
| `PH_NO`          | Need to add       |

Instead of creating the table again, we use `ALTER TABLE ... ADD`.

---

# 3. Syntax

### Question

**How do we add a new column to an existing table?**

### Syntax

```sql
ALTER TABLE table_name
ADD column_name datatype;
```

---

## 4. Syntax Explanation

| Syntax Part   | Meaning                                  |
| ------------- | ---------------------------------------- |
| `ALTER`       | Used to modify an existing table         |
| `TABLE`       | Specifies that a table is being modified |
| `table_name`  | Name of the existing table               |
| `ADD`         | Tells Oracle to add something            |
| `column_name` | Name of the new column                   |
| `datatype`    | Data type of the new column              |
| `;`           | End of the SQL command                   |

### Remember

```text
ALTER TABLE
     ↓
Which existing table?
     ↓
ADD
     ↓
What new column?
     ↓
What data type?
```

---

# 5. Example

### Question

**Add a `ph_no` column to the existing `Bank` table with the `NUMBER` data type.**

### Query

```sql
ALTER TABLE Bank
ADD ph_no NUMBER;
```

---

## 6. Step-by-Step Explanation

Before executing the query:

| BID | BNAME | BHQ       |
| --: | ----- | --------- |
|   1 | SBI   | Hyderabad |
|   2 | HDFC  | Mumbai    |

Execute:

```sql
ALTER TABLE Bank
ADD ph_no NUMBER;
```

### Step 1

Oracle finds the existing table:

```text
BANK
```

### Step 2

Oracle sees:

```text
ADD ph_no NUMBER
```

### Step 3

Oracle adds a new column:

```text
PH_NO
```

### Step 4

The data type of `PH_NO` is:

```text
NUMBER
```

### After adding the column

| BID | BNAME | BHQ       | PH_NO |
| --: | ----- | --------- | ----- |
|   1 | SBI   | Hyderabad | NULL  |
|   2 | HDFC  | Mumbai    | NULL  |

The new column is part of the table structure.

# 8. What happens to existing rows?

Suppose the table contains:

| BID | BNAME | BHQ       |
| --: | ----- | --------- |
|   1 | SBI   | Hyderabad |
|   2 | HDFC  | Mumbai    |
|   3 | ICICI | Delhi     |

After:

```sql
ALTER TABLE Bank
ADD ph_no NUMBER;
```

the structure becomes:

| BID | BNAME | BHQ       | PH_NO |
| --: | ----- | --------- | ----- |
|   1 | SBI   | Hyderabad | NULL  |
|   2 | HDFC  | Mumbai    | NULL  |
|   3 | ICICI | Delhi     | NULL  |

The existing rows are not deleted.

---

# 9. ADD COLUMN vs INSERT

This is an important difference.

| ADD COLUMN              | INSERT             |
| ----------------------- | ------------------ |
| Adds a **new column**   | Adds a **new row** |
| Changes table structure | Adds data          |
| Uses `ALTER`            | Uses `INSERT`      |
| DDL operation           | DML command        |

### Easy Example

**Add a column:**

```sql
ALTER TABLE Bank
ADD ph_no NUMBER;
```

**Add a row:**

```sql
INSERT INTO Bank
VALUES (...);
```

Think:

```text
ADD COLUMN → Add a vertical column
INSERT     → Add a horizontal row
```

---

# 10. ADD COLUMN vs CREATE TABLE

| CREATE TABLE              | ADD COLUMN                 |
| ------------------------- | -------------------------- |
| Creates a new table       | Modifies an existing table |
| Creates initial structure | Adds to existing structure |
| Uses `CREATE`             | Uses `ALTER`               |

### Memory Trick

> **CREATE = Create the table**
> **ADD = Add something to an existing table**

---

# 11. Common Mistakes

### Mistake 1 — Forgetting `TABLE`

❌ Wrong:

```sql
ALTER Bank
ADD ph_no NUMBER;
```

✅ Correct:

```sql
ALTER TABLE Bank
ADD ph_no NUMBER;
```

---

### Mistake 2 — Forgetting the data type

❌ Wrong:

```sql
ALTER TABLE Bank
ADD ph_no;
```

✅ Correct:

```sql
ALTER TABLE Bank
ADD ph_no NUMBER;
```

---

### Mistake 3 — Using CREATE instead of ALTER

If `Bank` already exists, don't create the table again just to add a column.

Use:

```sql
ALTER TABLE Bank
ADD ph_no NUMBER;
```

---

# 12. Important Rules

| Rule | Explanation                                                     |
| ---- | --------------------------------------------------------------- |
| 1    | The table must already exist                                    |
| 2    | `ALTER TABLE` is used                                           |
| 3    | `ADD` specifies that a new column is being added                |
| 4    | The new column must have a data type                            |
| 5    | Existing table structure remains; the new column is added to it |

# 13. Interview Questions

### Question 1

**How do you add a column to an existing table?**

### Answer

```sql
ALTER TABLE table_name
ADD column_name datatype;
```

---

### Question 2

**Which command is used to add a column to an existing table?**

### Answer

> `ALTER TABLE ... ADD` is used to add a new column to an existing table.

---

### Question 3

**Is ADD COLUMN a separate DDL command?**

### Answer

> No. It is an operation performed using the `ALTER` DDL command.

---

### Question 4

**Does ADD COLUMN add a row?**

### Answer

> No. It adds a **column** to the table structure. `INSERT` is used to add rows.
