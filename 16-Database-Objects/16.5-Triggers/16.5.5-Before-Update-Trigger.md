# 16.5.5-Before-Update-Trigger

## 1. What is a BEFORE UPDATE Trigger?

A **BEFORE UPDATE Trigger** is a Trigger whose action is executed **before an existing row is updated**.

Break the name into two parts:

```text
BEFORE  → When?
UPDATE  → Which event?
```

So the flow is:

```text
UPDATE is about to happen
        ↓
BEFORE UPDATE Trigger executes
        ↓
Trigger Action
        ↓
UPDATE continues
```

Triggers are prepared SQL statements saved in the database and executed autonomously when the specified event occurs. 

---

# 2. Why is it called BEFORE UPDATE?

Because the Trigger action happens **before the UPDATE operation**.

```text
BEFORE UPDATE

Trigger Action
      ↓
UPDATE
```

Compare this with AFTER UPDATE:

```text
AFTER UPDATE

UPDATE
  ↓
Trigger Action
```

### Easy memory

> **BEFORE UPDATE → Trigger first, UPDATE next**
> **AFTER UPDATE → UPDATE first, Trigger next**

---

# 3. General Syntax

### Question:

What is the syntax for creating a BEFORE UPDATE Trigger?

### Answer / Syntax:

```sql
CREATE TRIGGER trigger_name
BEFORE UPDATE
ON table_name
FOR EACH ROW
BEGIN
    SQL Query;
END;
```

The general Trigger syntax specifies the timing, event, table and Trigger action. 

---

# 4. Understanding the Syntax

| Part             | Meaning                          |
| ---------------- | -------------------------------- |
| `CREATE TRIGGER` | Creates a Trigger                |
| `trigger_name`   | Name of the Trigger              |
| `BEFORE`         | Action occurs before the event   |
| `UPDATE`         | Event that activates the Trigger |
| `ON table_name`  | Table on which UPDATE occurs     |
| `FOR EACH ROW`   | Applies to each affected row     |
| `BEGIN`          | Starts Trigger body              |
| `SQL Query`      | Action performed by Trigger      |
| `END`            | Ends Trigger                     |

---

# 5. What happens during UPDATE?

Suppose an employee's salary is going to be changed.

```text
Old Salary
   ↓
UPDATE is about to happen
   ↓
BEFORE UPDATE Trigger
   ↓
Trigger Action
   ↓
New Salary
```

The important point is:

> The Trigger action takes place **before the UPDATE operation**.

---

# 6. `:OLD` and `:NEW` in UPDATE

UPDATE is special because there can be both an **old value** and a **new value**.

The mapping is:

```text
UPDATE → :OLD + :NEW
```



For example:

```text
Before update:
Salary = 20,000
     ↓
:OLD.salary = 20,000

New value:
Salary = 25,000
     ↓
:NEW.salary = 25,000
```

So:

```text
:OLD → value before UPDATE
:NEW → value after/change-to value
```

### Question:

Create a BEFORE UPDATE Trigger on `table1`.

### Answer / Query:

```sql
CREATE TRIGGER dec
BEFORE UPDATE
ON table1
FOR EACH ROW
BEGIN
    -- SQL action
END;
```

The important part is:

```sql
BEFORE UPDATE
```

This tells Oracle:

```text
Event = UPDATE
Timing = BEFORE
```

# 8. Example of an UPDATE Event

### Question:

Update the salary of an employee in `emp1`.

### Answer / Query:

```sql

```

If a BEFORE UPDATE Trigger is defined on `emp1`, the flow is:

```text
UPDATE emp1
     ↓
BEFORE UPDATE Trigger
     ↓
Trigger Action
     ↓
Salary becomes 25000
```

# 9. Event and Action

### Question:

In a BEFORE UPDATE Trigger, identify the timing, event and action.

### Answer:

**Timing:**

```text
BEFORE
```

**Event:**

```text
UPDATE
```

**Action:**

```text
SQL statement written inside the Trigger
```

Therefore:

```text
BEFORE UPDATE
      ↓
UPDATE event is about to occur
      ↓
Trigger action executes
```

# 10. BEFORE UPDATE vs AFTER UPDATE

| BEFORE UPDATE                           | AFTER UPDATE                            |
| --------------------------------------- | --------------------------------------- |
| Trigger action occurs before UPDATE     | Trigger action occurs after UPDATE      |
| Timing = BEFORE                         | Timing = AFTER                          |
| Event = UPDATE                          | Event = UPDATE                          |
| UPDATE has `:OLD` and `:NEW` references | UPDATE has `:OLD` and `:NEW` references |

### Visual memory

```text
BEFORE UPDATE

BEFORE Trigger
      ↓
UPDATE
```

```text
AFTER UPDATE

UPDATE
  ↓
AFTER Trigger
```

---

# 11. UPDATE vs INSERT

| INSERT                   | UPDATE                   |
| ------------------------ | ------------------------ |
| Creates a new row        | Changes an existing row  |
| Uses `:NEW`              | Uses `:OLD` and `:NEW`   |
| Example: `BEFORE INSERT` | Example: `BEFORE UPDATE` |

The Trigger reference mapping is:

```text
INSERT → :NEW
UPDATE → :OLD + :NEW
DELETE → :OLD
```



---

# 12. Important Points

* `BEFORE UPDATE` is one of the six Trigger combinations.
* `BEFORE` specifies the timing.
* `UPDATE` specifies the event.
* The Trigger action executes before the UPDATE.
* UPDATE can use both `:OLD` and `:NEW`.
* `:OLD` represents the value before the UPDATE.
* `:NEW` represents the new value associated with the UPDATE. 
* A Trigger executes autonomously when its specified event occurs.
