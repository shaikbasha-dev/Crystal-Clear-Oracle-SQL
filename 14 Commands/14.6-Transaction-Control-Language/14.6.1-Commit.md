# 14.6.1-Commit

## 1. What is COMMIT?

`COMMIT` is a **TCL (Transaction Control Language)** command.

It is used to **save DML actions permanently in the database**. 

DML actions include:

* `INSERT`
* `UPDATE`
* `DELETE`

```text id="f1q2w3"
INSERT / UPDATE / DELETE
          ↓
       COMMIT
          ↓
   Changes saved permanently
```

---

## 2. Why do we need COMMIT?

DML commands make changes to table data.

`COMMIT` is used when we want to **make those changes permanent**.

### Simple example

```text id="a7b8c9"
INSERT
  ↓
Change made
  ↓
COMMIT
  ↓
Change permanently saved
```

---

## 3. Syntax

### Question:

**What is the syntax of the COMMIT command?**

### Answer / Query:

```sql id="d4e5f6"
COMMIT;
```

This is the syntax given for the command. 

---

## 4. COMMIT with INSERT

### Question:

**How do you permanently save an inserted record?**

### Answer / Query:

```sql id="g7h8i9"
INSERT INTO demo1 VALUES(1, 'A', 22);

COMMIT;
```

### Step-by-step

**Step 1:** Insert the record.

```text id="j1k2l3"
INSERT
  ↓
Record is inserted
```

**Step 2:** Execute `COMMIT`.

```text id="m4n5o6"
COMMIT
  ↓
DML change is permanently saved
```

## 5. COMMIT in a Transaction

### Question:

**How is COMMIT used after multiple INSERT operations in a transaction?**

### Answer / Query:

```sql id="p7q8r9"
INSERT INTO demo1 VALUES(1, 'A', 22);

INSERT INTO demo1 VALUES(2, 'B', 23);

INSERT INTO demo1 VALUES(3, 'C', 23);

COMMIT;
```



### Understanding

```text id="s1t2u3"
INSERT row 1
     ↓
INSERT row 2
     ↓
INSERT row 3
     ↓
   COMMIT
     ↓
Changes permanently saved
```

## 6. COMMIT and ROLLBACK

### Question:

**What is the basic difference between COMMIT and ROLLBACK?**

| COMMIT                        | ROLLBACK                                          |
| ----------------------------- | ------------------------------------------------- |
| Saves DML changes permanently | Undoes DML changes that are not permanently saved |
| Used to save changes          | Used to undo changes                              |
| `COMMIT;`                     | `ROLLBACK;`                                       |

The two commands have opposite purposes in controlling DML changes. 

---

## 7. COMMIT and SAVEPOINT

### Question:

**How are COMMIT and SAVEPOINT different?**

| COMMIT                        | SAVEPOINT                                      |
| ----------------------------- | ---------------------------------------------- |
| Permanently saves DML actions | Creates a temporary point within a transaction |
| Syntax: `COMMIT;`             | Syntax: `SAVEPOINT savepoint_name;`            |



---

## 8. Important Point

### Question:

**What happens to DML actions when COMMIT is executed?**

### Answer:

The DML actions are **saved permanently in the database**. 

### Remember:

```text id="v4w5x6"
DML
 ↓
INSERT / UPDATE / DELETE
 ↓
COMMIT
 ↓
PERMANENT SAVE
```

## 9. Interview Questions

### Q1. What is COMMIT?

**Answer:**

> COMMIT is a TCL command used to save DML actions permanently in the database.

### Q2. What is the syntax of COMMIT?

**Answer:**

```sql id="y7z8a9"
COMMIT;
```

### Q3. Is COMMIT a DML command?

**Answer:**

> No. COMMIT is a **TCL command**.

### Q4. With which commands is COMMIT generally used?

**Answer:**

> COMMIT is used to permanently save changes made by DML commands such as INSERT, UPDATE, and DELETE.

### Q5. What is the difference between COMMIT and ROLLBACK?

**Answer:**

> COMMIT permanently saves DML changes, whereas ROLLBACK undoes DML changes that have not been permanently saved.
