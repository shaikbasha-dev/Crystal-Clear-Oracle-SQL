# 19.13-Interview-Questions

## 1. Basic Normalisation Questions

### Q1. What is Normalisation?

**Answer:**

> Normalisation is the process of organizing data into properly structured related tables to reduce unnecessary redundancy and avoid data anomalies.

---

### Q2. Why do we need Normalisation?

**Answer:**

Normalisation helps to:

* Reduce data redundancy.
* Reduce insert anomalies.
* Reduce update anomalies.
* Reduce delete anomalies.
* Improve data consistency.
* Improve data integrity.
* Organize database tables properly.

---

### Q3. What are Database Anomalies?

**Answer:**

Database anomalies are unwanted problems that can occur because of poor table design.

The three major anomalies are:

```text
1. Insert Anomaly
2. Update Anomaly
3. Delete Anomaly
```

---

### Q4. Explain Insert Anomaly.

**Answer:**

> Insert Anomaly occurs when we cannot insert certain information into a table without having some unrelated information.

**Example:**
We want to add a new course, but the table requires student information too. If no student has enrolled yet, we cannot properly insert the course.

---

### Q5. Explain Update Anomaly.

**Answer:**

> Update Anomaly occurs when the same information is repeated in multiple rows and must be updated in several places. If some rows are not updated, inconsistent data can result.

---

### Q6. Explain Delete Anomaly.

**Answer:**

> Delete Anomaly occurs when deleting one record unintentionally causes other important information to be lost.

---

# 2. Normal Forms Questions

### Q7. What are Normal Forms?

**Answer:**

Normal forms are levels of database normalization used to progressively improve database design.

The important sequence is:

```text
1NF → 2NF → 3NF → BCNF → 4NF → 5NF
```

---

### Q8. What is 1NF?

**Answer:**

> 1NF, or First Normal Form, requires atomic values in each cell and eliminates repeating groups or multiple values stored in a single cell.

### Memory:

```text
1NF → Atomic
```

---

### Q9. What is an Atomic Value?

**Answer:**

> An atomic value is a single value stored in a cell.

Example:

```text
Phone
9876543210
```

is atomic.

But:

```text
9876543210, 9123456780
```

contains multiple values and violates the atomicity requirement.

---

### Q10. What is 2NF?

**Answer:**

> 2NF is achieved when a table is already in 1NF and has no partial functional dependency.

### Memory:

```text
2NF → No Partial Dependency
```

---

### Q11. What is Partial Functional Dependency?

**Answer:**

> Partial dependency occurs when a non-key attribute depends on only part of a composite key.

Example:

```text
(Student_ID, Course_ID) → Marks
```

is a full dependency.

But:

```text
Student_ID → Student_Name
```

is partial if `(Student_ID, Course_ID)` is the composite key.

---

### Q12. Can Partial Dependency occur with a single-column key?

**Answer:**

> No. Partial dependency requires a composite key because the dependency must be on only a part of the key.

---

### Q13. What is 3NF?

**Answer:**

> 3NF is achieved when a table is already in 2NF and has no transitive functional dependency.

### Memory:

```text
3NF → No Transitive Dependency
```

---

### Q14. What is Transitive Dependency?

**Answer:**

If:

```text
A → B
B → C
```

then:

```text
A → C
```

through B.

This is a transitive dependency.

Example:

```text
Student_ID → Department_ID
Department_ID → Department_Name
```

Therefore:

```text
Student_ID → Department_Name
```

through `Department_ID`.

---

# 3. BCNF Questions

### Q15. What is BCNF?

**Answer:**

> BCNF stands for Boyce-Codd Normal Form. A relation is in BCNF if, for every non-trivial functional dependency `X → Y`, X is a super key.

### Most important line:

```text
BCNF → Every determinant must be a Super Key.
```

---

### Q16. What is a Determinant?

**Answer:**

In:

```text
A → B
```

`A` is the **determinant** because it determines `B`.

---

### Q17. Is BCNF stronger than 3NF?

**Answer:**

Yes.

BCNF is stricter than 3NF.

```text
BCNF ⟹ 3NF
```

But a relation can be:

```text
3NF ✅
BCNF ❌
```

---

### Q18. Can a table be in 3NF but not BCNF?

**Answer:**

**Yes.**

This is a very common interview question.

3NF permits some cases that BCNF does not.

---

# 4. 4NF Questions

### Q19. What is 4NF?

**Answer:**

> 4NF, or Fourth Normal Form, deals with multivalued dependencies. A relation is in 4NF when it is in BCNF and every non-trivial multivalued dependency has a super key as its determinant.

### Memory:

```text
4NF → Multivalued Dependency
```

---

### Q20. What is a Multivalued Dependency?

**Answer:**

A multivalued dependency occurs when one attribute determines multiple independent values of another attribute.

It is represented as:

```text
A →→ B
```

---

### Q21. What is the difference between Functional Dependency and Multivalued Dependency?

**Answer:**

| Functional Dependency                     | Multivalued Dependency                |
| ----------------------------------------- | ------------------------------------- |
| `A → B`                                   | `A →→ B`                              |
| Describes functional determination        | Describes multiple independent values |
| Important in earlier normalization levels | Important for 4NF                     |

---

# 5. 5NF Questions

### Q22. What is 5NF?

**Answer:**

> 5NF, or Fifth Normal Form, also called Project-Join Normal Form, deals with join dependencies and ensures that a relation cannot be further losslessly decomposed based on valid join dependencies.

### Memory:

```text
5NF → Join Dependency
```

---

### Q23. What is another name for 5NF?

**Answer:**

> **Project-Join Normal Form (PJ/NF).**

---

### Q24. What is Join Dependency?

**Answer:**

> A join dependency describes a situation where a relation can be reconstructed by joining multiple decomposed relations.

---

### Q25. What is Lossless Decomposition?

**Answer:**

> Lossless decomposition means that after decomposing a table and joining the resulting tables, we can reconstruct the original valid information without losing information or generating incorrect additional information.

---

# 6. Normalisation vs Denormalisation

### Q26. What is Denormalisation?

**Answer:**

> Denormalisation is the intentional introduction of some redundancy or combining of data to reduce joins and potentially improve read performance.

---

### Q27. What is the difference between Normalisation and Denormalisation?

**Answer:**

| Normalisation                        | Denormalisation                      |
| ------------------------------------ | ------------------------------------ |
| Reduces redundancy                   | Intentionally allows some redundancy |
| Separates related data               | May combine or duplicate data        |
| Reduces anomalies                    | Can introduce some anomaly risks     |
| Usually requires more joins          | Can reduce joins                     |
| Focuses on consistency and integrity | Often focuses on read performance    |

### Interview one-line answer:

> **Normalization reduces redundancy and improves consistency, while denormalization accepts some redundancy to improve suitable read-heavy workloads.**

---

### Q28. Is Denormalisation bad database design?

**Answer:**

> No. Denormalisation can be appropriate when there is a genuine performance or reporting requirement. It should be introduced deliberately rather than simply to avoid designing proper relationships.

---

# 7. Most Important Comparison Questions

### Q29. What is the difference between 1NF and 2NF?

**Answer:**

> 1NF focuses on atomic values and eliminating repeating groups, while 2NF focuses on removing partial functional dependencies.

```text
1NF → Atomic
2NF → Partial Dependency
```

---

### Q30. What is the difference between 2NF and 3NF?

**Answer:**

> 2NF removes partial dependency, while 3NF removes transitive dependency.

```text
2NF → Partial
3NF → Transitive
```

---

### Q31. What is the difference between 3NF and BCNF?

**Answer:**

> BCNF is a stricter form of 3NF. BCNF requires every determinant of a non-trivial functional dependency to be a super key.

---

### Q32. What is the difference between BCNF and 4NF?

**Answer:**

> BCNF focuses on functional dependencies, whereas 4NF additionally deals with multivalued dependencies.

```text
BCNF → Functional Dependency
4NF  → Multivalued Dependency
```

---

### Q33. What is the difference between 4NF and 5NF?

**Answer:**

> 4NF deals with multivalued dependencies, while 5NF deals with join dependencies.

```text
4NF → Multivalued
5NF → Join
```

---

# 8. Very Important Interview Question

### Q34. Explain all normal forms in one answer.

**Answer:**

> **1NF** requires atomic values and removes repeating groups.
> **2NF** requires 1NF and removes partial functional dependencies.
> **3NF** requires 2NF and removes transitive functional dependencies.
> **BCNF** requires every determinant of a non-trivial functional dependency to be a super key.
> **4NF** deals with multivalued dependencies.
> **5NF** deals with join dependencies and lossless decomposition.

### Memory:

```text
1NF  → ATOMIC
2NF  → PARTIAL
3NF  → TRANSITIVE
BCNF → SUPER KEY
4NF  → MULTIVALUED
5NF  → JOIN
```

# 9. Scenario-Based Interview Questions

### Q35. A column contains `Java, Python, SQL` in a single cell. Which normal form is violated?

**Answer:**

**1NF**, because the cell contains multiple values instead of an atomic value.

---

### Q36. A non-key attribute depends only on part of a composite key. Which normal form is violated?

**Answer:**

**2NF.**

---

### Q37. A non-key attribute depends on another non-key attribute. What problem is present?

**Answer:**

**Transitive dependency**, which violates the 3NF requirement.

---

### Q38. The determinant of a non-trivial functional dependency is not a super key. Which normal form may be violated?

**Answer:**

**BCNF.**

---

### Q39. A table contains two independent multi-valued relationships. Which normal form addresses this problem?

**Answer:**

**4NF.**

---

### Q40. A relation can be decomposed further based on a valid join dependency without losing information. Which normal form addresses this?

**Answer:**

**5NF.**

---
