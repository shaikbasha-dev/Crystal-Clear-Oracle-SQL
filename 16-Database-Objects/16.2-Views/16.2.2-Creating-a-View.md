# 16.2.2-Creating-a-View

## 1. What does Creating a View mean?

Creating a View means **creating a virtual table based on an SQL query**.

The basic idea is:

```text id="x1v8q2"
Actual Table
     ↓
   SQL Query
     ↓
Create View
     ↓
 Virtual Table
```

The View gets its definition from the SQL query.

---

## 2. Syntax for Creating a View

### Question:

What is the syntax for creating a View?

### Answer / Syntax:

```sql
CREATE VIEW view_name
AS
SQL Query;
```

The important keywords are:

* `CREATE VIEW` → tells Oracle that we want to create a View.
* `view_name` → name we give to the View.
* `AS` → connects the View name with the SQL query.
* `SQL Query` → query used to define the View.



---

# 3. Creating a View — Example

### Question:

Create a View named `dec` that displays `f_name`, `salary`, and `dept_id` from the `emp` table for employees whose `dept_id` is `22`.

### Answer / Query:

```sql
CREATE VIEW dec
AS
SELECT f_name, salary, dept_id
FROM emp
WHERE dept_id = 22;
```



---

## 4. Query Explanation

Let's understand each part.

### Step 1

```sql
CREATE VIEW dec
```

Creates a View with the name:

```text
dec
```

### Step 2

```sql
AS
```

Connects the View name with the SQL query that defines it.

### Step 3

```sql
SELECT f_name, salary, dept_id
```

Selects these three columns from the table.

### Step 4

```sql
FROM emp
```

Specifies that the data comes from the `emp` table.

### Step 5

```sql
WHERE dept_id = 22;
```

Selects only employees whose department ID is `22`.

---

# 5. What does the View contain?

After executing:

```sql
CREATE VIEW dec
AS
SELECT f_name, salary, dept_id
FROM emp
WHERE dept_id = 22;
```

the View represents the result containing:

| f_name                         |       salary | dept_id |
| ------------------------------ | -----------: | ------: |
| Employees satisfying condition | Their salary |      22 |
| Employees satisfying condition | Their salary |      22 |
| Employees satisfying condition | Their salary |      22 |

The exact rows depend on the current contents of the `emp` table.

---

# 6. Understand the Complete Flow

```text id="m9j4ka"
              EMP TABLE
                  │
                  │
          ┌───────┴────────┐
          │                │
     Select columns    Apply condition
          │                │
 f_name, salary,       dept_id = 22
     dept_id               │
          └───────┬────────┘
                  ↓
             CREATE VIEW
                  ↓
                 DEC
                  ↓
            Virtual Table
```

So:

> **The View `dec` is created from the result of the specified SELECT query.**

---

# 7. Why is `CREATE VIEW` useful?

Suppose the same query is required repeatedly:

```sql
SELECT f_name, salary, dept_id
FROM emp
WHERE dept_id = 22;
```

Instead of repeatedly writing this complete query, we can create a View:

```text id="8n2j6x"
Complex/Repeated Query
         ↓
       VIEW
         ↓
   Easier access
```

This is one of the reasons Views are used to **make complex queries simple**. 

---

# 8. Important Rules to Remember

### Rule 1

The View must have a name.

```sql
CREATE VIEW dec
```

Here `dec` is the View name.

### Rule 2

`AS` is used before the SQL query.

```sql
CREATE VIEW dec
AS
SELECT ...
```

### Rule 3

The query defining the View can select required columns.

```sql
SELECT f_name, salary, dept_id
```

### Rule 4

A condition can be used while defining the View.

```sql
WHERE dept_id = 22;
```

---

# 9. Common Confusion

### View vs Table

| Table                                | View                        |
| ------------------------------------ | --------------------------- |
| Actual table                         | Virtual table               |
| Stores table data                    | Based on an SQL query       |
| Created as a table                   | Created using `CREATE VIEW` |
| Can contain complete table structure | Can expose selected data    |
