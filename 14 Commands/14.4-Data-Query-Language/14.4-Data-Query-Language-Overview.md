# 14.4-Data-Query-Language-Overview

## 1. What is Data Query Language?

**DQL** stands for **Data Query Language**.

DQL is used to **retrieve/read data from database tables**.

The main command used for DQL is:

```sql
SELECT
```

### Simple meaning

Think of a table like a notebook containing information.

* **INSERT** → put new information into the notebook
* **UPDATE** → change existing information
* **DELETE** → remove information
* **SELECT** → read/search information

So:

> **DQL is mainly used to retrieve data from database tables.**

---

## 2. DQL Command

The important DQL command is:

| Command  | Purpose                               |
| -------- | ------------------------------------- |
| `SELECT` | To retrieve/display data from a table |

For example, if we have a `Bank` table, we can use `SELECT` to see its data.

---

## 3. Basic SELECT Syntax

### Question:

**How do you display all the records from a table?**

### Answer / Query:

```sql
SELECT * FROM Bank;
```

### Explanation

* `SELECT` → tells Oracle that we want to retrieve data.
* `*` → means **all columns**.
* `FROM` → tells Oracle from which table we want the data.
* `Bank` → table name.
* `;` → ends the SQL statement.

So:

```text
SELECT * FROM Bank;
      ↓       ↓
   What?    From where?
    All       Bank
   columns   table
```

---

## 4. Selecting Specific Columns

We do not always need every column.

### Question:

**How do you display only the `Bname` and `bhq` columns from the `Bank` table?**

### Answer / Query:

```sql
SELECT Bname, bhq
FROM Bank;
```

### Explanation

Here we are asking Oracle:

> "From the Bank table, give me only the bank name and headquarters."

---

## 5. DQL and DML Difference

| DML                | DQL                       |
| ------------------ | ------------------------- |
| Manipulates data   | Retrieves data            |
| `INSERT`           | `SELECT`                  |
| `UPDATE`           |                           |
| `DELETE`           |                           |
| Changes table data | Reads/displays table data |

### Easy memory trick

**DML → Modify**

**DQL → Query**

```text
DML
 ↓
Change the data

DQL
 ↓
Read the data
```

---

## 6. DDL, DML, DQL — Quick Comparison

| Language | Full Form                  | Main Purpose            | Commands                      |
| -------- | -------------------------- | ----------------------- | ----------------------------- |
| DDL      | Data Definition Language   | Defines table structure | CREATE, ALTER, TRUNCATE, DROP |
| DML      | Data Manipulation Language | Manipulates table data  | INSERT, UPDATE, DELETE        |
| DQL      | Data Query Language        | Retrieves table data    | SELECT                        |

### Remember

```text
DDL → Structure
DML → Data manipulation
DQL → Data retrieval
```

---

## 7. Important Point

`SELECT` **does not modify the table data**.

For example:

### Question:

**How do you retrieve all records from the `Bank` table without modifying them?**

### Answer / Query:

```sql
SELECT * FROM Bank;
```

This only **displays/retrieves** the data.

It does not:

* insert a row
* update a row
* delete a row
* change the table structure

---

## 8. Interview Questions

### Q1. What is DQL?

**Answer:**

> DQL stands for Data Query Language. It is used to retrieve or query data from database tables. The main command used in DQL is `SELECT`.

### Q2. Which command is used in DQL?

**Answer:**

> `SELECT` command.

### Q3. What does `*` mean in a SELECT statement?

**Answer:**

> `*` represents all columns.

### Q4. Does SELECT modify table data?

**Answer:**

> No. SELECT is used to retrieve/display data; it does not modify the table data.

### Q5. What is the difference between DML and DQL?

**Answer:**

> DML is used to manipulate table data using INSERT, UPDATE and DELETE, whereas DQL is used to retrieve data using SELECT.
