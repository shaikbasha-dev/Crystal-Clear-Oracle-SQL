# 09.3-Multirow-Functions

## 1. What are Multirow Functions?

Multirow Functions are also called:

* **Group Functions**
* **Aggregate Functions**

They work with **one or more rows** and produce **one result** for the group of rows.

The functions covered here are:

```text
COUNT()
SUM()
MAX()
MIN()
AVG()
```

### Very simple idea

Suppose salaries are:

```text
10000
20000
30000
```

A multirow function can take all these values together:

```text
10000 ─┐
20000 ─┼──→ Function ──→ One Result
30000 ─┘
```

For example:

```text
SUM() → 60000
MAX() → 30000
MIN() → 10000
AVG() → 20000
```

# 2. COUNT()

`COUNT()` is used to **count rows or values**.

---

## Query 1 — Count All Rows

### Question

**Write a query to display the count of all the rows present in the `EMP` table.**

### Answer / Query

```sql
SELECT COUNT(*)
FROM emp;
```

### Output

```text
COUNT(*)
--------
19
```



### Explanation

```sql
COUNT(*)
```

counts the rows present in the `EMP` table.

There are **19 rows**, so the result is:

```text
19
```

### Remember

```text
COUNT(*) → counts rows
```

---

## Query 2 — Count Distinct Salaries

### Question

**Write a query to display the count of distinct salaries in the `EMP` table.**

### Answer / Query

```sql
SELECT COUNT(DISTINCT salary)
FROM emp;
```

### Output

```text
COUNT(DISTINCT SALARY)
----------------------
16
```



### Explanation

Here:

```sql
DISTINCT salary
```

means duplicate salary values are considered only once.

For example, if:

```text
12000
12000
18000
18000
25000
```

then the distinct salaries are:

```text
12000
18000
25000
```

So the duplicates are not counted again.

# 3. MIN()

`MIN()` is used to find the **smallest value**.

---

## Query 3 — Minimum Salary

### Question

**Write a query to display the minimum of all the salaries from the `EMP` table.**

### Answer / Query

```sql
SELECT MIN(salary)
FROM emp;
```

### Output

```text
MIN(SALARY)
-----------
9500
```



### Explanation

Oracle looks at all the salaries and finds the smallest salary.

```text
9500
```

is the lowest salary.

---

## Query 4 — Minimum Salary Excluding Duplicates

### Question

**Write a query to display the minimum of all the salaries excluding duplicates.**

### Answer / Query

```sql
SELECT MIN(DISTINCT salary)
FROM emp;
```

### Output

```text
MIN(DISTINCT SALARY)
--------------------
9500
```



### Explanation

`DISTINCT` removes duplicate salary values before finding the minimum.

But remember:

```text
MIN(all salaries)
```

and

```text
MIN(distinct salaries)
```

give the same minimum when duplicates do not affect which value is smallest.

Here both give:

```text
9500
```

# 6. AVG()

`AVG()` is used to calculate the **average**.

The basic idea is:

```text
Average = Total ÷ Number of values
```

---

## Query 11 — Average Salary

### Question

**Write a query to display the average of all the salaries from the `EMP` table.**

### Answer / Query

```sql

FROM emp;
```

### Output

```text
AVG(SALARY)
-----------
35552.631578947368...
```



### Explanation

Oracle calculates the average of the salaries.

Conceptually:

```text
Total salary
     ÷
Number of salary values
     =
Average salary
```

# 8. What Does DISTINCT Mean with Aggregate Functions?

This is very important.

### Without DISTINCT

```sql
SUM(salary)
```

uses all salary values.

### With DISTINCT

```sql
SUM(DISTINCT salary)
```

uses each different salary value only once.

The same idea is shown in the notes for:

```sql
COUNT(DISTINCT salary)
MIN(DISTINCT salary)
MAX(DISTINCT salary)
SUM(DISTINCT salary)
AVG(DISTINCT salary)
```

# 9. All Multirow Functions at One Glance

| Function  | Meaning               |
| --------- | --------------------- |
| `COUNT()` | Counts                |
| `SUM()`   | Calculates total      |
| `MAX()`   | Finds highest/largest |
| `MIN()`   | Finds lowest/smallest |
| `AVG()`   | Calculates average    |

### Memory trick

```text
COUNT → How many?
SUM   → How much total?
MAX   → Highest?
MIN   → Lowest?
AVG   → Average?
```

# 10. Important Difference Between MIN/MAX with Dates

This is easy to remember:

```text
MIN(hire_date)
     ↓
Earliest hire date
     ↓
Oldest employee
```

and:

```text
MAX(hire_date)
     ↓
Latest hire date
```

So:

```text
MIN(date) → Oldest / Earliest
MAX(date) → Newest / Latest
```

# 11. COUNT(*) vs COUNT(column)

The notes specifically use:

```sql
COUNT(*)
```

for counting all rows.

And:

```sql
COUNT(DISTINCT salary)
```

for counting different salary values.

The main idea to remember from these examples is:

```text
COUNT(*)              → count rows
COUNT(DISTINCT salary) → count different salary values
```

# 12. Multirow Function Flow

Think of it like this:

```text
EMP TABLE
   ↓
Many rows
   ↓
Multirow Function
   ↓
One result
```

Examples:

```text
19 employee rows
      ↓
   COUNT(*)
      ↓
      19
```

```text
All salaries
      ↓
   SUM(salary)
      ↓
    675500
```

```text
      ↓

```

```text

      ↓
   MIN(salary)
      ↓
      9500
```

```text
All salaries
```

# 13. Common Confusion

### `MAX()` means maximum salary only?

No.

`MAX()` can be applied to other appropriate values too.

The notes demonstrate:

```sql
MAX(salary)
MAX(hire_date)
```

For salary:

```text
MAX → highest salary
```

For date:

```text
MAX → latest date
```

---

### `MIN()` means minimum salary only?

No.

The notes demonstrate:

```sql
MIN(salary)
MIN(hire_date)
```

For salary:

```text
MIN → lowest salary
```

For date:

```text
MIN → earliest date
```

---

### Does DISTINCT always change the result?

No.

For `MIN()` and `MAX()`, removing duplicate values usually does not change the minimum or maximum.

For example, the notes show:

```text
MIN(salary)          → 9500
MIN(DISTINCT salary) → 9500
```

and:

```text
MAX(salary)          → 85000
MAX(DISTINCT salary) → 85000
```

But for `SUM()` and `AVG()`, duplicates can change the result.
