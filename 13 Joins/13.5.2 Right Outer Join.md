# 13.5.2 Right Outer Join

## 1. What is a Right Outer Join?

A **Right Outer Join** combines two tables and returns:

> **All rows from the right table + only matching rows from the left table.**

This is the most important rule.

```text
LEFT TABLE                    RIGHT TABLE
    │                              │
    │                    ALL ROWS ─┤
    │                              │
    └──── matching rows ───────────┘
```

So, in a Right Outer Join:

```text
RIGHT TABLE → Keep ALL rows
LEFT TABLE  → Keep only MATCHING rows
```

---

# 2. Simple Example

Consider these two tables.

### Table 5 — Left Table

|  A |  B |
| -: | -: |
|  1 |  2 |
|  3 |  4 |
|  5 |  6 |
|  7 |  8 |

### Table 6 — Right Table

|  B |  C |
| -: | -: |
|  2 |  1 |
|  8 |  1 |
|  9 |  1 |

The common column is `B`.

Compare the values:

```text
Left B       Right B
------       -------
2       →    2    ✓
4       →    no   ✗
6       →    no   ✗
8       →    8    ✓
```

There is also:

```text
Right B = 9
```

There is no `9` in the left table.

But because this is a **Right Outer Join**, the row containing `9` must still be retained.

---

# 3. What does Right Outer Join keep?

Remember:

```text
RIGHT OUTER JOIN
       ↓
ALL RIGHT ROWS
       +
MATCHING LEFT ROWS
```

Therefore:

```text
2 → Match       → Keep
8 → Match       → Keep
9 → No match    → Still keep
```

The unmatched rows from the **right table** are preserved.

---

# 4. Syntax

### Question

**What is the syntax of a Right Outer Join?**

### Answer / Query

```sql
SELECT */attribute
FROM Table1
RIGHT OUTER JOIN Table2
ON Table1.B = Table2.B;
```



Here:

```text
Table1 → LEFT TABLE
Table2 → RIGHT TABLE
```

Therefore, all rows from `Table2` are preserved.

---

# 5. Short Syntax

The word `OUTER` can be omitted.

### Question

**Can we write Right Outer Join as Right Join?**

### Answer / Query

```sql
SELECT */attribute
FROM Table1
RIGHT JOIN Table2
ON Table1.B = Table2.B;
```

Both forms are used:

```sql
RIGHT OUTER JOIN
```

and

```sql
RIGHT JOIN
```

# 6. Output of the Example

### Question

**Perform a Right Outer Join between Table 5 and Table 6 using column `B`.**

### Answer / Query

```sql
SELECT *
FROM Table5
RIGHT OUTER JOIN Table6
ON Table5.B = Table6.B;
```

### Result

|  A |  B |  B |  C |
| -: | -: | -: | -: |
|  1 |  2 |  2 |  1 |
|  7 |  8 |  8 |  1 |
|  - |  - |  9 |  1 |

Notice the last row:

```text
-  -  9  1
```

Why is it present?

Because `9` belongs to the **right table**, and Right Outer Join keeps **all rows from the right table**. 

---

# 7. Understanding the `-`

Look at:

```text
A | B | B | C
- | - | 9 | 1
```

The right table has:

```text
B = 9
C = 1
```

But there is no matching row in the left table.

Therefore, there is no corresponding value for:

```text
A
B
```

from the left table.

So those positions have no matching data.

The important point is:

> **The right-side row is not removed just because there is no match on the left.**

# 8. EMP and DEPT Example

The common column between `EMP` and `DEPT` is:

```text
DEPT_ID
```

So the joining condition is:

```sql
EMP.DEPT_ID = DEPT.DEPT_ID
```

### Question

**Perform an EMP Right Outer Join with the DEPT table using DEPT_ID.**

### Answer / Query

```sql
SELECT *
FROM EMP
RIGHT OUTER JOIN DEPT
ON EMP.DEPT_ID = DEPT.DEPT_ID;
```

Here:

```text
EMP  → LEFT TABLE
DEPT → RIGHT TABLE
```

Therefore:

```text
ALL DEPT ROWS
      +
MATCHING EMP ROWS
```

The exact form of this query appears in the SQL material. 

---

# 9. Table Position is Very Important

Consider:

```sql
FROM EMP
RIGHT OUTER JOIN DEPT
```

Here:

```text
EMP  → LEFT
DEPT → RIGHT
```

Therefore:

```text
DEPT → ALL rows preserved
EMP  → Matching rows only
```

But if we change the order:

```sql
FROM DEPT
RIGHT OUTER JOIN EMP
```

then:

```text
DEPT → LEFT
EMP  → RIGHT
```

Now:

```text
EMP → ALL rows preserved
DEPT → Matching rows only
```

So always look at **which table comes after `RIGHT JOIN`**.

# 10. Right Join vs Left Join

This is a very common interview question.

### Left Outer Join

```sql
SELECT *
FROM EMP e
LEFT OUTER JOIN DEPT d
ON e.DEPT_ID = d.DEPT_ID;
```

```text
EMP  → ALL
DEPT → Matching
```

### Right Outer Join

```sql
SELECT *
FROM EMP e
RIGHT OUTER JOIN DEPT d
ON e.DEPT_ID = d.DEPT_ID;
```

```text
EMP  → Matching
DEPT → ALL
```

### Easy comparison

| Left Outer Join          | Right Outer Join          |
| ------------------------ | ------------------------- |
| All rows from left table | All rows from right table |
| Matching rows from right | Matching rows from left   |
| Left side is preserved   | Right side is preserved   |

---

# 11. Right Join vs Inner Join

### Inner Join

```sql
SELECT *
FROM EMP e
INNER JOIN DEPT d
ON e.DEPT_ID = d.DEPT_ID;
```

Only:

```text
MATCHING ROWS
```

are returned.

### Right Outer Join

```sql
SELECT *
FROM EMP e
RIGHT OUTER JOIN DEPT d
ON e.DEPT_ID = d.DEPT_ID;
```

Returns:

```text
ALL DEPT ROWS
+
MATCHING EMP ROWS
```

So:

```text
INNER JOIN
    ↓
Matching only

RIGHT OUTER JOIN
    ↓
All right + matching left
```

---

# 12. Important Rules

### Rule 1

Right Outer Join keeps **all rows from the right table**.

### Rule 2

It keeps only **matching rows from the left table**.

### Rule 3

The joining condition is written using `ON`.

Example:

```sql
ON EMP.DEPT_ID = DEPT.DEPT_ID
```

### Rule 4

`RIGHT JOIN` and `RIGHT OUTER JOIN` represent the same join form shown here.

# 13. Interview Questions

### Q1. What is a Right Outer Join?

**Answer:**
A Right Outer Join returns all rows from the right table and only matching rows from the left table.

### Q2. Which table is completely preserved?

**Answer:**
The **right table**.

### Q3. Does Right Outer Join return unmatched rows from the right table?

**Answer:**
**Yes.**

### Q4. Does it return unmatched rows from the left table?

**Answer:**
**No.**

### Q5. Can `RIGHT OUTER JOIN` be written as `RIGHT JOIN`?

**Answer:**
Yes.

```sql
RIGHT JOIN
```

can be used instead of:

```sql
RIGHT OUTER JOIN
```



### Q6. In this query, which table is preserved completely?

```sql
SELECT *
FROM EMP e
RIGHT OUTER JOIN DEPT d
ON e.DEPT_ID = d.DEPT_ID;
```

**Answer:**
`DEPT`, because it is the **right table**.

# 14. Easy Memory Trick

```text
RIGHT OUTER JOIN
       ↓
      RIGHT
       ↓
KEEP EVERYTHING
       ↓
   + MATCHING
      LEFT
```

### One-line definition

> **Right Outer Join = All rows from the right table + matching rows from the left table.**
