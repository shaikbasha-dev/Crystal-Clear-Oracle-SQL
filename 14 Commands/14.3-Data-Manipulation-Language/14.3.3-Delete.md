# 14.3.3-Delete

## 1. What is DELETE?

`DELETE` is a **DML (Data Manipulation Language) command**.

It is used to **delete or remove rows from a table**.

Simple idea:

```text
Existing Rows
     ↓
   DELETE
     ↓
Rows removed
```

The important point is:

> **DELETE removes rows, but the table structure remains.**

---

# 2. Why do we need DELETE?

Suppose the `Bank` table contains:

| BNAME      | BHQ       | BID |
| ---------- | --------- | --: |
| State bank | Hyderabad |   1 |
| Axis bank  | Mumbai    |   2 |
| HDFC       | Delhi     |   3 |

If we no longer need a particular row, we can remove it using `DELETE`.

For example:

```text
State bank
     ↓
  DELETE
     ↓
Row removed
```

---

# 3. Syntax

There are **two forms**.

### Syntax 1 — Delete all rows

```sql
DELETE FROM table_name;
```

### Syntax 2 — Delete particular rows

```sql
DELETE FROM table_name
WHERE condition;
```

These are the two DELETE syntaxes provided for this command. 

---

# 4. DELETE Particular Row

### Question

**Delete the row from the `Bank` table where `Bname` is `State bank`.**

### Query

```sql
DELETE FROM Bank
WHERE Bname = 'State bank';
```

This removes the row whose `Bname` matches `State bank`. 

### Before

| BNAME      | BHQ       | BID |
| ---------- | --------- | --: |
| State bank | Hyderabad |   1 |
| Axis bank  | Mumbai    |   2 |
| HDFC       | Delhi     |   3 |

### After

| BNAME     | BHQ    | BID |
| --------- | ------ | --: |
| Axis bank | Mumbai |   2 |
| HDFC      | Delhi  |   3 |

Only the matching row is removed.

---

# 5. Step-by-Step Execution

### Step 1 — Select the table

```text
BANK
```

### Step 2 — Specify DELETE

```text
DELETE FROM Bank
```

### Step 3 — Specify which row should be deleted

```text
WHERE Bname = 'State bank'
```

### Complete Query

### Question

**Delete the bank whose name is `State bank`.**

### Query

```sql
DELETE FROM Bank
WHERE Bname = 'State bank';
```

### Execution

```text
Bank
 ↓
Find Bname = 'State bank'
 ↓
Matching row found
 ↓
Remove that row
```

# 6. DELETE All Rows

We can also delete **all rows** from a table using `DELETE` without a `WHERE` condition.

### Question

**Delete all rows from the `Bank` table.**

### Query

```sql
DELETE FROM Bank;
```

This removes all rows from the table. 

### Before

| BNAME      | BHQ       | BID |
| ---------- | --------- | --: |
| State bank | Hyderabad |   1 |
| Axis bank  | Mumbai    |   2 |
| HDFC       | Delhi     |   3 |

### After

| BNAME | BHQ | BID |
| ----- | --- | --: |
|       |     |     |

The table still exists.

---

# 7. DELETE and WHERE

`WHERE` is used when we want to delete **particular rows**.

### Question

**Delete only the bank whose name is `State bank`.**

### Query

```sql
DELETE FROM Bank
WHERE Bname = 'State bank';
```

Think:

```text
WHERE
  ↓
Find required row
  ↓
DELETE
  ↓
Remove that row
```

---

## 8. What Happens Without WHERE?

This is very important.

### Question

**Delete all rows from the `Bank` table.**

### Query

```sql
DELETE FROM Bank;
```

Because there is no `WHERE` condition:

```text
All rows
   ↓
DELETE
   ↓
All rows removed
```

### Memory Trick

> **DELETE + WHERE → selected rows**
> **DELETE without WHERE → all rows**

---

# 9. DELETE vs TRUNCATE

Both can remove all rows, but they are different commands.

| DELETE                                    | TRUNCATE                     |
| ----------------------------------------- | ---------------------------- |
| DML command                               | DDL command                  |
| Removes rows                              | Removes all rows             |
| Can use `WHERE`                           | Cannot use `WHERE`           |
| `DELETE FROM table_name WHERE condition;` | `TRUNCATE TABLE table_name;` |
| Can target particular rows                | Removes all rows             |

### DELETE Particular Rows

### Question

**Delete the bank whose name is `State bank`.**

### Query

```sql
DELETE FROM Bank
WHERE Bname = 'State bank';
```

### TRUNCATE

### Question

**Remove all rows from `Bank`.**

### Query

```sql
TRUNCATE TABLE Bank;
```

### Easy Memory Trick

> **DELETE → Can select rows using WHERE**
> **TRUNCATE → Removes all rows at once**

---

# 10. DELETE vs DROP

| DELETE            | DROP                 |
| ----------------- | -------------------- |
| DML               | DDL                  |
| Removes rows      | Removes the table    |
| Table remains     | Table is removed     |
| Structure remains | Structure is removed |
| `DELETE FROM`     | `DROP TABLE`         |

### DELETE

### Question

**Delete all rows from `Bank`.**

### Query

```sql
DELETE FROM Bank;
```

Result:

```text
Rows → Removed
Table → Remains
```

### DROP

### Question

**Remove the `Bank` table completely.**

### Query

```sql
DROP TABLE Bank;
```

Result:

```text
Table → Removed
```

---

# 11. DELETE vs INSERT vs UPDATE

| Command  | What does it do?        |
| -------- | ----------------------- |
| `INSERT` | Adds rows               |
| `UPDATE` | Changes existing values |
| `DELETE` | Removes rows            |

Think of the three DML commands as:

```text
INSERT → Add
UPDATE → Change
DELETE → Remove
```

---

# 12. DELETE and COMMIT

`DELETE` is a DML operation.

DML actions are not permanent immediately. `COMMIT` is used to make DML actions permanent. 

### Question

**Delete the bank whose name is `State bank` and make the deletion permanent.**

### Query

```sql
DELETE FROM Bank
WHERE Bname = 'State bank';

COMMIT;
```

The flow is:

```text
DELETE
  ↓
Row removed
  ↓
COMMIT
  ↓
Change made permanent
```

---

# 13. Common Mistakes

### Mistake 1 — Forgetting `FROM`

❌

```sql
DELETE Bank
WHERE Bname = 'State bank';
```

✅

```sql
DELETE FROM Bank
WHERE Bname = 'State bank';
```

---

### Mistake 2 — Forgetting WHERE

If you intend to delete only one particular row:

❌

```sql
DELETE FROM Bank;
```

This targets **all rows**.

✅

```sql
DELETE FROM Bank
WHERE Bname = 'State bank';
```

---

### Mistake 3 — Confusing DELETE with DROP

❌ Thinking:

```sql
DELETE FROM Bank;
```

removes the table.

It doesn't.

It removes the rows, while the table remains.

---

# 14. Important Points

1. `DELETE` is a **DML command**.
2. It is used to remove rows from a table.
3. `WHERE` can be used to select particular rows.
4. Without `WHERE`, all rows are deleted.
5. The table structure remains after `DELETE`.
6. `COMMIT` can be used to make the DML action permanent.
7. `DELETE` is different from `TRUNCATE` and `DROP`.
