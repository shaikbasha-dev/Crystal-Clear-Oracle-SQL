# 16.7.3-Deleting-a-Synonym

## 1. What does Deleting a Synonym mean?

Deleting a Synonym means **removing an existing Synonym from the database**.

The command used is:

```text
DROP SYNONYM
```

It removes the **Synonym**, not the original table.

---

## 2. Syntax

### Question:

What is the syntax for deleting a Synonym?

### Answer / Syntax:

```sql
DROP SYNONYM synonym_name;
```

### Meaning

| Part           | Meaning                                |
| -------------- | -------------------------------------- |
| `DROP`         | Removes a database object              |
| `SYNONYM`      | Specifies that the object is a Synonym |
| `synonym_name` | Name of the Synonym to delete          |

The deletion syntax is `DROP SYNONYM synonym_name;`. 

---

# 3. Example

Earlier, we created:

```text
EMP
  ↑
  │
EMP_DETAILS
```

where `EMP_DETAILS` is the Synonym for `EMP`.

### Question:

How can you delete the Synonym named `emp_details`?

### Answer / Query:

```sql
DROP SYNONYM emp_details;
```

This removes the Synonym `emp_details`.

---

# 4. What Happens After Deleting the Synonym?

Before deletion:

```text
Actual Table
     ↓
    EMP
     ↑
     │
  Synonym
     │
EMP_DETAILS
```

Now execute:

### Question:

Delete the Synonym `emp_details`.

### Answer / Query:

```sql
DROP SYNONYM emp_details;
```

After deletion:

```text
Actual Table
     ↓
    EMP
```

The Synonym `EMP_DETAILS` no longer exists.

### Very important:

**The `EMP` table is not deleted.**

Only its Synonym is removed.

---

# 5. Synonym vs Original Table

Suppose:

```text
EMP             → Actual table
EMP_DETAILS     → Synonym
```

If we execute:

### Question:

Delete the Synonym `emp_details`.

### Answer / Query:

```sql
DROP SYNONYM emp_details;
```

Then:

| Object                | Status         |
| --------------------- | -------------- |
| `EMP` table           | ✅ Still exists |
| `EMP_DETAILS` Synonym | ❌ Removed      |

# 6. Creating and Deleting a Synonym

### Question:

Create a Synonym named `emp_details` for the `emp` table.

### Answer / Query:

```sql
CREATE SYNONYM emp_details
FOR emp;
```

Now:

```text
EMP
 ↑
 │
EMP_DETAILS
```

### Question:

Delete the Synonym named `emp_details`.

### Answer / Query:

```sql
DROP SYNONYM emp_details;
```

Now:

```text
EMP
```

The original table remains.

---

# 7. `DROP SYNONYM` vs `DROP TABLE`

This is an important interview difference.

| `DROP SYNONYM`              | `DROP TABLE`            |
| --------------------------- | ----------------------- |
| Deletes a Synonym           | Deletes a table         |
| Original table remains      | Table itself is removed |
| `DROP SYNONYM emp_details;` | `DROP TABLE emp;`       |

### Easy memory:

```text
DROP SYNONYM → Remove another name
DROP TABLE    → Remove the table
```

---

# 8. `DROP SYNONYM` vs `DROP SEQUENCE`

| Command         | Removes  |
| --------------- | -------- |
| `DROP SYNONYM`  | Synonym  |
| `DROP SEQUENCE` | Sequence |

### Question:

Which command removes the Synonym `emp_details`?

### Answer / Query:

```sql
DROP SYNONYM emp_details;
```

### Question:

Which command removes the Sequence `Dec`?

### Answer / Query:

```sql
DROP SEQUENCE Dec;
```

---

# 9. Important Points

* `DROP SYNONYM` is used to delete a Synonym.
* The Synonym name must be specified.
* Example:

```sql
DROP SYNONYM emp_details;
```

* Deleting a Synonym **does not delete the original table**.
* The original table continues to exist.
* Only the alternate name is removed.
