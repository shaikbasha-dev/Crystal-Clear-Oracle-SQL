# 14.5-Data-Control-Language-Overview

## 1. What is Data Control Language?

**DCL** stands for **Data Control Language**.

DCL commands are used to **control access to the data present in tables for users**. 

### Simple meaning

Imagine a company database.

There may be many users:

```text
Database
   │
   ├── User A
   ├── User B
   └── User C
```

We may want to decide:

* Who can access a table?
* Who can perform a particular operation?
* Who should no longer have that permission?

DCL is used for controlling these **permissions/privileges**.

---

# 2. DCL Commands

There are **two DCL commands**:

| Command  | Purpose                                    |
| -------- | ------------------------------------------ |
| `GRANT`  | Give permission/privilege to a user        |
| `REVOKE` | Take back permission/privilege from a user |



### Easy memory trick

```text
GRANT  → Give permission
REVOKE → Remove permission
```

---

# 3. What is a Privilege?

A **privilege** is a permission given to a user.

For example:

```text
User
  ↓
Permission
  ↓
Access to a table
```

The permission can be given and later taken back. 

---

# 4. Users and DCL

Before giving or taking privileges, the user needs to exist.

### Question:

**How do you create a user?**

### Answer / Query:

```sql
CREATE USER user_name IDENTIFIED BY password;
```



For example:

### Question:

**How do you create a user named `December` with password `December`?**

### Answer / Query:

```sql
CREATE USER December IDENTIFIED BY December;
```

This creates the user `December`. 

---

# 5. GRANT

`GRANT` is used to **give permission on a table to a user**. 

### Syntax

```sql
GRANT [privilege]
ON table_name
TO user_name;
```

### Understand the syntax

| Part          | Meaning                   |
| ------------- | ------------------------- |
| `GRANT`       | Give permission           |
| `[privilege]` | Permission being given    |
| `ON`          | Specifies the object      |
| `table_name`  | Table                     |
| `TO`          | Specifies the user        |
| `user_name`   | User receiving permission |

---

# 6. REVOKE

`REVOKE` is used to **take back a privilege from a user**.

### Syntax

```sql
REVOKE [privilege]
ON table_name
FROM user_name;
```



### Easy understanding

```text
GRANT
  ↓
Give permission

REVOKE
  ↓
Take back permission
```

---

# 7. Complete Example

### Question:

**How do you create the user `December`, give the user access to `emp`, take back that access, and then delete the user?**

### Answer / Query:

```sql
CREATE USER December IDENTIFIED BY December;

GRANT SELECT ON emp TO December;

REVOKE SELECT ON emp FROM December;

DROP USER December;
```

The sequence demonstrates creating the user, granting a privilege, revoking the privilege, and deleting the user. 

> **Correction:** The original example writes `GRANT SELECT ON emp FROM December;`. The correct GRANT syntax uses **`TO`**, so it is `GRANT SELECT ON emp TO December;`. 

---

# 8. DCL vs DQL

This is an important distinction:

| DCL                         | DQL                 |
| --------------------------- | ------------------- |
| Data Control Language       | Data Query Language |
| Controls access/permissions | Reads data          |
| `GRANT`                     | `SELECT`            |
| `REVOKE`                    | —                   |

DQL uses `SELECT` to query/read data from tables. 

---

# 9. DCL vs DML

| DCL                             | DML                          |
| ------------------------------- | ---------------------------- |
| Controls access                 | Manipulates data             |
| Works with users and privileges | Works with table rows/data   |
| `GRANT`, `REVOKE`               | `INSERT`, `UPDATE`, `DELETE` |

### Simple memory

```text
DCL → Control access
DML → Manipulate data
DQL → Query/read data
```

# 10. Interview Questions

### Q1. What is DCL?

**Answer:**

> DCL stands for Data Control Language. It is used to control access to data in tables for users.

### Q2. What are the DCL commands?

**Answer:**

> `GRANT` and `REVOKE`.

### Q3. What is GRANT?

**Answer:**

> GRANT is used to give permission on database objects such as tables to users.

### Q4. What is REVOKE?

**Answer:**

> REVOKE is used to take back a privilege from a user.

### Q5. What is a privilege?

**Answer:**

> A privilege is a permission given to a user to access or perform an operation on a database object.

### Q6. What is the difference between GRANT and REVOKE?

**Answer:**

> GRANT gives a privilege to a user, whereas REVOKE takes the privilege back.
