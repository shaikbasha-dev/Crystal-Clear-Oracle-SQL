# 14.2.2.6-Change-Data-Type-Size

## 1. What is Change Data Type Size?

Sometimes we do not want to change the **data type** of a column. We only want to change the **size** of that data type.

For example:

```text
BANK_NAME
VARCHAR2(50)
```

may need more space:

```text
BANK_NAME
VARCHAR2(97)
```

We can use `ALTER TABLE ... MODIFY` to change the size.

---

## 2. Why do we need it?

Suppose a column was created as:

```text
VARCHAR2(50)
```

but later we need to store longer values.

We can increase its size:

```text
VARCHAR2(50)
       ↓
VARCHAR2(97)
```

The data type remains:

```text
VARCHAR2
```

Only the **size** changes.

---

# 3. Syntax

### Question

**How can we change the size of a data type of an existing column?**

### Syntax

```sql
ALTER TABLE table_name
MODIFY column_name datatype(size);
```

### Syntax Explanation

| Part          | Meaning                            |
| ------------- | ---------------------------------- |
| `ALTER TABLE` | Modifies an existing table         |
| `table_name`  | Name of the table                  |
| `MODIFY`      | Modifies the column definition     |
| `column_name` | Column whose size is being changed |
| `datatype`    | Data type of the column            |
| `size`        | New size of the data type          |

---

# 4. Example

### Question

**Change the size of the `bank_name` column in `Bank_Details` to `VARCHAR2(97)`.**

### Query

```sql
ALTER TABLE Bank_Details
MODIFY bank_name VARCHAR2(97);
```

### Before

```text
BANK_NAME
VARCHAR2(50)
```

### After

```text
BANK_NAME
VARCHAR2(97)
```

So:

```text
VARCHAR2(50)
       ↓
   MODIFY
       ↓
VARCHAR2(97)
```

The **data type is still `VARCHAR2`**.

Only its size changed.

# 6. Data Type vs Data Type Size

This is very important.

### Change Data Type

Suppose:

```text
BID → NUMBER
```

and we want:

```text
BID → VARCHAR2(54)
```

### Question

**Modify the data type of `bid` to `VARCHAR2(54)`.**

### Query

```sql
ALTER TABLE Bank_Details
MODIFY bid VARCHAR2(54);
```

Here the **data type changes**.

```text
NUMBER
  ↓
VARCHAR2
```

---

### Change Data Type Size

Suppose:

```text
BANK_NAME → VARCHAR2(50)
```

and we want:

```text
BANK_NAME → VARCHAR2(97)
```

### Question

**Change the size of the `bank_name` column to `VARCHAR2(97)`.**

### Query

```sql
ALTER TABLE Bank_Details
MODIFY bank_name VARCHAR2(97);
```

Here:

```text
VARCHAR2
   ↓
VARCHAR2
```

The data type remains the same.

Only:

```text
50
 ↓
97
```

changes.

---

# 7. Easy Comparison

| Modify Data Type      | Change Data Type Size         |
| --------------------- | ----------------------------- |
| Changes the data type | Changes the size              |
| `NUMBER → VARCHAR2`   | `VARCHAR2(50) → VARCHAR2(97)` |
| Data type changes     | Data type remains the same    |
| Uses `MODIFY`         | Uses `MODIFY`                 |

### Memory Trick

> **Type changes → MODIFY datatype**
> **Size changes → MODIFY datatype(size)**

---

# 8. Common Mistake

### Mistake — Thinking `VARCHAR2(50)` and `VARCHAR2(97)` are different data types

They are both:

```text
VARCHAR2
```

The difference is only the **size**.

```text
VARCHAR2(50)
       ↑
     size

VARCHAR2(97)
       ↑
     size
```

**Which command is used to change the size of a column?**

### Answer

---

### Question 3

**Does changing `VARCHAR2(50)` to `VARCHAR2(97)` change the data type?**

### Answer

> No. The data type remains `VARCHAR2`; only its size changes.

---

### Question 4

**What is the difference between `VARCHAR2(50)` and `VARCHAR2(97)`?**

### Answer

> Both have the `VARCHAR2` data type, but the maximum specified size is different.
