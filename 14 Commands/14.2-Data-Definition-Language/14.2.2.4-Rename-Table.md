# 14.2.2.4-Rename-Table

## 1. What is RENAME TABLE?

**RENAME TABLE** is an operation performed using the `ALTER` command.

It is used to **change the name of an existing table**.

### Simple Example

Suppose we have a table:

```text
BANK
```

We want to change its name to:

```text
BANK_DETAILS
```

The table itself remains the same. Only its **name changes**.

```text
BANK
  ↓
RENAME
  ↓
BANK_DETAILS
```

---

## 2. Why do we need RENAME TABLE?

Sometimes an existing table name may not be suitable or may not clearly describe the table.

For example:

```text
BANK
```

can be renamed as:

```text
BANK_DETAILS
```

The **table name changes**, while the table and its data continue to exist.

---

# 3. Syntax

### Question

**How do you rename an existing table?**

### Syntax

```sql
ALTER TABLE table_name
RENAME TO new_table_name;
```

---

## 4. Syntax Explanation

| Part             | Meaning                                         |
| ---------------- | ----------------------------------------------- |
| `ALTER`          | Used to modify an existing table                |
| `TABLE`          | Specifies that we are working with a table      |
| `table_name`     | Existing table name                             |
| `RENAME TO`      | Specifies that the table name should be changed |
| `new_table_name` | New name of the table                           |
| `;`              | Ends the SQL statement                          |

### Easy memory

```text
ALTER TABLE
     ↓
OLD TABLE NAME
     ↓
RENAME TO
     ↓
NEW TABLE NAME
```

# 6. Step-by-Step Execution

Suppose the existing table is:

### Before

**Table name: `BANK`**

| BID | BNAME | BHQ       |
| --: | ----- | --------- |
|   1 | SBI   | Hyderabad |
|   2 | HDFC  | Mumbai    |

Now execute:

### Question

**Rename the `Bank` table to `Bank_Details`.**

### Query

```sql
ALTER TABLE Bank
RENAME TO Bank_Details;
```

### Step 1

Oracle identifies the existing table:

```text
BANK
```

### Step 2

`RENAME TO` tells Oracle that the table name must be changed.

### Step 3

The new name is:

```text
BANK_DETAILS
```

### After execution

The table is now called:

```text
BANK_DETAILS
```

Its data is still present:

| BID | BNAME | BHQ       |
| --: | ----- | --------- |
|   1 | SBI   | Hyderabad |
|   2 | HDFC  | Mumbai    |

So:

```text
Table name changes
        ↓
    BANK
        ↓
BANK_DETAILS

Data remains
        ↓
    unchanged
```

# 7. RENAME TABLE vs RENAME COLUMN

This is an important difference.

| RENAME TABLE                   | RENAME COLUMN           |
| ------------------------------ | ----------------------- |
| Changes the table name         | Changes the column name |
| Works on the entire table name | Works on one column     |
| `RENAME TO`                    | `RENAME COLUMN ... TO`  |
| `BANK → BANK_DETAILS`          | `BNAME → BANKNAME`      |

### Rename Table

### Question

**Rename the `Bank` table to `Bank_Details`.**

### Query

```sql
ALTER TABLE Bank
RENAME TO Bank_Details;
```

### Rename Column

### Question

**Rename the `bname` column to `bankname`.**

### Query

```sql
ALTER TABLE Bank
RENAME COLUMN bname TO bankname;
```

### Memory Trick

> **TABLE → change table name**
> **COLUMN → change column name**

---

# 8. RENAME TABLE vs DROP TABLE

Do not confuse these two.

| RENAME TABLE             | DROP TABLE                                 |
| ------------------------ | ------------------------------------------ |
| Changes the table name   | Removes the table                          |
| Table continues to exist | Table no longer exists                     |
| Data remains             | Table data is removed along with the table |
| Uses `RENAME TO`         | Uses `DROP TABLE`                          |

### Rename

### Question

**Change the name of `Bank` to `Bank_Details`.**

### Query

```sql
ALTER TABLE Bank
RENAME TO Bank_Details;
```

The table still exists.

### Drop

### Question

**Remove the `Bank_Details` table.**

### Query

```sql
DROP TABLE Bank_Details;
```

The table is removed.

---

# 9. Important Rules

| Rule | Explanation                               |
| ---- | ----------------------------------------- |
| 1    | The table must already exist              |
| 2    | Use `ALTER TABLE`                         |
| 3    | Use `RENAME TO`                           |
| 4    | Specify the old table name                |
| 5    | Specify the new table name                |
| 6    | Renaming does not mean dropping the table |
| 7    | The table's existing data remains         |

---

# 10. Common Mistakes

### Mistake 1 — Using `RENAME COLUMN`

If the requirement is to rename the **table**, don't use `RENAME COLUMN`.

❌

```sql
ALTER TABLE Bank
RENAME COLUMN Bank TO Bank_Details;
```

✅

```sql
ALTER TABLE Bank
RENAME TO Bank_Details;
```

---

### Mistake 2 — Using `DROP`

❌

```sql
DROP TABLE Bank;
```

This removes the table.

✅

```sql
ALTER TABLE Bank
RENAME TO Bank_Details;
```

This changes only the table name.

# 11. Interview Questions

### Question 1

**How do you rename a table?**

### Answer

Use:

```sql
ALTER TABLE old_table_name
RENAME TO new_table_name;
```

---

### Question 2

**Which command is used to rename an existing table?**

### Answer

> `ALTER TABLE ... RENAME TO` is used to rename an existing table.

---

### Question 3

**Does renaming a table remove its data?**

### Answer

> No. The table name changes, but the existing data remains.

---

### Question 4

**What is the difference between renaming a table and dropping a table?**

### Answer

> Renaming changes the table's name, whereas dropping removes the table.
