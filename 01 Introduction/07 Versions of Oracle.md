# Versions of Oracle

Oracle has released different versions over the years.

### Oracle versions and their years

| Oracle Version | Year |
| -------------- | ---: |
| **Oracle 1**   | 1978 |
| **Oracle 2**   | 1979 |
| **Oracle 3**   | 1983 |
| **Oracle 4**   | 1984 |
| **Oracle 5**   | 1985 |
| **Oracle 6**   | 1988 |
| **Oracle 7**   | 1992 |
| **Oracle 8**   | 1997 |
| **Oracle 8i**  | 1999 |
| **Oracle 9i**  | 2001 |
| **Oracle 10g** | 2004 |
| **Oracle 11g** | 2007 |
| **Oracle 12c** | 2013 |
| **Oracle 18c** | 2018 |
| **Oracle 19c** | 2019 |
