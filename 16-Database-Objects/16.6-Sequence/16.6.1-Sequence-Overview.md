# 16.6.1-Sequence-Overview

## 1. What is a Sequence?

A **Sequence** is a database object that is used to **generate automatic numbers** for a specified column.



### Simple example

Suppose we have employee IDs:

```text
1
2
3
4
5
...
```

Instead of manually entering every number, a **Sequence** can generate these numbers automatically.

```text
Sequence
   ↓
1
2
3
4
5
6
...
```

---

## 2. Why do we need a Sequence?

Imagine inserting many records into a table.

Without a Sequence:

```text
Insert employee 1 → manually enter 1
Insert employee 2 → manually enter 2
Insert employee 3 → manually enter 3
Insert employee 4 → manually enter 4
```

This becomes difficult when there are many records.

With a Sequence:

```text
Sequence
   ↓
1 → 2 → 3 → 4 → 5 → ...
```

The numbers can be generated automatically.

---

## 3. Simple Real-Life Example

Think about a **token counter** at a bank.

```text
Customer 1 → Token 1
Customer 2 → Token 2
Customer 3 → Token 3
Customer 4 → Token 4
```

Nobody has to decide the next number manually.

A Sequence works in a similar way:

```text
Sequence
   ↓
Next number
   ↓
Next number
   ↓
Next number
```

---

# 4. Main Purpose of Sequence

The main purpose is:

> **To generate automatic numbers for a specified column.**

For example, an ID column:

```text
ID
---
1
2
3
4
5
```

The Sequence can generate the values for the ID.

---

# 5. Important Sequence Keywords

Two important keywords are associated with a Sequence:

| Keyword   | Meaning                                  |
| --------- | ---------------------------------------- |
| `NEXTVAL` | Generates the next value in the Sequence |
| `CURRVAL` | Gives the current value of the Sequence  |

### Easy memory

```text
NEXTVAL
   ↓
NEXT number

CURRVAL
   ↓
CURRENT number
```

These are the two Sequence values/keywords covered in the topic. 

---

# 6. Sequence Flow

A simple Sequence flow is:

```text
CREATE SEQUENCE
       ↓
Sequence is created
       ↓
NEXTVAL
       ↓
Next number is generated
       ↓
Use the number
       ↓
NEXTVAL
       ↓
Next number
```

For example:

```text
1st NEXTVAL → 1
2nd NEXTVAL → 2
3rd NEXTVAL → 3
4th NEXTVAL → 4
```

---

# 7. Sequence Example

A Sequence can be created with a starting value and an increment value.

### Question:

Create a Sequence named `Dec` that starts with `1` and increases by `1`.

### Answer / Query:

```sql
CREATE SEQUENCE Dec
START WITH 1
INCREMENT BY 1;
```

### Explanation

Here:

| Part              | Meaning                     |
| ----------------- | --------------------------- |
| `CREATE SEQUENCE` | Creates a Sequence          |
| `Dec`             | Sequence name               |
| `START WITH 1`    | First value starts from `1` |
| `INCREMENT BY 1`  | Increases by `1` each time  |

So the generated values will follow:

```text
1 → 2 → 3 → 4 → 5 → ...
```

---

# 8. Sequence Syntax

### Question:

What is the syntax for creating a Sequence?

### Answer / Syntax:

```sql
CREATE SEQUENCE sequence_name
START WITH start_value
INCREMENT BY increment_value;
```

The same structure is used for the Sequence creation syntax. 

---

# 9. Sequence and Table

A Sequence itself does **not mean that a table column automatically receives values**.

The generated value can be used when inserting data.

For example:

```text
Sequence
   ↓
NEXTVAL
   ↓
Generated number
   ↓
INSERT into table
```

This is why `NEXTVAL` is important when working with a Sequence.

---

# 10. Sequence vs Normal Number

| Normal number                           | Sequence                            |
| --------------------------------------- | ----------------------------------- |
| Entered manually                        | Generated automatically             |
| User has to decide the number           | Sequence generates the number       |
| More manual work                        | Less manual work                    |
| Example: `1`, `2`, `3` entered manually | Example: `NEXTVAL` generates values |

---

# 11. Sequence vs Identity of a Table

For this topic, remember the simple idea:

```text
Sequence → Database object
```

It generates numbers that can be used for table data, such as IDs.

---

# 12. Important Points to Remember

* A **Sequence is a database object**.
* It generates **automatic numbers**.
* It can be given a starting value.
* It can be given an increment value.
* `NEXTVAL` generates the **next value**.
* `CURRVAL` represents the **current value**.
* A Sequence can be used while inserting values into a table.
* A Sequence can also be deleted using `DROP SEQUENCE`.
