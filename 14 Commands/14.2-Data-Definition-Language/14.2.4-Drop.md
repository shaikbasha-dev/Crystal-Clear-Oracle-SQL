# 14.2.4-Drop

## 1. What is DROP?

`DROP` is a **DDL command**.

It is used to **delete a table, database, or database object**.

For a table:

```sql
DROP TABLE table_name;
```

The important point is:

> **DROP removes the table itself, not just the rows.**

---

## 2. Why do we use DROP?

Suppose we have a table:

```text
BANK_DETAILS
```

and we no longer need this table.

We can remove it using `DROP`.

```text
BANK_DETAILS
     ↓
    DROP
     ↓
Table removed
```

After dropping the table, the table structure and its data are no longer available as that table.

---

# 3. Syntax

### Question

**What is the syntax for dropping a table?**

### Syntax

```sql
DROP TABLE table_name;
```

### Syntax Explanation

| Part         | Meaning                              |
| ------------ | ------------------------------------ |
| `DROP`       | Removes the database object          |
| `TABLE`      | Specifies that the object is a table |
| `table_name` | Name of the table to be removed      |
| `;`          | Ends the statement                   |

# 6. DROP vs TRUNCATE

This is very important.

| DROP                     | TRUNCATE                     |
| ------------------------ | ---------------------------- |
| Removes the table        | Removes all rows             |
| Table does not remain    | Table remains                |
| Structure is removed     | Structure remains            |
| Data is removed          | Data is removed              |
| `DROP TABLE table_name;` | `TRUNCATE TABLE table_name;` |

### DROP

### Question

**Remove the `Bank_Details` table completely.**

### Query

```sql
DROP TABLE Bank_Details;
```

Result:

```text
BANK_DETAILS → Removed
```

### TRUNCATE

### Question

**Remove all rows from `Bank_Details` but keep the table.**

### Query

```sql
TRUNCATE TABLE Bank_Details;
```

Result:

```text
Rows       → Removed
Table      → Remains
Structure  → Remains
```

### Memory Trick

> **DROP → Remove the table**
> **TRUNCATE → Empty the table**

# 7. DROP vs DELETE

| DROP                          | DELETE                               |
| ----------------------------- | ------------------------------------ |
| DDL command                   | DML command                          |
| Removes the table             | Removes rows                         |
| Table structure is removed    | Table structure remains              |
| Can remove the complete table | Can remove selected rows or all rows |
| `DROP TABLE`                  | `DELETE FROM`                        |

### DROP

### Question

**Remove the `Bank_Details` table.**

### Query

```sql
DROP TABLE Bank_Details;
```

### DELETE

### Question

**Delete the employee whose `emp_id` is 101.**

### Query

```sql
DELETE FROM emp
WHERE emp_id = 101;
```

The `emp` table still exists.

---

# 8. DROP vs DROP CONSTRAINT

These are also different.

| DROP TABLE        | DROP CONSTRAINT                   |
| ----------------- | --------------------------------- |
| Removes the table | Removes only a constraint         |
| Table is removed  | Table remains                     |
| `DROP TABLE`      | `ALTER TABLE ... DROP CONSTRAINT` |

### Drop Table

### Question

**Remove the `Bank_Details` table.**

### Query

```sql
DROP TABLE Bank_Details;
```

### Drop Constraint

### Question

**Remove the constraint named `b_pk` from `Bank_Details`.**

### Query

```sql
ALTER TABLE Bank_Details
DROP CONSTRAINT b_pk;
```

---

# 9. Important Points

### 1. DROP is a DDL command

```text
DDL
 ↓
DROP
```

### 2. DROP removes the table

It is different from `TRUNCATE`, which keeps the table structure.

### 3. DROP removes the table's data and structure

The table is no longer available after the drop operation.

### 4. Use the correct table name

The table must be specified correctly.

---

# 10. Common Mistakes

### Mistake 1 — Confusing DROP with TRUNCATE

❌ Thinking:

```sql
DROP TABLE Bank_Details;
```

only removes the rows.

It does **not**. It removes the table.

---

### Mistake 2 — Using DELETE when the requirement is to remove the table

❌

```sql
DELETE FROM Bank_Details;
```

This removes rows, but the table remains.

✅

```sql
DROP TABLE Bank_Details;
```

This removes the table.

---

### Mistake 3 — Forgetting `TABLE`

For dropping a table, use:

```sql
DROP TABLE Bank_Details;
```
