# 13.9 All Queries Related to Joins

Below are **all the Join-related practice queries appearing in the Join section**, with the **question immediately followed by the answer/query**. I have not skipped the Cross Join, Natural Join, Outer Join, Self Join, or EMP–DEPT queries.  

---

## 1. Inner Join

### Question:

**Write a query to display all the details from Table1 and Table2 where the value of column2 in Table1 is equal to the value of column2 in Table2.**

### Answer:

```sql
SELECT *
FROM Table1
INNER JOIN Table2
ON Table1.B = Table2.B;
```

**Meaning:** Only the rows where `Table1.B` and `Table2.B` match are returned. 

---

## 2. Natural Join

### Question:

**Write a query to display all the details from Table1 and Table2 where the value of column2 in Table1 is equal to the value of column2 in Table2 by using Natural Join keyword.**

### Answer:

```sql
SELECT *
FROM Table1
NATURAL JOIN Table2;
```

**Meaning:** Oracle automatically uses columns having the same name to perform the join. No `ON` condition is written. 

---

## 3. Left Outer Join

### Question:

**Display all the details from Table1 and Table2 by using Left Outer Join keyword.**

### Answer:

```sql
SELECT *
FROM Table1
LEFT JOIN Table2
ON Table1.B = Table2.B;
```

**Meaning:** All rows from `Table1` are returned, along with matching rows from `Table2`. 

---

## 4. Right Outer Join

### Question:

**Write a query to display all the details from Table1 and Table2 by using Right Outer Join keyword.**

### Answer:

```sql
SELECT *
FROM Table1
RIGHT JOIN Table2
ON Table1.B = Table2.B;
```

**Meaning:** All rows from `Table2` are returned, along with matching rows from `Table1`. 

---

## 5. Full Outer Join

### Question:

**Write a query to display all the details from Table1 and Table2 by using Full Outer Join keyword.**

### Answer:

```sql
SELECT *
FROM Table1
FULL OUTER JOIN Table2
ON Table1.B = Table2.B;
```

**Meaning:** Matching and non-matching rows from **both tables** are returned. 

---

## 6. Cross Join

### Question:

**Write a query to display all the details from Table1 and Table2 by using Cross Join keyword.**

### Query shown in the PDF:

```sql
SELECT *
FROM Table1
CROSS JOIN Table2
ON Table1.B = Table2.B;
```

### ⚠️ Correction

The above query contains an `ON` condition after `CROSS JOIN`.

For the Cross Join concept, the correct query is:

```sql
SELECT *
FROM Table1
CROSS JOIN Table2;
```

A Cross Join produces every possible combination of rows and does not require a join condition.

# EMP and DEPT Join Queries

## 7. Inner Join — EMP and DEPT

### Question:

**Write a query to display the emp_id, f_name, salary and dept_name for all the employees whose dept_id in the EMP table is equal to the dept_id in the DEPT table using Inner Join keyword.**

### Answer:

```sql
SELECT emp_id, f_name, salary, dept_name
FROM emp
INNER JOIN dept
ON emp.dept_id = dept.dept_id;
```

**Meaning:**

```text
EMP.DEPT_ID = DEPT.DEPT_ID
```

Only employees having a matching department are returned. 

---

## 8. Natural Join — EMP and DEPT

### Question:

**Give an example to perform Natural Join.**

### Answer:

```sql
SELECT *
FROM emp
NATURAL JOIN dept;
```

**Meaning:** `EMP` and `DEPT` contain the common column `DEPT_ID`, so Oracle uses that common column automatically.

## 9. Cross Join — EMP and DEPT

### Question:

**Perform EMP table Cross Join with DEPT table.**

### Answer:

```sql
SELECT *
FROM emp
CROSS JOIN dept;
```

**Meaning:** Every employee row is combined with every department row.

**Meaning:** All employees are displayed. If an employee has a matching department, department information is also displayed.

### Answer:

## 13. Fill in the Missing Part — Left Outer Join

### Question:

**Insert the missing parts in the JOIN clause to join the two tables EMP and DEPT, using the dept_id field in both tables as the relationship between the two tables.**

### Query shown:

```sql
SELECT *
FROM emp e
LEFT OUTER JOIN dept d
e.dept_id = d.dept_id;
```

### Answer / Correct Query:

```sql
SELECT *
FROM emp e
LEFT OUTER JOIN dept d
ON e.dept_id = d.dept_id;
```

### Missing keyword:

```text
ON
```

So the important pattern is:

```sql
LEFT OUTER JOIN dept d
ON e.dept_id = d.dept_id;
```

The `ON` keyword is missing in the original query. 

---

## 14. Choose the Correct JOIN Clause — Inner Join

### Question:

**Choose the correct JOIN clause to select all records from the two tables where there is a match in both tables.**

### Answer:

```sql
SELECT *
FROM emp e
INNER JOIN dept c
ON e.dept_id = c.dept_id;
```

**Why?**

The requirement says:

> **match in both tables**

That means we need an **INNER JOIN**.

# Self Join Query

## 15. Self Join — EMP with EMP

### Question:

**Display the first name, last name and salary of employees whose salary is greater than the salary of Pandey.**

### Answer:

```sql
SELECT f.F_name, f.L_name, f.Salary
FROM Emp e, Emp f
WHERE f.Salary > e.Salary
AND e.F_name = 'Pandey';
```

### How it works:

```text
EMP e → used to identify Pandey
EMP f → used to find employees earning more than Pandey
```

The same `EMP` table is therefore used twice.

# Join Queries — Quick Revision

| No. | Requirement                                | Join             |
| --: | ------------------------------------------ | ---------------- |
|   1 | Matching records from two tables           | Inner Join       |
|   2 | Matching common-name columns automatically | Natural Join     |
|   3 | All rows from Table1                       | Left Outer Join  |
|   4 | All rows from Table2                       | Right Outer Join |
|   5 | All rows from both tables                  | Full Outer Join  |
|   6 | Every row × every row                      | Cross Join       |
|   7 | EMP + DEPT matching `DEPT_ID`              | Inner Join       |
|   8 | EMP + DEPT automatically                   | Natural Join     |
|   9 | Every EMP × every DEPT                     | Cross Join       |
|  10 | All EMP records + matching DEPT            | Left Outer Join  |
|  11 | All DEPT records + matching EMP            | Right Outer Join |
|  12 | All EMP + all DEPT                         | Full Outer Join  |
|  13 | Fill missing JOIN keyword                  | `ON`             |
|  14 | Matching records from both tables          | Inner Join       |
|  15 | EMP compared with itself                   | Self Join        |
