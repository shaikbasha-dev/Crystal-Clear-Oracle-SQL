# 14.5.1-Grant

## 1. What is GRANT?

`GRANT` is a **DCL command**.

It is used to **give permission/privilege on a table in the database to a user**. 

### Simple meaning

Think of a database like an office.

```text
Database
   ↓
Table
   ↓
User
   ↓
Permission
```

`GRANT` means:

> **Give this user permission to access/use this database object.**

---

# 2. Why do we need GRANT?

Suppose a user named `December` exists.

We may want to give that user permission to access the `emp` table.

So we use `GRANT`.

```text
GRANT
  ↓
Give permission
  ↓
To a user
  ↓
On a table
```

---

# 3. Syntax of GRANT

### Question:

**What is the syntax of the GRANT command?**

### Answer / Query:

```sql
GRANT [privilege]
ON table_name
TO user_name;
```

The important parts are:

| Part          | Meaning                                 |
| ------------- | --------------------------------------- |
| `GRANT`       | Give permission                         |
| `[privilege]` | Permission being given                  |
| `ON`          | Specifies the database object           |
| `table_name`  | Name of the table                       |
| `TO`          | Specifies the user receiving permission |
| `user_name`   | Name of the user                        |



---

# 4. Example of GRANT

### Question:

**How do you give `SELECT` permission on the `emp` table to the user `December`?**

### Answer / Query:

```sql
GRANT SELECT
ON emp
TO December;
```

### Understand it step by step

```text
GRANT
  ↓
Give permission

SELECT
  ↓
Permission to read/select data

ON emp
  ↓
On the EMP table

TO December
  ↓
To the DECEMBER user
```

So the complete meaning is:

> **Give SELECT permission on the EMP table to DECEMBER.**

---

# 5. GRANT Example with User Creation

A user must first exist before privileges are given to that user.

### Question:

**How do you create the user `December` and give the user SELECT permission on the `emp` table?**

### Answer / Query:

```sql
CREATE USER December IDENTIFIED BY December;

GRANT SELECT
ON emp
TO December;
```

The user is created first, and then the privilege is granted. 

---

# 6. Important Syntax Point

Remember this carefully:

### GRANT uses `TO`

```sql
GRANT SELECT ON emp TO December;
```

### REVOKE uses `FROM`

```sql
REVOKE SELECT ON emp FROM December;
```

### Memory trick

```text
GRANT  → TO
REVOKE → FROM
```

This is an important syntax difference.

---

# 7. GRANT vs REVOKE

| GRANT                                       | REVOKE                                         |
| ------------------------------------------- | ---------------------------------------------- |
| Gives permission                            | Takes back permission                          |
| Uses `TO`                                   | Uses `FROM`                                    |
| Example: `GRANT SELECT ON emp TO December;` | Example: `REVOKE SELECT ON emp FROM December;` |

---

# 8. Important Point

`GRANT` is **not used to insert or modify table data**.

It controls **user privileges/access**.

```text
INSERT
  ↓
Manipulates data

UPDATE
  ↓
Manipulates data

DELETE
  ↓
Manipulates data

GRANT
  ↓
Controls permission
```

---

# 9. Correction to the Example

There is an important syntax correction.

The example appears as:

```sql
GRANT SELECT ON emp FROM December;
```

That is incorrect for `GRANT`.

The correct syntax is:

```sql
GRANT SELECT ON emp TO December;
```

The general GRANT syntax also confirms that the user follows `TO`.

# 10. Interview Questions

### Q1. What is GRANT?

**Answer:**

> GRANT is a DCL command used to give permission or privileges on database objects such as tables to users.

### Q2. What is the purpose of GRANT?

**Answer:**

> GRANT is used to provide permissions to users for accessing database objects.

### Q3. What keyword is used with GRANT to specify the user?

**Answer:**

> `TO`.

### Q4. Write the syntax of GRANT.

**Answer:**

```sql
GRANT [privilege]
ON table_name
TO user_name;
```

### Q5. Write a query to give SELECT permission on EMP to DECEMBER.

**Answer:**

```sql
GRANT SELECT ON emp TO December;
```

```text
  │
  ├── ON → table/object
  │
  └── TO → user
```
