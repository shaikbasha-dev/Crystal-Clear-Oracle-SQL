# 14.2.3-Truncate

## 1. What is TRUNCATE?

`TRUNCATE` is a **DDL command**.

It is used to **remove all rows from a table in a single operation**.

The important point is:

> **TRUNCATE removes the data (rows), but the table structure remains.**

### Simple idea

```text
BANK_DETAILS
     ↓
  TRUNCATE
     ↓
All rows removed
     ↓
BANK_DETAILS still exists
```

---

## 2. Why do we use TRUNCATE?

Suppose a table contains many records:

| BID | BNAME | BHQ       |
| --: | ----- | --------- |
|   1 | SBI   | Hyderabad |
|   2 | HDFC  | Mumbai    |
|   3 | ICICI | Delhi     |
|   4 | Axis  | Chennai   |

If we want to remove **all records at once**, we can use `TRUNCATE`.

After truncation:

|         BID | BNAME | BHQ |
| ----------: | ----- | --- |
| *(no rows)* |       |     |

But the table structure still exists:

```text
BANK_DETAILS
├── BID
├── BNAME
└── BHQ
```

---

# 3. Syntax

### Question

**What is the syntax for truncating a table?**

### Syntax

```sql
TRUNCATE TABLE table_name;
```

### Syntax Explanation

| Part         | Meaning                              |
| ------------ | ------------------------------------ |
| `TRUNCATE`   | Removes all rows                     |
| `TABLE`      | Specifies that the target is a table |
| `table_name` | Name of the table                    |
| `;`          | Ends the statement                   |

```sql

```

### Step 3 — Oracle removes all rows

```text
Row 1  → removed

```

```text

```

```text

```

# 6. TRUNCATE vs DROP

This is one of the most important differences.

| TRUNCATE                          | DROP                     |
| --------------------------------- | ------------------------ |
| Removes all rows                  | Removes the table        |
| Table remains                     | Table is removed         |
| Structure remains                 | Structure is removed     |
| Table can still be used afterward | Table no longer exists   |
| `TRUNCATE TABLE table_name;`      | `DROP TABLE table_name;` |

### TRUNCATE

### Question

**Remove all records from `Bank_Details`, but keep the table.**

### Query

```sql
TRUNCATE TABLE Bank_Details;
```

### DROP

### Question

**Remove the `Bank_Details` table itself.**

### Query

```sql
DROP TABLE Bank_Details;
```

### Memory Trick

> **TRUNCATE → Empty the table**
> **DROP → Remove the table**

---

# 7. TRUNCATE vs DELETE

Both can remove rows, but they are different commands.

| TRUNCATE                                 | DELETE                                    |
| ---------------------------------------- | ----------------------------------------- |
| DDL command                              | DML command                               |
| Removes all rows                         | Can remove selected rows or all rows      |
| No `WHERE` condition                     | Can use `WHERE`                           |
| `TRUNCATE TABLE table_name;`             | `DELETE FROM table_name WHERE condition;` |
| Used to remove all rows in one operation | Used when row-level deletion is required  |

### Example of TRUNCATE

### Question

**Remove all rows from `Bank_Details`.**

### Query

```sql
TRUNCATE TABLE Bank_Details;
```

---

### Example of DELETE with condition

### Question

**Delete the employee whose `emp_id` is 101.**

### Query

```sql
DELETE FROM emp
WHERE emp_id = 101;
```

Only the matching row is targeted.

---

### DELETE without condition

### Question

**Delete all rows from the `Bank_Details` table using DELETE.**

### Query

```sql
DELETE FROM Bank_Details;
```

This also removes all rows, but it is a **DELETE operation**, not `TRUNCATE`.

# 8. Important Point — Table Structure Remains

Suppose the table was created as:

```text
BANK_DETAILS
```

with:

```text
BID
BANK_NAME
BHQ
```

After:

### Question

**Remove all rows from `Bank_Details` using TRUNCATE.**

### Query

```sql
TRUNCATE TABLE Bank_Details;
```

The data is removed, but we can still use the table:

```text
BANK_DETAILS
├── BID
├── BANK_NAME
└── BHQ
```

So `TRUNCATE` does **not** mean deleting the table.

---

# 9. Common Mistakes

### Mistake 1 — Writing `WHERE`

❌

```sql
TRUNCATE TABLE Bank_Details
WHERE BID = 1;
```

`TRUNCATE` does not use a `WHERE` condition.

If you need to remove selected rows, use `DELETE`.

---

### Mistake 2 — Confusing TRUNCATE with DROP

❌ Thinking:

```sql
TRUNCATE TABLE Bank_Details;
```

removes the table.

It does not.

It removes the **rows** and keeps the table structure.

---

### Mistake 3 — Forgetting `TABLE`

Use:

```sql
TRUNCATE TABLE Bank_Details;
```
