# 16.3.4-Creating-an-Index

## 1. What does Creating an Index mean?

Creating an Index means creating a **data structure on one or more columns of a table** to help retrieve data faster.

The basic flow is:

```text id="c5s7hx"
Table
  ↓
Select column(s)
  ↓
Create Index
  ↓
Faster data retrieval
```

---

# 2. Syntax

### Question:

What is the syntax for creating an Index?

### Answer / Syntax:

```sql id="5b3h7p"
CREATE INDEX index_name
ON table_name(column_name1, column_name2);
```



### Syntax Explanation

| Part           | Meaning                                |
| -------------- | -------------------------------------- |
| `CREATE INDEX` | Creates an Index                       |
| `index_name`   | Name given to the Index                |
| `ON`           | Specifies the table                    |
| `table_name`   | Name of the table                      |
| `column_name1` | First column on which Index is created |
| `column_name2` | Second column, if required             |

The syntax allows one or more columns to be specified. 

---

# 3. Example from the Topic

### Question:

Create an Index named `dec` on the `dept_id` column of the `emp` table.

### Answer / Query:

```sql id="u6b1nc"
CREATE INDEX dec
ON emp(dept_id);
```



---

---

# 5. What is the benefit?

Suppose `dept_id` is frequently used for retrieving employee information.

### Question:

Retrieve employees whose department ID is 22.

### Query:

```sql id="s5j0rd"
SELECT *
FROM emp
WHERE dept_id = 22;
```

If `dept_id` is an appropriate column for indexing, the Index can help Oracle retrieve the required data faster.

The main purpose of an Index is to **speed up SELECT queries and retrieve data faster**.

# 6. Creating an Index on Multiple Columns

The syntax also allows multiple columns:

### Question:

What is the syntax for creating an Index using two columns?

### Answer / Query:

```sql id="v7q6y2"
CREATE INDEX index_name
ON table_name(column_name1, column_name2);
```

For example:

```text id="3q5b6f"
CREATE INDEX
      ↓
table_name
      ↓
column1 + column2
```

The syntax provided supports specifying `colname1, colname2`. 

---

# 7. Important Points

### Point 1

`CREATE INDEX` is used to create an Index.

### Point 2

An Index is created **on a table**.

### Point 3

We specify the column or columns inside parentheses.

### Point 4

The Index helps with faster data retrieval.

### Point 5

The suitability of an Index depends on factors such as:

```text
Large data
+
Frequently used condition column
+
Table not updated frequently
```

# 8. Common Confusion

### Index name vs Column name

In:

```sql id="6w9b4s"
CREATE INDEX dec
ON emp(dept_id);
```

| Item        | Value     |
| ----------- | --------- |
| Index name  | `dec`     |
| Table name  | `emp`     |
| Column name | `dept_id` |

So **`dec` is not the column name**.
