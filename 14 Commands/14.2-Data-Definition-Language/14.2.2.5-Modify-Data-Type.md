# 14.2.2.5-Modify-Data-Type

## 1. What is MODIFY DATA TYPE?

`MODIFY` is an operation of the `ALTER` command.

It is used to **change the data type of an existing column** in a table.

For example, suppose a column is:

```text
BID → NUMBER
```

We can modify it to:

```text
BID → VARCHAR2(54)
```

The basic syntax is:

```sql
ALTER TABLE table_name
MODIFY column_name datatype;
```

---

## 2. Why do we need MODIFY DATA TYPE?

When a column was created with a particular data type, sometimes we may need to change that data type later.

For example:

```text
BID
NUMBER
```

may need to become:

```text
BID
VARCHAR2(54)
```

We use `ALTER TABLE ... MODIFY` for this.

---

# 3. Syntax

### Question

**How can we modify the data type of an existing column?**

### Syntax

```sql
ALTER TABLE table_name
MODIFY column_name datatype;
```

### Syntax Explanation

| Part          | Meaning                                  |
| ------------- | ---------------------------------------- |
| `ALTER`       | Used to modify an existing table         |
| `TABLE`       | Specifies the table                      |
| `table_name`  | Name of the existing table               |
| `MODIFY`      | Used to modify a column definition       |
| `column_name` | Column whose definition is being changed |
| `datatype`    | New data type                            |
| `;`           | Ends the SQL statement                   |

---

# 4. Important Condition

A very important point is:

> **The column to be modified must be empty to change its data type.**

In other words, if the column contains data, changing its data type may not be possible.

### Simple Example

Suppose:

```text
BID
NUMBER
```

and the column is empty.

We can modify it to:

```text
BID
VARCHAR2(54)
```

---

# 5. Example

### Question

**Modify the data type of the `bid` column in the `Bank_Details` table from its existing type to `VARCHAR2(54)`.**

### Query

```sql
ALTER TABLE Bank_Details
MODIFY bid VARCHAR2(54);
```

### Before

| Column | Data Type |
| ------ | --------- |
| `BID`  | `NUMBER`  |

### After

| Column | Data Type      |
| ------ | -------------- |
| `BID`  | `VARCHAR2(54)` |

So:

```text
BID
NUMBER
  ↓
MODIFY
  ↓
VARCHAR2(54)
```

# 7. `MODIFY DATA TYPE` vs `RENAME COLUMN`

These two operations are different.

| MODIFY DATA TYPE        | RENAME COLUMN           |
| ----------------------- | ----------------------- |
| Changes the data type   | Changes the column name |
| Uses `MODIFY`           | Uses `RENAME COLUMN`    |
| `NUMBER → VARCHAR2(54)` | `BID → BANK_ID`         |

### Modify Data Type

### Question

**Change the data type of `bid` to `VARCHAR2(54)`.**

### Query

```sql
ALTER TABLE Bank_Details
MODIFY bid VARCHAR2(54);
```

### Rename Column

### Question

**Change the column name `bid` to `bank_id`.**

### Query

```sql
ALTER TABLE Bank_Details
RENAME COLUMN bid TO bank_id;
```

### Memory Trick

> **MODIFY → Change the column definition/data type**
> **RENAME → Change the name**

---

# 8. MODIFY DATA TYPE vs CHANGE SIZE

These are closely related but should not be confused.

### Modify Data Type

### Question

**Change the data type of the `bid` column to `VARCHAR2`.**

### Query

```sql
ALTER TABLE Bank_Details
MODIFY bid VARCHAR2(54);
```

Here, the **data type** is being specified/changed.

### Change Size

### Question

**Change the size of the `bank_name` column to `VARCHAR2(97)`.**

### Query

```sql
ALTER TABLE Bank_Details
MODIFY bank_name VARCHAR2(97);
```

Here, the modification includes the **size** of the `VARCHAR2` column.

The next topic deals specifically with changing the data type size.

# 9. Common Mistakes

### Mistake 1 — Forgetting `MODIFY`

❌

```sql
ALTER TABLE Bank_Details
bid VARCHAR2(54);
```

✅

```sql
ALTER TABLE Bank_Details
MODIFY bid VARCHAR2(54);
```

---

### Mistake 2 — Using `RENAME COLUMN`

❌

```sql
ALTER TABLE Bank_Details
RENAME COLUMN bid TO VARCHAR2(54);
```

`RENAME COLUMN` is for changing a **column name**, not its data type.

✅

```sql
ALTER TABLE Bank_Details
MODIFY bid VARCHAR2(54);
```

---

### Mistake 3 — Trying to modify a column containing data

If the column contains data, the modification may fail depending on the requested conversion.

For the example being studied, remember:

> **The column to be modified must be empty to change its data type.**
