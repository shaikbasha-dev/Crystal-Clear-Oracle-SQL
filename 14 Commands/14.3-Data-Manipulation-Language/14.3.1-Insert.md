# 14.3.1-Insert

## 1. What is INSERT?

`INSERT` is a **DML (Data Manipulation Language) command**.

It is used to **insert data into a table as rows**.

The DML commands are:

```text
DML
│
├── INSERT
├── UPDATE
└── DELETE
```

DML commands work with the **rows of a table**, and the DML actions are not permanent until they are handled with transaction control commands such as `COMMIT`. 

---

# 2. Why do we need INSERT?

Suppose we have an empty table:

```text
BANK
```

We want to add a bank record:

```text
State bank
Hyderabad
1
```

We use `INSERT`.

```text
Table
  ↓
INSERT
  ↓
New row added
```

---

# 3. Types of INSERT Syntax

There are **two forms** given here.

### Syntax 1 — Insert values into all columns

```sql
INSERT INTO table_name
VALUES(value1, value2, value3);
```

### Syntax 2 — Specify the columns

```sql
INSERT INTO table_name(column1, column2)
VALUES(value1, value2);
```

These two syntaxes are given for the `INSERT` command. 

---

# 4. INSERT INTO All Columns

### Question

**How do you insert values into a table when values are being supplied for all columns?**

### Syntax

```sql
INSERT INTO table_name
VALUES(value1, value2, value3);
```

### Meaning

If the table has three columns:

```text
Column 1
Column 2
Column 3
```

then the values are supplied in the corresponding order:

```text
value1 → Column 1
value2 → Column 2
value3 → Column 3
```

---

# 5. Example from the Topic

### Question

**Insert the values `State bank`, `Hyderabad`, and `1` into the `Bank` table.**

### Query

```sql
INSERT INTO Bank
VALUES('State bank', 'Hyderabad', 1);
```

The example uses these three values with the `Bank` table. 

### Result

A new row is inserted:

| BNAME      | BHQ       | BID |
| ---------- | --------- | --: |
| State bank | Hyderabad |   1 |

### Step-by-step

```text
'State bank'
     ↓
Column 1

'Hyderabad'
     ↓
Column 2

1
     ↓
Column 3
```

So one complete row is inserted into the table.

---

# 6. INSERT by Specifying Column Names

The second syntax allows us to explicitly mention the columns.

### Question

**How do you insert values by specifying the column names?**

### Syntax

```sql
INSERT INTO table_name(column1, column2)
VALUES(value1, value2);
```

For example, if we want to insert into only two specified columns:

```sql
INSERT INTO Bank(bname, bhq)
VALUES('State bank', 'Hyderabad');
```

Here the column names tell Oracle where the supplied values should go.

```text
BNAME              BHQ
  ↓                 ↓
'State bank'     'Hyderabad'
```

---

# 7. Difference Between the Two INSERT Syntaxes

| All columns                                          | Specified columns                                     |
| ---------------------------------------------------- | ----------------------------------------------------- |
| Column names are not written                         | Column names are written                              |
| Values are supplied for the table's columns in order | Values are supplied for the specified columns         |
| `INSERT INTO table_name VALUES(...)`                 | `INSERT INTO table_name(column1,column2) VALUES(...)` |

### Form 1

### Question

**Insert values into the table without specifying column names.**

### Query

```sql
INSERT INTO Bank
VALUES('State bank', 'Hyderabad', 1);
```

### Form 2

### Question

**Insert values into specified columns of the `Bank` table.**

### Query

```sql
INSERT INTO Bank(bname, bhq)
VALUES('State bank', 'Hyderabad');
```

---

# 8. Important Point — Order of Values

When using:

```sql
INSERT INTO Bank
VALUES(...);
```

the values correspond to the table's columns in their defined order.

For example:

```text
Column 1 ← Value 1
Column 2 ← Value 2
Column 3 ← Value 3
```

So we must provide the values in the correct order.

# 10. INSERT vs CREATE

Do not confuse these commands.

| INSERT          | CREATE                   |
| --------------- | ------------------------ |
| DML             | DDL                      |
| Adds data       | Creates the table/object |
| Works with rows | Defines structure        |
| `INSERT INTO`   | `CREATE TABLE`           |

### CREATE

### Question

**Create a `Bank` table with columns `bid`, `bname`, and `bhq`.**

### Query

```sql
CREATE TABLE Bank
(
    bid INT,
    bname VARCHAR2(87),
    bhq VARCHAR2(46)
);
```

### INSERT

### Question

**Insert a bank record into the existing `Bank` table.**

### Query

```sql
INSERT INTO Bank
VALUES('State bank', 'Hyderabad', 1);
```

Think:

```text
CREATE
  ↓
Creates the table

INSERT
  ↓
Adds data into the table
```

---

# 11. INSERT vs UPDATE

| INSERT              | UPDATE                           |
| ------------------- | -------------------------------- |
| Adds a new row      | Changes existing data            |
| Used to insert data | Used to update data              |
| `INSERT INTO`       | `UPDATE`                         |
| Creates a new row   | Modifies values in existing rows |

### INSERT

### Question

**Add a new bank record.**

### Query

```sql
INSERT INTO Bank
VALUES('State bank', 'Hyderabad', 1);
```

### UPDATE

### Question

**Change the bank name from `Axis bank` to `Bank of Baroda`.**

### Query

```sql
UPDATE Bank
SET Bname = 'Bank of Baroda'
WHERE Bname = 'Axis bank';
```

---

# 12. INSERT vs DELETE

| INSERT        | DELETE          |
| ------------- | --------------- |
| Adds rows     | Removes rows    |
| `INSERT INTO` | `DELETE FROM`   |
| Data is added | Data is removed |

### INSERT

### Question

**Insert a bank record into `Bank`.**

### Query

```sql
INSERT INTO Bank
VALUES('State bank', 'Hyderabad', 1);
```

### DELETE

### Question

**Delete the bank whose name is `State bank`.**

### Query

```sql
DELETE FROM Bank
WHERE Bname = 'State bank';
```

# 13. INSERT and COMMIT

An important point in DML is that the action is **not permanent immediately**.

The DML commands are:

```text
INSERT
UPDATE
DELETE
```

and `COMMIT` is used to make DML actions permanent. 

### Question

**Insert a bank record and then make the insertion permanent.**

### Query

```sql
INSERT INTO Bank
VALUES('State bank', 'Hyderabad', 1);

COMMIT;
```

The idea is:

```text
INSERT
  ↓
Data changed
  ↓
COMMIT
  ↓
Change made permanent
```

# 14. Common Mistakes

### Mistake 1 — Forgetting `INTO`

❌

```sql
INSERT Bank
VALUES('State bank', 'Hyderabad', 1);
```

✅

```sql
INSERT INTO Bank
VALUES('State bank', 'Hyderabad', 1);
```

---

### Mistake 2 — Forgetting quotes around character data

Character values should be written as strings.

❌

```sql
INSERT INTO Bank
VALUES(State bank, Hyderabad, 1);
```

✅

```sql
INSERT INTO Bank
VALUES('State bank', 'Hyderabad', 1);
```

---

### Mistake 3 — Putting values in the wrong order

When using:

```sql
INSERT INTO Bank
VALUES(...);
```

the values must correspond to the table's columns in their proper order.
