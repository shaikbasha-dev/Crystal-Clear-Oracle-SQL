# 14.4.1-Select

## 1. What is SELECT?

`SELECT` is the **DQL command** used to **fetch/read data from tables**.

In simple words:

> **SELECT means: "Show me the data."** 

---

## 2. Why do we use SELECT?

Suppose an `EMP` table contains employee information.

If we want to see the data stored in that table, we use `SELECT`.

```text
Table
  ↓
SELECT
  ↓
Data is fetched/displayed
```

`SELECT` does **not** insert, update, or delete the data.

---

## 3. Basic SELECT Syntax

### Question:

**What is the syntax to fetch all data from a table?**

### Answer / Query:

```sql
SELECT * FROM table_name;
```

### Meaning of each part

| Part         | Meaning              |
| ------------ | -------------------- |
| `SELECT`     | Fetch/read data      |
| `*`          | All columns          |
| `FROM`       | Specifies the table  |
| `table_name` | Name of the table    |
| `;`          | End of SQL statement |

So:

```sql
SELECT * FROM table_name;
```

means:

> **Fetch all columns from the specified table.**

---

# 4. SELECT Example

### Question:

**How do you fetch/read all the data from the `emp` table?**

### Answer / Query:

```sql
SELECT * FROM emp;
```

This displays the data present in the `emp` table. 

### Simple execution

```text
SELECT
   ↓
I want to read data

*
   ↓
I want all columns

FROM
   ↓
From which table?

emp
   ↓
EMP table

Result
   ↓
All data from EMP table
```

---

## 5. SELECT Specific Columns

A `SELECT` statement can also be used to retrieve particular columns instead of all columns.

### Question:

**How do you display only the `name` column from the `student` table?**

### Answer / Query:

```sql
SELECT name FROM student;
```

This retrieves only the `name` column.

### Question:

**How do you display `name`, `age`, and `gender` from the `student` table?**

### Answer / Query:

```sql
SELECT name, age, gender
FROM student;
```

This retrieves only those three columns. 

---

## 6. `SELECT *` vs Specific Columns

| Query                             | Meaning                          |
| --------------------------------- | -------------------------------- |
| `SELECT * FROM emp;`              | Fetch all columns                |
| `SELECT f_name FROM emp;`         | Fetch only `f_name`              |
| `SELECT f_name, salary FROM emp;` | Fetch only `f_name` and `salary` |

### Easy memory trick

```text
SELECT * 
   ↓
Everything

SELECT column1, column2
   ↓
Only selected columns
```

---

## 7. SELECT with WHERE

`SELECT` can also retrieve only the rows that satisfy a condition.

### Question:

**How do you display the name of the student whose age is 22?**

### Answer / Query:

```sql
SELECT name
FROM student
WHERE age = 22;
```

The `WHERE` condition restricts which rows are returned. 

### Question:

**How do you display the details of students whose gender is male?**

### Answer / Query:

```sql
SELECT *
FROM student
WHERE gender = 'Male';
```

# 8. Two Important Parts of Retrieving Data

The retrieval section introduces two ideas:

### 1. Selection

> Fetching data from the table by eliminating certain rows.

Example:

```sql
SELECT *
FROM student
WHERE marks > 60;
```

Only rows satisfying the condition are returned. 

### 2. Projection

> Fetching data from the table **without eliminating rows**, by selecting the required columns.

Example:

```sql
SELECT name, age, gender
FROM student;
```

Here the selected columns are `name`, `age`, and `gender`. 

### Easy way to remember

```text
SELECTION
   ↓
Controls ROWS

PROJECTION
   ↓
Controls COLUMNS
```

---

# 9. Important Rules

### Rule 1

`SELECT` is used to **read/fetch data**.

### Rule 2

`*` means **all columns**.

### Rule 3

`FROM` specifies the table from which data is retrieved.

### Rule 4

Specific column names can be written instead of `*`.

### Rule 5

`WHERE` can be used to restrict the rows returned.

---

# 10. Common Confusion

### ❌ Wrong understanding

> `SELECT` changes the table.

### ✅ Correct understanding

> `SELECT` only retrieves/displays data.

---

### ❌ Wrong

```sql
SELECT emp;
```

### ✅ Correct

```sql
SELECT * FROM emp;
```

Because Oracle needs to know **what to select** and **from which table**.

# 11. Interview Questions

### Q1. What is SELECT?

**Answer:**

> SELECT is a DQL command used to fetch or read data from database tables.

### Q2. What does `*` mean in SELECT?

**Answer:**

> `*` represents all columns.

### Q3. What is the basic syntax of SELECT?

**Answer:**

```sql
SELECT * FROM table_name;
```

### Q4. Can SELECT retrieve specific columns?

**Answer:**

> Yes. We can specify the required column names after `SELECT`.

Example:

```sql
SELECT f_name, salary
FROM emp;
```

### Q5. Can SELECT be used with WHERE?

**Answer:**

> Yes. `WHERE` can be used with SELECT to restrict the rows based on a condition.

---

# 12. Interview-Ready Answer

> **SELECT is the DQL command used to fetch or read data from database tables. The basic syntax is `SELECT * FROM table_name;`, where `*` represents all columns. We can also specify particular columns and use conditions such as WHERE to retrieve required rows.**
