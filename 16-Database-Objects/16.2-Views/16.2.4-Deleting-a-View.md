# 16.2.4-Deleting-a-View

## 1. What does Deleting a View mean?

Deleting a View means **removing the View from the database**.

If a View is no longer required, we can delete it using the `DROP VIEW` command.

The important point is:

> **`DROP VIEW` deletes the View itself.**

---

## 2. Syntax

### Question:

What is the syntax for deleting a View?

### Answer / Query:

```sql
DROP VIEW view_name;
```

Here:

* `DROP VIEW` → tells Oracle to delete a View.
* `view_name` → name of the View that we want to delete.



---

# 3. Example

Earlier, we created a View named `dec`.

### Question:

Delete the View named `dec`.

### Answer / Query:

```sql
DROP VIEW dec;
```



### Query Explanation:

```text
DROP VIEW
    ↓
   dec
```

* `DROP VIEW` → deletion command for a View.
* `dec` → the name of the View being deleted.

After successful execution, the View `dec` is removed from the database.

---

# 4. What happens after deleting the View?

Suppose we had:

```text
EMP TABLE
   ↓
 VIEW DEC
```

After:

```sql
DROP VIEW dec;
```

the structure becomes:

```text
EMP TABLE
   ↓
 VIEW DEC ❌
```

The View `dec` no longer exists.

The original `emp` table remains.

### Important:

> **Deleting a View does not mean deleting the original table.**

---

# 5. Complete View Flow

We can remember the three operations together:

```text id="v6f3q8"
        VIEW
         │
    ┌────┼────┐
    ↓    ↓    ↓
 CREATE FETCH DROP
    │    │     │
    ↓    ↓     ↓
   dec  data  delete dec
```

### Create

```sql
CREATE VIEW dec
AS
SELECT f_name, salary, dept_id
FROM emp
WHERE dept_id = 22;
```

### Fetch

```sql
SELECT * FROM dec;
```

### Delete

```sql
DROP VIEW dec;
```

# 6. View Commands — Quick Revision

| Operation       | Command       |
| --------------- | ------------- |
| Create View     | `CREATE VIEW` |
| Fetch View data | `SELECT`      |
| Delete View     | `DROP VIEW`   |

---

# 7. Common Confusion

### `DROP VIEW` vs `DROP TABLE`

| `DROP VIEW`               | `DROP TABLE`               |
| ------------------------- | -------------------------- |
| Deletes a View            | Deletes a table            |
| Used for virtual table    | Used for actual table      |
| Example: `DROP VIEW dec;` | Example: `DROP TABLE emp;` |

So remember:

```text
DROP VIEW  → View
DROP TABLE → Table
```
