# 14.2.2.2-Drop-Column

## 1. What is DROP COLUMN?

**DROP COLUMN** is an operation of the `ALTER` command.

It is used to **remove an existing column from a table**.

### Simple idea

Suppose we have:

| BID | BNAME | BHQ       | PH_NO      |
| --: | ----- | --------- | ---------- |
|   1 | SBI   | Hyderabad | 9876543210 |
|   2 | HDFC  | Mumbai    | 9123456780 |

If we no longer need the `PH_NO` column, we can remove it using `ALTER TABLE ... DROP COLUMN`.

After dropping it:

| BID | BNAME | BHQ       |
| --: | ----- | --------- |
|   1 | SBI   | Hyderabad |
|   2 | HDFC  | Mumbai    |

---

# 2. Why do we need DROP COLUMN?

Sometimes a column is no longer required in a table.

For example:

```text
BANK
│
├── BID
├── BNAME
├── BHQ
└── PH_NO   ← No longer required
```

We can remove only that column instead of deleting the entire table.

```text
Existing Table
      ↓
ALTER TABLE
      ↓
DROP COLUMN
      ↓
Column removed
```

---

# 3. Syntax

### Question

**How do we remove a column from an existing table?**

### Syntax

```sql
ALTER TABLE table_name
DROP COLUMN column_name;
```

---

## 4. Syntax Explanation

| Syntax Part   | Meaning                                  |
| ------------- | ---------------------------------------- |
| `ALTER`       | Used to modify an existing table         |
| `TABLE`       | Specifies that a table is being modified |
| `table_name`  | Name of the existing table               |
| `DROP`        | Specifies removal                        |
| `COLUMN`      | Specifies that a column is being removed |
| `column_name` | Name of the column to remove             |
| `;`           | End of the SQL command                   |

### Remember

```text
ALTER TABLE
     ↓
Which table?
     ↓
DROP COLUMN
     ↓
Which column?
```

---

# 5. Example

### Question

**Drop the `ph_no` column from the `Bank` table.**

### Query

```sql
ALTER TABLE Bank
DROP COLUMN ph_no;
```

---

# 6. Step-by-Step Execution

Suppose the table currently has:

| BID | BNAME | BHQ       | PH_NO      |
| --: | ----- | --------- | ---------- |
|   1 | SBI   | Hyderabad | 9876543210 |
|   2 | HDFC  | Mumbai    | 9123456780 |
|   3 | ICICI | Delhi     | 9988776655 |

We execute:

```sql
ALTER TABLE Bank
DROP COLUMN ph_no;
```

### Step 1

Oracle identifies the existing table:

```text
BANK
```

### Step 2

Oracle sees:

```text
DROP COLUMN PH_NO
```

### Step 3

Oracle removes the `PH_NO` column from the table structure.

### Step 4

The remaining table becomes:

| BID | BNAME | BHQ       |
| --: | ----- | --------- |
|   1 | SBI   | Hyderabad |
|   2 | HDFC  | Mumbai    |
|   3 | ICICI | Delhi     |

The `PH_NO` column is no longer part of the table.

---

# 7. Important Point

`DROP COLUMN` removes a **column**, not the entire table.

### Example

```sql
ALTER TABLE Bank
DROP COLUMN ph_no;
```

Result:

```text
BANK table → Still exists
PH_NO      → Removed
```

---

# 8. DROP COLUMN vs DROP TABLE

This is a very important difference.

| DROP COLUMN              | DROP TABLE               |
| ------------------------ | ------------------------ |
| Removes one column       | Removes the entire table |
| Table continues to exist | Table itself is removed  |
| Uses `ALTER TABLE`       | Uses `DROP TABLE`        |
| Changes table structure  | Removes the table/object |

### Example — Remove a column

```sql
ALTER TABLE Bank
DROP COLUMN ph_no;
```

### Example — Remove the entire table

```sql
DROP TABLE Bank;
```

### Easy memory

> **DROP COLUMN → Remove one column**
> **DROP TABLE → Remove the whole table**

---

# 9. DROP COLUMN vs DELETE

| DROP COLUMN             | DELETE                  |
| ----------------------- | ----------------------- |
| Removes a column        | Removes rows            |
| Changes table structure | Manipulates table data  |
| DDL operation           | DML command             |
| Column disappears       | Table structure remains |

### Example

**Remove a column:**

```sql
ALTER TABLE Bank
DROP COLUMN ph_no;
```

**Remove a row:**

```sql
DELETE FROM Bank
WHERE bid = 1;
```

So:

```text
DROP COLUMN → Column
DELETE       → Row
```

# 10. Common Mistakes

### Mistake 1 — Forgetting `COLUMN`

❌

```sql
ALTER TABLE Bank
DROP ph_no;
```

For the syntax being studied here, use:

✅

```sql
ALTER TABLE Bank
DROP COLUMN ph_no;
```

---

### Mistake 2 — Using DELETE to remove a column

❌

```sql
DELETE FROM Bank
WHERE ph_no = ...;
```

`DELETE` works with **rows**, not columns.

To remove a column:

✅

```sql
ALTER TABLE Bank
DROP COLUMN ph_no;
```

---

### Mistake 3 — Using DROP TABLE

❌

```sql
DROP TABLE Bank;
```

This removes the **entire table**, not just `PH_NO`.

---

# 11. Important Rules

| Rule | Explanation                          |
| ---- | ------------------------------------ |
| 1    | The table must already exist         |
| 2    | Use `ALTER TABLE`                    |
| 3    | Use `DROP COLUMN` to remove a column |
| 4    | Specify the column name              |
| 5    | The table itself is not removed      |

# 12. Interview Questions

### Question 1

**How do you drop a column from an existing table?**

### Answer

```sql
ALTER TABLE table_name

```

---

### Question 2

**Which command is used to remove a column from an existing table?**

### Answer

> `ALTER TABLE ... DROP COLUMN` is used to remove a column from an existing table.

---

### Question 3

**Does DROP COLUMN delete the entire table?**

### Answer

> No. It removes only the specified column. The table continues to exist.

---

### Question 4

**What is the difference between DELETE and DROP COLUMN?**

### Answer

> `DELETE` removes rows from a table, whereas `DROP COLUMN` removes a column from the table structure.
