# 16.5.4-After-Insert-Trigger

## 1. What is an AFTER INSERT Trigger?

An **AFTER INSERT Trigger** is a Trigger whose action is executed **after a new row has been inserted into a table**.

Break the name into two parts:

```text
AFTER  → When?
INSERT → Which event?
```

So:

```text
INSERT happens
      ↓
AFTER INSERT Trigger executes
      ↓
Trigger Action
```

Triggers are prepared SQL statements saved in the database and called autonomously when the specified event occurs.

---

## 2. Why do we call it AFTER INSERT?

Because the **INSERT operation happens first**, and the Trigger's action happens afterward.

```text
BEFORE INSERT

Trigger Action
      ↓
INSERT
```

Whereas:

```text
AFTER INSERT

INSERT
      ↓
Trigger Action
```

### Easy memory

> **BEFORE INSERT → Trigger first, INSERT next**
> **AFTER INSERT → INSERT first, Trigger next**

---

## 3. General Syntax

### Question:

What is the syntax for creating an AFTER INSERT Trigger?

### Answer / Syntax:

```sql
CREATE TRIGGER trigger_name
AFTER INSERT
ON table_name
FOR EACH ROW
BEGIN
    SQL Query;
END;
```

The Trigger syntax uses the timing (`BEFORE`/`AFTER`) and event (`INSERT`/`UPDATE`/`DELETE`) together. 

---

## 4. Understanding the Syntax

| Part             | Meaning                          |
| ---------------- | -------------------------------- |
| `CREATE TRIGGER` | Creates a Trigger                |
| `trigger_name`   | Name of the Trigger              |
| `AFTER`          | Action occurs after the event    |
| `INSERT`         | Event that activates the Trigger |
| `ON table_name`  | Table where INSERT occurs        |
| `FOR EACH ROW`   | Applies to each affected row     |
| `BEGIN`          | Starts Trigger body              |
| `SQL Query`      | Action performed by Trigger      |
| `END`            | Ends Trigger                     |

---

# 5. Example

### Question:

Create an AFTER INSERT Trigger named `dec` on `table1` that inserts the newly inserted `id` and `name` into `table2`.

### Answer / Query:

```sql
CREATE TRIGGER dec
AFTER INSERT
ON table1
FOR EACH ROW
BEGIN
    INSERT INTO table2 VALUES(:NEW.id, :NEW.name);
END;
```

The Trigger example uses `:NEW` for the values of the newly inserted row. 

---

# 6. Understanding `:NEW`

For an INSERT event, the relevant row reference is:

```text
INSERT → :NEW
```

So:

```sql
:NEW.id
```

means the newly inserted `id`.

And:

```sql
:NEW.name
```

means the newly inserted `name`.

The row-reference mapping is:

| Event  | Reference      |
| ------ | -------------- |
| INSERT | `:NEW`         |
| UPDATE | `:OLD`, `:NEW` |
| DELETE | `:OLD`         |



---

# 7. Execution Flow

Suppose we insert:

### Question:

Insert a new row into `table1`.

### Answer / Query:

```sql
INSERT INTO table1 VALUES(2, 'B');
```

Because an **AFTER INSERT** Trigger exists:

```text
INSERT INTO table1
       ↓
Row is inserted
       ↓
AFTER INSERT Trigger
       ↓
:NEW.id   = 2
:NEW.name = B
       ↓
Trigger Action executes
       ↓
INSERT into table2
```

The important point is that the Trigger action occurs **after** the INSERT event.

---

# 8. BEFORE INSERT vs AFTER INSERT

| BEFORE INSERT                              | AFTER INSERT                               |
| ------------------------------------------ | ------------------------------------------ |
| Trigger action occurs before INSERT        | Trigger action occurs after INSERT         |
| INSERT is the event                        | INSERT is the event                        |
| Timing = BEFORE                            | Timing = AFTER                             |
| `:NEW` is associated with the inserted row | `:NEW` is associated with the inserted row |

### Visual memory

```text
BEFORE INSERT

BEFORE Trigger
      ↓
   INSERT


AFTER INSERT

   INSERT
      ↓
AFTER Trigger
```

---

# 9. Event and Action

### Question:

In an AFTER INSERT Trigger, what are the event and action?

### Answer:

**Event:**

```text
INSERT
```

**Timing:**

```text
AFTER
```

**Action:**

```text
The SQL statement written inside the Trigger body.
```

Therefore:

```text
AFTER INSERT
     ↓
INSERT event occurs
     ↓
Trigger action executes
```

---

# 10. Important Points

* `AFTER INSERT` is one of the six Trigger combinations.
* `AFTER` specifies the timing.
* `INSERT` specifies the event.
* The INSERT happens first.
* The Trigger action happens afterward.
* `:NEW` is associated with INSERT.  
* A Trigger is stored in the database and executes autonomously.

# 11. Interview Questions

### Q1. What is an AFTER INSERT Trigger?

**Answer:**
It is a Trigger whose action executes after an INSERT event occurs on the specified table.

### Q2. What is the event in an AFTER INSERT Trigger?

**Answer:**

```text
INSERT
```

### Q3. What does `AFTER` specify?

**Answer:**
It specifies that the Trigger action executes after the INSERT event.

### Q4. Which reference is associated with INSERT?

**Answer:**

```text
:NEW
```

### Q5. Give the syntax of an AFTER INSERT Trigger.

**Answer:**

```sql
CREATE TRIGGER trigger_name
AFTER INSERT
ON table_name
FOR EACH ROW
BEGIN
    SQL Query;
END;
```

### Q6. What is the difference between BEFORE INSERT and AFTER INSERT?

**Answer:**

```text
BEFORE INSERT → Trigger action → INSERT

AFTER INSERT  → INSERT → Trigger action
```
