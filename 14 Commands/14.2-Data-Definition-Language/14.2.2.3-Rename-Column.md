# 14.2.2.3-Rename-Column

## 1. What is RENAME COLUMN?

**RENAME COLUMN** is an operation of the `ALTER` command.

It is used to **change the name of an existing column** in a table.

### Simple Example

Suppose the table has:

| BID | BNAME | BHQ       |
| --: | ----- | --------- |
|   1 | SBI   | Hyderabad |
|   2 | HDFC  | Mumbai    |

Suppose we want to change the column name:

```text
BNAME
  ↓
BANKNAME
```

We use `ALTER TABLE ... RENAME COLUMN`.

---

# 2. Why do we need RENAME COLUMN?

Sometimes a column name may not be clear or may not follow the required naming convention.

For example:

```text
BNAME
```

can be changed to:

```text
BANKNAME
```

The **column name changes**, but the column's purpose remains the same.

```text
Old column name
      ↓
   RENAME
      ↓
New column name
```

---

# 3. Syntax

### Question

**How do we rename an existing column?**

### Syntax

```sql
ALTER TABLE table_name
RENAME COLUMN old_column_name
TO new_column_name;
```

---

## 4. Syntax Explanation

| Syntax Part       | Meaning                                          |
| ----------------- | ------------------------------------------------ |
| `ALTER`           | Used to modify an existing table                 |
| `TABLE`           | Specifies that a table is being modified         |
| `table_name`      | Name of the existing table                       |
| `RENAME COLUMN`   | Specifies that the column name should be changed |
| `old_column_name` | Current name of the column                       |
| `TO`              | Specifies the new name                           |
| `new_column_name` | New name of the column                           |
| `;`               | End of the SQL statement                         |

### Easy way to remember

```text
ALTER TABLE
     ↓
Which table?
     ↓
RENAME COLUMN
     ↓
Old name
     ↓
TO
     ↓
New name
```

---

# 5. Example

### Question

**Rename the `bname` column of the `Bank` table to `bankname`.**

### Query

```sql
ALTER TABLE Bank
RENAME COLUMN bname
TO bankname;
```

---

# 6. Step-by-Step Execution

### Before renaming

The table structure is:

| Column Name | Data Type      |
| ----------- | -------------- |
| `BID`       | `INT`          |
| `BNAME`     | `VARCHAR2(87)` |
| `BHQ`       | `VARCHAR2(46)` |

Execute:

```sql
ALTER TABLE Bank
RENAME COLUMN bname
TO bankname;
```

### Step 1

Oracle identifies the existing table:

```text
BANK
```

### Step 2

Oracle identifies the existing column:

```text
BNAME
```

### Step 3

`RENAME COLUMN` tells Oracle to change the column name.

### Step 4

`TO BANKNAME` specifies the new name.

### After execution

| Column Name | Data Type      |
| ----------- | -------------- |
| `BID`       | `INT`          |
| `BANKNAME`  | `VARCHAR2(87)` |
| `BHQ`       | `VARCHAR2(46)` |

So:

```text
BNAME
  ↓
BANKNAME
```

The column has been renamed.

---

# 7. What happens to the existing data?

Renaming a column does **not mean that the existing values are removed**.

Suppose before renaming:

| BID | BNAME | BHQ       |
| --: | ----- | --------- |
|   1 | SBI   | Hyderabad |
|   2 | HDFC  | Mumbai    |

After:

```sql
ALTER TABLE Bank
RENAME COLUMN bname
TO bankname;
```

the data is still there:

| BID | BANKNAME | BHQ       |
| --: | -------- | --------- |
|   1 | SBI      | Hyderabad |
|   2 | HDFC     | Mumbai    |

Only the **column name** has changed.

---

# 8. Rename Column vs Drop Column

| Rename Column              | Drop Column                     |
| -------------------------- | ------------------------------- |
| Changes the column name    | Removes the column              |
| Column continues to exist  | Column no longer exists         |
| Data remains in the column | Column and its data are removed |
| Uses `RENAME COLUMN`       | Uses `DROP COLUMN`              |

### Example

**Rename:**

```sql
ALTER TABLE Bank
RENAME COLUMN bname TO bankname;
```

**Drop:**

```sql
ALTER TABLE Bank
DROP COLUMN bname;
```

### Memory Trick

> **RENAME → Change the name**
> **DROP → Remove the column**

---

# 9. Rename Column vs Rename Table

These two are easy to confuse.

| Rename Column        | Rename Table          |
| -------------------- | --------------------- |
| Changes column name  | Changes table name    |
| Uses `RENAME COLUMN` | Uses `RENAME TO`      |
| `BNAME → BANKNAME`   | `BANK → BANK_DETAILS` |

### Rename a column

```sql
ALTER TABLE Bank
RENAME COLUMN bname TO bankname;
```

### Rename a table

```sql
ALTER TABLE Bank
RENAME TO Bank_Details;
```

---

# 10. Common Mistakes

### Mistake 1 — Forgetting `COLUMN`

❌

```sql
ALTER TABLE Bank
RENAME bname TO bankname;
```

✅

```sql
ALTER TABLE Bank
RENAME COLUMN bname TO bankname;
```

---

### Mistake 2 — Using `DROP`

If the requirement is to **rename** the column, don't use `DROP`.

❌

```sql
ALTER TABLE Bank
DROP COLUMN bname;
```

This removes the column.

✅

```sql
ALTER TABLE Bank
RENAME COLUMN bname TO bankname;
```

---

### Mistake 3 — Confusing column name with table name

If we want:

```text
BNAME → BANKNAME
```

we rename the **column**.

If we want:

```text
BANK → BANK_DETAILS
```

we rename the **table**.

---

# 11. Important Rules

| Rule | Explanation                                    |
| ---- | ---------------------------------------------- |
| 1    | The table must already exist                   |
| 2    | The column must already exist                  |
| 3    | Use `ALTER TABLE`                              |
| 4    | Use `RENAME COLUMN` for changing a column name |
| 5    | Specify the old column name                    |
| 6    | Use `TO` before the new column name            |
| 7    | The column's existing data remains             |

# 12. Interview Questions

### Question 1

**How do you rename a column in SQL?**

### Answer

```sql
ALTER TABLE table_name

TO new_column_name;
```

---

### Question 2

**Which command is used to rename an existing column?**

### Answer

> `ALTER TABLE ... RENAME COLUMN` is used to rename an existing column.

---

### Question 3

**Does renaming a column delete its data?**

### Answer

> No. The column name changes, but the existing data remains.

---

### Question 4

**What is the difference between RENAME COLUMN and DROP COLUMN?**

### Answer

> `RENAME COLUMN` changes the name of a column, whereas `DROP COLUMN` removes the column from the table.
