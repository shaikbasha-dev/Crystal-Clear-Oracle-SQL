# 13.5 Outer Join Overview

## 1. What is an Outer Join?

An **Outer Join** is used when we want to get **matching records as well as some non-matching records**.

This is the main difference from an Inner Join.

### Inner Join

```text
Only matching records
```

### Outer Join

```text
Matching records
       +
Non-matching records
```

---

# 2. Why do we need Outer Join?

Suppose we have two tables:

### Table 1

|  B |
| -: |
|  2 |
|  4 |
|  6 |
|  8 |

### Table 2

|  B |
| -: |
|  2 |
|  8 |
|  9 |

The matching values are:

```text
2 → match
8 → match
```

But there are also non-matching values:

```text
Table 1 → 4, 6
Table 2 → 9
```

An **Inner Join** would return only:

```text
2
8
```

But an **Outer Join** can also preserve the required non-matching records.

---

# 3. Types of Outer Join

There are **three types**:

```text
              OUTER JOIN
                  │
       ┌──────────┼──────────┐
       ↓          ↓          ↓
     LEFT       RIGHT       FULL
     OUTER      OUTER       OUTER
     JOIN       JOIN        JOIN
```

They are:

1. **Left Outer Join**
2. **Right Outer Join**
3. **Full Outer Join**



---

# 4. Left Outer Join

A **Left Outer Join** returns:

> **All rows from the left table + only matching rows from the right table.**

```text
LEFT TABLE                    RIGHT TABLE
    │                              │
    │                              │
    └────── ALL ROWS ──────────────┘
                   +
             matching rows
```

### Example

If:

```text
Table 1 → LEFT
Table 2 → RIGHT
```

then:

```text
LEFT TABLE
   ↓
All rows are kept

RIGHT TABLE
   ↓
Only matching rows are kept
```

### Syntax

```sql
SELECT */attribute
FROM Table1
LEFT OUTER JOIN Table2
ON Table1.B = Table2.B;
```

It can also be written as:

```sql
SELECT */attribute
FROM Table1
LEFT JOIN Table2
ON Table1.B = Table2.B;
```



---

# 5. Right Outer Join

A **Right Outer Join** returns:

> **All rows from the right table + only matching rows from the left table.**

```text
LEFT TABLE
   ↓
Only matching rows

RIGHT TABLE
   ↓
All rows
```

### Syntax

```sql
SELECT */attribute
FROM Table1
RIGHT OUTER JOIN Table2
ON Table1.B = Table2.B;
```

It can also be written as:

```sql
SELECT */attribute
FROM Table1
RIGHT JOIN Table2
ON Table1.B = Table2.B;
```



---

# 6. Full Outer Join

A **Full Outer Join** is a combination of Left Outer Join and Right Outer Join.

It returns:

> **Matching and non-matching records from both tables.**

So:

```text
LEFT TABLE
   ↓
All rows

        +

RIGHT TABLE
   ↓
All rows
```

Therefore, the result can contain:

* Matching records
* Left-only records
* Right-only records



### Syntax

```sql
SELECT */attribute
FROM Table1
FULL OUTER JOIN Table2
ON Table1.B = Table2.B;
```

---

# 7. Main Difference

This is the easiest way to remember the three:

| Join                 | What is preserved?                         |
| -------------------- | ------------------------------------------ |
| **Left Outer Join**  | Everything from LEFT + matching from RIGHT |
| **Right Outer Join** | Everything from RIGHT + matching from LEFT |
| **Full Outer Join**  | Everything from BOTH                       |

# 8. Visual Memory

Imagine:

```text
        LEFT TABLE          RIGHT TABLE

             A                 B
          ┌───────┐         ┌───────┐
          │       │         │       │
          │       │         │       │
          └───────┘         └───────┘
```

### LEFT OUTER JOIN

```text
████████████     ░░░░░░░░░░
████████████     ░░ matching
ALL LEFT         RIGHT
```

**Remember: LEFT = Keep all left rows.**

---

### RIGHT OUTER JOIN

```text
░░░░░░░░░░       ████████████
matching         ALL RIGHT
LEFT             RIGHT
```

**Remember: RIGHT = Keep all right rows.**

---

### FULL OUTER JOIN

```text
████████████     ████████████
ALL LEFT         ALL RIGHT
       \          /
        \        /
       EVERYTHING
```

**Remember: FULL = Keep both sides.**

# 9. EMP and DEPT Example

The common column between `EMP` and `DEPT` is:

```text
DEPT_ID
```

So the relationship is:

```sql
EMP.DEPT_ID = DEPT.DEPT_ID
```

### Question

**How can we combine EMP and DEPT while keeping all records from the left table?**

### Answer / Query

```sql
SELECT *
FROM EMP e
LEFT OUTER JOIN DEPT d
ON e.DEPT_ID = d.DEPT_ID;
```

Here:

```text
EMP → LEFT TABLE
DEPT → RIGHT TABLE
```

Therefore:

```text
All EMP rows
     +
Matching DEPT rows
```

---

# 10. Important Difference from Inner Join

### Inner Join

```sql
SELECT *
FROM EMP e
INNER JOIN DEPT d
ON e.DEPT_ID = d.DEPT_ID;
```

Result:

```text
Only matching records
```

### Left Outer Join

```sql
SELECT *
FROM EMP e
LEFT OUTER JOIN DEPT d
ON e.DEPT_ID = d.DEPT_ID;
```

Result:

```text
All EMP records
+
Matching DEPT records
```

So the key question is:

> **Do I want only matches, or do I also want unmatched records?**

```text
Only matches       → INNER JOIN

Keep left side     → LEFT OUTER JOIN

Keep right side    → RIGHT OUTER JOIN

Keep both sides    → FULL OUTER JOIN
```

# 11. Important Interview Questions

### Q1. What is an Outer Join?

**Answer:**
An Outer Join returns matching records and can also retain non-matching records from one or both tables.

### Q2. How many types of Outer Join are there?

**Answer:**

1. Left Outer Join
2. Right Outer Join
3. Full Outer Join

### Q3. What does Left Outer Join return?

**Answer:**
All rows from the left table and only matching rows from the right table.

### Q4. What does Right Outer Join return?

**Answer:**
All rows from the right table and only matching rows from the left table.

### Q5. What does Full Outer Join return?

**Answer:**
Both matching and non-matching records from both tables.

### Q6. Which Outer Join keeps everything from the left table?

**Answer:**
**Left Outer Join.**

### Q7. Which Outer Join keeps everything from the right table?

**Answer:**
**Right Outer Join.**

### Q8. Which Outer Join keeps everything from both tables?

**Answer:**
**Full Outer Join.**

# 12. Easy Memory Trick

```text
LEFT  → All LEFT
RIGHT → All RIGHT
FULL  → All BOTH
```

And:

```text
INNER → Matching only
```

### Final picture

```text
INNER JOIN
    ↓
MATCHING ONLY

LEFT OUTER JOIN
    ↓
ALL LEFT + MATCHING RIGHT

RIGHT OUTER JOIN
    ↓
ALL RIGHT + MATCHING LEFT

FULL OUTER JOIN
    ↓
ALL LEFT + ALL RIGHT
```
