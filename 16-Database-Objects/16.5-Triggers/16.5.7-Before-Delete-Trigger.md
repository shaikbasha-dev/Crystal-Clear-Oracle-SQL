# 16.5.7-Before-Delete-Trigger

## 1. What is a BEFORE DELETE Trigger?

A **BEFORE DELETE Trigger** is a Trigger whose action is executed **before an existing row is deleted from a table**.

Break the name into two parts:

```text
BEFORE → When?
DELETE → Which event?
```

So the flow is:

```text
DELETE is about to happen
        ↓
BEFORE DELETE Trigger executes
        ↓
Trigger Action
        ↓
DELETE continues
```

Triggers are prepared SQL statements saved in the database and executed autonomously when their specified event occurs.

---

## 2. Why is it called BEFORE DELETE?

Because the Trigger action happens **before the DELETE operation**.

```text
BEFORE DELETE

Trigger Action
      ↓
DELETE
```

Compare this with AFTER DELETE:

```text
AFTER DELETE

DELETE
  ↓
Trigger Action
```

### Easy memory

> **BEFORE DELETE → Trigger first, DELETE next**
> **AFTER DELETE → DELETE first, Trigger next**

---

# 3. General Syntax

### Question:

What is the syntax for creating a BEFORE DELETE Trigger?

### Answer / Syntax:

```sql
CREATE TRIGGER trigger_name
BEFORE DELETE
ON table_name
FOR EACH ROW
BEGIN
    SQL Query;
END;
```

The general Trigger syntax specifies the timing, event, table and action.

---

# 4. Understanding the Syntax

| Part             | Meaning                          |
| ---------------- | -------------------------------- |
| `CREATE TRIGGER` | Creates a Trigger                |
| `trigger_name`   | Name of the Trigger              |
| `BEFORE`         | Action occurs before the event   |
| `DELETE`         | Event that activates the Trigger |
| `ON table_name`  | Table on which DELETE occurs     |
| `FOR EACH ROW`   | Applies to each affected row     |
| `BEGIN`          | Starts Trigger body              |
| `SQL Query`      | Action performed by Trigger      |
| `END`            | Ends Trigger                     |

---

# 5. What happens during DELETE?

Suppose an employee record is going to be deleted.

```text
Employee record exists
       ↓
DELETE is about to happen
       ↓
BEFORE DELETE Trigger
       ↓
Trigger Action
       ↓
Employee record is deleted
```

The important point is:

> The Trigger action occurs **before the row is deleted**.

---

# 6. What is `:OLD` in DELETE?

For a DELETE event, the row that is going to be removed is an **existing/old row**.

Therefore:

```text
DELETE → :OLD
```

The row-reference mapping is:

| Event  | Reference       |
| ------ | --------------- |
| INSERT | `:NEW`          |
| UPDATE | `:OLD` + `:NEW` |
| DELETE | `:OLD`          |

So in a BEFORE DELETE Trigger, we use `:OLD` to refer to the row that is about to be deleted.

### Example:

```text
Before DELETE:

ID = 101
Name = Basha
Salary = 25000

        ↓

:OLD.id     = 101
:OLD.name   = Basha
:OLD.salary = 25000
```


# 8. Example of a DELETE Event

### Question:

Delete an employee whose `emp_id` is `101` from `emp1`.

### Answer / Query:

```sql
DELETE FROM emp1
WHERE emp_id = 101;
```

If a BEFORE DELETE Trigger exists on `emp1`, the flow is:

```text
DELETE FROM emp1
WHERE emp_id = 101
        ↓
BEFORE DELETE Trigger
        ↓
Trigger Action
        ↓
Employee 101 is deleted
```

# 9. Event and Action

### Question:

In a BEFORE DELETE Trigger, identify the timing, event and action.

### Answer:

**Timing:**

```text
BEFORE
```

**Event:**

```text
DELETE
```

**Action:**

```text
SQL statement written inside the Trigger
```

Therefore:

```text
BEFORE DELETE
      ↓
DELETE event is about to occur
      ↓
Trigger action executes
```

# 10. BEFORE DELETE vs AFTER DELETE

| BEFORE DELETE                       | AFTER DELETE                       |
| ----------------------------------- | ---------------------------------- |
| Trigger action occurs before DELETE | Trigger action occurs after DELETE |
| Timing = BEFORE                     | Timing = AFTER                     |
| Event = DELETE                      | Event = DELETE                     |
| Uses `:OLD`                         | Uses `:OLD`                        |

### Visual memory

```text
BEFORE DELETE

BEFORE Trigger
      ↓
DELETE
```

```text
AFTER DELETE

DELETE
  ↓
AFTER Trigger
```

---

# 11. DELETE vs UPDATE

| DELETE                  | UPDATE                  |
| ----------------------- | ----------------------- |
| Removes an existing row | Changes an existing row |
| Uses `:OLD`             | Uses `:OLD` and `:NEW`  |
| Example: BEFORE DELETE  | Example: BEFORE UPDATE  |

Easy memory:

```text
DELETE → :OLD
UPDATE → :OLD + :NEW
```

---

# 12. Important Points

* `BEFORE DELETE` is one of the six Trigger combinations.
* `BEFORE` specifies the timing.
* `DELETE` specifies the event.
* The Trigger action executes before the row is deleted.
* DELETE uses `:OLD`.
* `:OLD` represents the existing row that is going to be deleted.
* A Trigger executes autonomously when its specified event occurs.
