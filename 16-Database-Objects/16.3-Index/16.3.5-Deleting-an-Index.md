# 16.3.5-Deleting-an-Index

## 1. What does Deleting an Index mean?

Deleting an Index means **removing an existing Index from the database**.

When an Index is no longer required, we can delete it using the `DROP INDEX` command.

---

## 2. Syntax

### Question:

What is the syntax for deleting an Index?

### Answer / Query:

```sql
DROP INDEX index_name;
```



### Syntax Explanation

| Part         | Meaning                         |
| ------------ | ------------------------------- |
| `DROP INDEX` | Deletes an Index                |
| `index_name` | Name of the Index to be deleted |

---

# 3. Example

Earlier, we created an Index named `dec`:

```sql
CREATE INDEX dec
ON emp(dept_id);
```

Now we want to remove it.

### Question:

Delete the Index named `dec`.

### Answer / Query:

```sql
DROP INDEX dec;
```



### Query Explanation

```text
DROP INDEX
     ↓
    dec
```

* `DROP INDEX` → tells Oracle to delete an Index.
* `dec` → name of the Index being deleted.

After successful execution, the Index `dec` is removed.

---

# 4. What happens to the Table?

Suppose:

```text
EMP TABLE
   │
   └── INDEX DEC
```

After:

```sql
DROP INDEX dec;
```

it becomes:

```text
EMP TABLE
   │
   └── INDEX DEC ❌
```

The **Index is deleted**, but the `emp` table remains.

### Important:

> **Deleting an Index does not delete the table or its data.**

---

# 5. Complete Index Flow

```text
                INDEX
                  │
          ┌───────┴────────┐
          ↓                ↓
       CREATE            DELETE
          ↓                ↓
    CREATE INDEX       DROP INDEX
          ↓                ↓
         dec             dec ❌
```

### Create an Index

### Question:

Create an Index named `dec` on `dept_id` of `emp`.

### Query:

```sql
CREATE INDEX dec
ON emp(dept_id);
```

### Delete the Index

### Question:

Delete the Index named `dec`.

### Query:

```sql
DROP INDEX dec;
```

---

# 6. Index vs Table Deletion

| Delete Index       | Delete Table                   |
| ------------------ | ------------------------------ |
| `DROP INDEX`       | `DROP TABLE`                   |
| Deletes the Index  | Deletes the table              |
| Table remains      | Table is removed               |
| Table data remains | Table and its data are removed |

Remember:

```text
DROP INDEX → Index
DROP TABLE  → Table
```

---

# 7. Important Points

* `DROP INDEX` is used to delete an Index.
* The Index name must be specified.
* Deleting an Index does **not** delete the table.
* Deleting an Index does **not** mean deleting the table's data.

# 8. Interview Questions

### Q1. Which command is used to delete an Index?

**Answer:**

```sql
DROP INDEX;
```

### Q2. What is the syntax for deleting an Index?

**Answer:**

```sql
DROP INDEX index_name;
```

### Q3. How do you delete an Index named `dec`?

**Answer:**

```sql
DROP INDEX dec;
```

### Q4. Does `DROP INDEX` delete the table?

**Answer:**
No. It deletes only the Index. The table remains.

### Q5. What is the difference between `DROP INDEX` and `DROP TABLE`?

**Answer:**

* `DROP INDEX` → removes an Index.
* `DROP TABLE` → removes a table.

# 9. One-Line Memory Trick

> **CREATE INDEX → Create an Index**
> **DROP INDEX → Delete an Index**

```text
CREATE INDEX dec
       ↓
      INDEX
       ↓
DROP INDEX dec
       ↓
    INDEX ❌
```
